# 使用临时密钥修改用户密码
##### 简要描述
请求中超级用户(SuperPassword)的密码通过手机app扫描EasySearch上的二维码获取，获取的密码存在有效期，超时后需要重新获取
![](http://zwp2p.p6sai.com:4999/server/index.php?s=/api/attachment/visitFile&sign=474332b2d33de4d9c38d23e2a8be4b26)

##### 请求

**xml**

```
<?xml version=”1.0" encoding="utf-8"?>
<PasswordModify>
    <SuperUserName><!--wo,req,xs:string, the max length : 32--></SuperUserName>
    <SuperPassword><!--wo,req,xs:string, the max length : 32--></SuperPassword>
    <ModifyUserName><!--wo,req,xs:string, the max length : 32--></ModifyUserName>
    <ModifyPassword><!--wo,req,xs:string, the max length : 32--></ModifyPassword>
</PasswordModify>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| SuperUserName | string | 超级用户的用户名，默认是admin | 是 | 是 | 否 | 只写 | 最大长度32 |  |
| SuperPassword | string | 超级用户的密码，通过手机app扫描EasySearch上的二维码获取，获取的密码存在有效期，超时后需要重新获取 | 是 | 是 | 否 | 只写 | 最大长度32 |  |
| ModifyUserName | string | 要修改的用户名, 默认是admin | 是 | 是 | 否 | 只写 | 最大长度32 |  |
| ModifyPassword | string | 要修改的用户密码 | 是 | 是 | 否 | 只写 | 最大长度32 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/Security/ModifyPasswordByTempSecretKey` 

##### 请求方式

- put
