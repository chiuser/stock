# 获取指定用户信息
##### 简要描述

- ##### 说明

当调用“GET”方法时，<ID>单元有效，当调用其他方法时，<ID>单元无效。您无法通过<ID>设置用户信息，只需通过<UserName>设置用户密码。
<ID>从1开始。
请不要删除“default”或“admin”用户。
请不要创建“default”或“管理员”级别用户，您只需创建“普通”级别用户即可。
我们只是支持用户级别.

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<User>
    <ID><!--rw,req,xs:integer--></ID>
    <UserName><!--rw,req,xs:string, the max  length : 64--></UserName>
    <UserLevel><!--rw,req,xs:string,”Default,Adminstrator,Normal”--> </UserLevel>
    <IPAddress><!--rw,req,xs:string, the max  length : 16--></IPAddress>
    <MACAddress><!--rw,req,xs:string, the max  length : 18--></MACAddress>
</User>
```
