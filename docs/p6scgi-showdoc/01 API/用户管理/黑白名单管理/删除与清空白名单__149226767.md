# 删除与清空白名单
##### 简要描述

##### **请求**

**xml**

```xml
<WhiteList>
    <ID><!--wo,req,xs:integer,the value is unique--></ID>
    <Mode><!--wo,req,xs:string,”IP”,”IPRange” --></Mode>
    //根据Mode决定参数，若Mode为IP，则为：
    <IP><!--wo,opt,xs:string, --></IP>
    //若Mode为IPRange，则为：
    <IPBegin><!--wo,opt,xs:string, --></IPBegin>
    <IPEnd><!--wo,opt,xs:string, --></IPEnd>
</WhiteList>
```

| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| WhiteList |  | <span class="colour" style="color:rgb(106, 153, 85)">白名单规则</span> | 否 | 是 |  |  |  |  |
| ID | integer | <span class="colour" style="color:rgb(106, 153, 85)">白名单ID</span> | 是 | 是 | 否 | 只写 | 取值需与设备确认 |  |
| Mode | string | <span class="colour" style="color:rgb(106, 153, 85)">白名单规则，</span><span class="colour" style="color:rgb(206, 145, 120)">IP</span><span class="colour" style="color:rgb(106, 153, 85)">-指定IP，</span><span class="colour" style="color:rgb(206, 145, 120)">IPRange</span><span class="colour" style="color:rgb(106, 153, 85)">-指定IP段</span> | 是 | 是 | 否 | 只写 | 动态数组 |  |
