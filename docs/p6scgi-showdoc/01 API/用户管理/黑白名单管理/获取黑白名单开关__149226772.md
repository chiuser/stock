# 获取黑白名单开关
##### 简要描述

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<BaseConfig>
    //白名单功能开关：true-开启，false-关闭
    <WhiteList><!--rw,opt,xs:boolean--></WhiteList>
</BaseConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| WhiteList | boolean | <span class="colour" style="color:rgb(106, 153, 85)">白名单是否使能；false-否，true-是</span> | 否 | 是 | 否 | 可读可写 | false/true |  ||

##### 请求URL

 - `/Security/BaseConfig` 

##### 请求方式

- get
