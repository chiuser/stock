# 根据用户名获取用户权限
##### 简要描述

URL使用示例：
[http://xxx.xxx.xxx.xxx/Security/UserPermissionConfigByUsername?Username=xxx](http://xxx.xxx.xxx.xxx/Security/UserPermissionConfigByUsername?Username=xxx)

UserID：用户ID
UserName：用户名
UserType：用户类型
RemoteConfigPermission：远程配置权限
FaceGroupManagePermission：脸库管理权限
RealStreamPermission：实时流权限
VoiceTalkPermission：语音权限
PTZControlPermission：PTZ配置权限
RemotePlaybackPermission：远程回放权限(历史流)

##### 请求

**xml**
无
**字段说明**
无
