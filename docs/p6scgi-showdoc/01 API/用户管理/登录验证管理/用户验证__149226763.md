# 用户验证
##### 简要描述
  | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
 | ---------------- | ---------------- | ---------- | --------- |
 |  | <span class="colour" style="color: rgb(206, 145, 120);">登录界面</span> |  |||
 
##### 请求示例

```
URL：[http://192.168.1.46/Security/UserAuth](http://192.168.1.46/Security/UserAuth)
数据格式:
  PUT /Security/UserAuth HTTP/1.1\r\n
  Connection:close\r\n
  Host: 192.168.0.46\r\n
  Content-Length:\r\n
\r\n
Username=admin&Password=admin&LoginMode=factory
```
   说明：LoginMode表示登录模式，取值“common”、“factory”，“common”表示一般登录模式，“factory”表示工厂模式

##### 请求URL

 - `/Security/UserAuth` 

##### 请求方式

- put
