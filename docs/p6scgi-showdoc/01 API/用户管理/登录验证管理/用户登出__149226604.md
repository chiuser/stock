# 用户登出
##### 简要描述

- ##### 请求

**xml**

```
<LogoutInfo>
    <Token><!--wo,req,xs:string,the max len is 32--></Token>
</LogoutInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Token | string | 用户token | 是 | 是 | 否 | 只写 | 最大长度32 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/UserTokenLogout` 

##### 请求方式

- put

```
{}
```
