# 设置第三方协议开启配置
##### 简要描述

- ##### 请求

**xml**

```
<ThirdPartyProtocolConfig>
    <JSTP><!--rw,opt,xs:boolean,”false”,”true” --></JSTP>
</ThirdPartyProtocolConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| JSTP | boolean | 是否开启第三方协议配置<span class="colour" style="color:rgb(106, 153, 85)">，false-否，true-是</span> | 否 | 是 | 否 | 可读可写 | false/true |  |  | <span class="colour" style="color: rgb(206, 145, 120);">配置-网络-第三方协议-HK协议</span> |  |  ||

##### 响应

**xml**
无
**字段说明**
无

 - `/System/ChannelID/ThirdProtocolManage`
