# 检测设备网络状态
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<DetectDeviceNetworkInfo Version="1.0">
    <ifname><!--wo,req,xs:string,the max length :  64--></ifname>
    <Host_addr><!--wo,req,xs:string,the max length :  256--></Host_addr>
</DetectDeviceNetworkInfo>
```

**字段说明**<span lang="EN-US"></span>

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ifname | string | 网卡名 | 是 | 是 | 否 | 只写 | 最大长度64 |  |
| Host_addr | string | 域名或IP地址<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 只写 | 最大长度256 |  ||

##### 响应

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<DetectDeviceNetworkStatus Version="1.0">
    <PingInfo1><!--ro,req,xs:string--></PingInfo1>
    <PingInfo1><!--ro,req,xs:string--></PingInfo1>
    ...
</DetectDeviceNetworkStatus>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| PingInfo1 | string | Ping状态信息 | 是 | 是 | 否 | 只读 | 动态数组 |  ||

##### 请求URL

 - `/System/DetectDeviceNetworkStatus` 

##### 请求方式

- post
