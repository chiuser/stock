# 设置P2P配置V2
##### 简要描述

- ##### 说明

请不要频繁设置网络配置，因为设备端设置的网络配置是异步响应，所以如果经常设置，只响应第一个操作，建议时间间隔设置为3-5s。
设置完UUID后，IPC会自动重启，UID会在重启后生效。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<P2PList>
    <P2P>
        <ID><!--rw,req,xs:integer--></ID>
        <Enable><!--rw,req,xs:boolean--></Enable>
        <UUID><!--rw,req,xs:string, the max  length:64--></UUID>
        <SubKey><!--rw,opt,xs:string, the max  length:20--></SubKey>
        <P2PConnectInfo>
            <PlatformName><!--wo,req,xs:string, the max  length:16--></PlatformName>
            <Server><!--wo,req,xs:string, the max  length:256--></Server>
            <AuthWord><!--wo,req,xs:string, the max  length:32--></AuthWord>
            <DomainList>
                <Domain>
                    <Address><!--wo,req,xs:string, the max  length:64--></Address>
                    <IP><!--wo,req,xs:string, the max  length:16--></IP>
                </Domain>
            </DomainList>
        </P2PConnectInfo>
    </P2P>
</P2PList>
```
