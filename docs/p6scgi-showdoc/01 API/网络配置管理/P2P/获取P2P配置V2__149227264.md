- ##### 请求

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<P2PList>
    <P2P>
        <ID><!--rw,req,xs:integer--></ID>
        <Enable><!--rw,req,xs:boolean--></Enable>
        <P2PProtocolName><!--ro,req,xs:string, "tutk", "ulk"--></P2PProtocolName>
        <UUID><!--rw,req,xs:string,  the max length:64--></UUID>
        <SubKey><!--rw,req,xs:string,  the max length:20--></SubKey>
        <AndroidAppDownload><!--ro,req,xs:string, the max  length:256--></AndroidAppDownload>
        <IphoneAppDownload><!--ro,req,xs:string, the max  length:256--></IphoneAppDownload>
        <Status><!--ro,req,xs:string,”offline,internet-ready,intranet-ready,Network-Unreachable,Invalid-UUID,NotFoundServer, Online, Register Failed”--></Status>
        <ErrCode><!--ro,req,xs:integer--></ErrCode>
        <DidGetStatus><!--ro,req,xs:string,”OK,Getting,NetWorkErr,Refuse,Fail”--></DidGetStatus>
    </P2P>
</P2PList>
```
