# 设置NVR主动注册配置
##### 简要描述

- ##### 请求

**xml**

```
<RegisterConfig>
    <CmsEnable><!--rw,req,xs:boolean--></CmsEnable>
    <ManageHostAddress><!--rw,req,xs:string; max length 256 --></ManageHostAddress>
    <ManageHostPort><!--rw,req,xs:integer--></ManageHostPort>
    <AutoRegIntervals><!--rw,req,xs:integer--></AutoRegIntervals>
</RegisterConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| CmsEnable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否启用管理服务器；false-不启用管理服务器, true-启用</span> | <span class="colour" style="color:black">是</span> | <span class="colour" style="color:black">是</span> | 否 | 可读可写 | false，true |  |  | <span class="colour" style="color: rgb(206, 145, 120);">配置-网络-主动注册-启用主动注册</span> |  |  |
| ManageHostAddress | string | <span class="colour" style="color:rgb(106, 153, 85)">远程管理主机地址，长度考虑域名，最大长度256</span> | <span class="colour" style="color:black">是</span> | <span class="colour" style="color:black">是</span> | 否 | 可读可写 | 动态数组 |  |  | <span class="colour" style="color: rgb(206, 145, 120);">配置-网络-主动注册-地址</span> |  | 受CmsEnable限制是否显示 |
| ManageHostPort | <span class="colour" style="color:black">integer</span> | <span class="colour" style="color:rgb(106, 153, 85)">远程管理主机端口</span> | <span class="colour" style="color:black">是</span> | <span class="colour" style="color:black">是</span> | 否 | 可读可写 | 0-65535 |  |  | <span class="colour" style="color: rgb(206, 145, 120);">配置-网络-主动注册-端口</span> |  | 受CmsEnable限制是否显示 |
| AutoRegIntervals | <span class="colour" style="color:black">integer</span> | <span class="colour" style="color:rgb(106, 153, 85)">注册间隔时间，单位为秒，暂时无效，默认为10s</span> | <span class="colour" style="color:black">是</span> | <span class="colour" style="color:black">是</span> | 否 | 可读可写 | 0-100 |  |  | <span class="colour" style="color: rgb(206, 145, 120);">配置-网络-主动注册-注册间隔</span> |  | 受CmsEnable限制是否显示 |
