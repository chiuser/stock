# 设置Onvif配置
##### 简要描述

- ##### 请求

**xml**

```
<OnvifCfg>
    <Enable><!--rw,opt,xs:boolean--></Enable>
    <OnvifAuthEnable><!--rw,opt,xs:boolean--></OnvifAuthEnable>
</OnvifCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否使能配置；false-否，true-是</span> | 否 | 是 | 否 | 可读可写 | false/true |  |  | <span class="colour" style="color:rgb(206, 145, 120)">配置-网络-平台接入-ONVIF-平台接入</span> |  |  |
| <span class="colour" style="color: rgb(85, 85, 85);">OnvifAuthEnable</span> | boolean | <span class="colour" style="color: rgb(106, 153, 85);">是否使能Onvif鉴权，Onvif鉴权开启、禁用同时联动控制RTSP的鉴权为开启、禁用；false-否，true-是</span> | 否 | 是 | 否 | 可读可写 | false/true |  |  | <span class="colour" style="color:rgb(206, 145, 120)">配置-网络-平台接入-ONVIF-ONVIF鉴权</span> |  |  ||
