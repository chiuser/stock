# 获取RTSP的流配置信息
##### 简要描述

##### 说明

URI中的<ChannelID>显示通道编号，<ChannelID>从1开始。
<StreamID>表示流类型，通常“1”表示主流，“2”表示“第一个子流”，依此类推。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Transport>
    <RTSPURI><!--ro,opt,xs:string, the max length : 256--></RTSPURI>
</Transport>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| RTSPURI | string | RTSP协议对流进行访问的地址 | 否 | 是 | 否 | 只读 | 最大长度256 |  ||

##### 请求URL

 - `/Streams/ChannelID/StreamID/Transport` 

##### 请求方式

- get
 
##### 成功返回示例  
```
[]

```
