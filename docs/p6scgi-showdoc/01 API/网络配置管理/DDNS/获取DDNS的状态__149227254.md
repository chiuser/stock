# 获取DDNS的状态
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### **响应**

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Status>
    <State><!--rw,req,xs:string, “stopped,Registering ,Registered ,stopping”--></State>
</Status>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否必须 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ---- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| State | string | <span class="colour" style="color:rgb(106, 153, 85)">目前DDNS的状态，stopped表示已经停止，Registering表示正在启动，Registered表示已经启动，stopping表示正在停止</span> | 是 | 是 | 是 | 只读 | 动态数组 | <span class="colour" style="color:rgb(106, 153, 85)">只读</span> |  | <span class="colour" style="color:rgb(85, 85, 85)">配置-网络-DDNS设置-</span><span class="colour" style="color:rgb(206, 145, 120)">连接状态</span> |  |  ||

##### 请求URL

 - `/Network/DDNS/Status` 

##### 请求方式

- get
