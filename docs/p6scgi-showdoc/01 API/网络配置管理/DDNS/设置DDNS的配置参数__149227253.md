# 设置DDNS的配置参数
##### 简要描述

- ##### 说明

请不要频繁设置网络配置，因为设备端设置的网络配置是异步响应，所以如果经常设置，只响应第一个操作，建议时间间隔设置为3-5s。
当获取<Config> XML时，<Password>字段不显示，但如果设置中没有<Password>，则密码不会更改，否则密码将被更改。
设置<ProtocolName>字段时，我们必须确保在协议列表中获取字段的值，否则您将设置不成功，并且没有错误消息。
仅在<Enable>中为true，另一个设置为有效。
<ServerPort>字段暂时不支持设置，默认值为0。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Config>
    <Enable><!--rw,req,xs:boolean--></Enable>
    <ProtocolName><!--rw,req,xs:string,--></ProtocolName>
    <ServerPort><!--rw,req,xs:integer--></ServerPort>
    <DomainName><!--rw,req,xs:string, the max  length: 256--></DomainName>
    <UserName><!--rw,req,xs:string, the max  length: 64--></UserName>
    <Password><!--wo,opt,xs:string, the max  length: 64--></Password>
    <RefreshIntervals><!--rw,req,xs:integer,in sec--></RefreshIntervals>
</Config>
```
