# 设置Email的所有参数
##### 简要描述

- ##### 说明

请不要频繁设置网络配置，因为设备端设置的网络配置是异步响应，所以如果经常设置，只响应第一个操作，建议时间间隔设置为3-5s。
如果<AllDay>的值为true，则表示每天的所有时间对于运动有效，但<TimeBlockList>的值无效，如果为false，则<TimeBlockList>的值有效。
一天分为48块，这意味着每隔半小时到一段时间，当一块时间被布防时，则块被设置为1，否则，块被设置为0，例如，如果全部一天的时间有效，则<TimeBlock_0>的值为“111111111111111111111111111111111111111111111111”，如果一天中的所有时间都无效，则<Block_0>的值为“000000000000000000000000000000000000000000000000”。
对于<Email>的<Schedule>字段，某些设备不支持，某些设备支持，<Schedule>字段对于不支持设备无效。
当获取<EMail> XML时，不显示<SenderEmailPassword>字段，如果设置时没有<SenderEmailPassword>，则密码不会更改，否则密码将被更改。

##### 请求

**xml**

```
    <AttachedSnapshot><!--rw,req,xs:boolean--></AttachedSnapshot>
    <ConfigMode><!--rw,opt,xs:string,”auto,custom”--></ConfigMode>
    <SenderEmailPassword><!--wo,opt,xs:string, the max length: 64--></SenderEmailPassword>
    <RefreshIntervals><!--rw,opt,xs:integer,in sec--></RefreshIntervals>
    <Topic><!--rw,opt,xs:string,  the max length: 32--></Topic>
    <Message><!--rw,opt,xs:string, the max  length: 128--></Message>
    <SMTPTLSConfig><!--req-->
        <SMTPTLS><!--rw,req,xs:string,”off(NONE),on(SSL),TLS,STARTTLS”--></SMTPTLS>
    </SMTPTLSConfig>
    <ReceiverList><!--req-->
        <Receiver><!--opt-->
            <ID><!--rw,req,xs:integer, start from 1--></ID>
            <EmailAddress><!--rw,req,xs:string,  the max length: 256--></EmailAddress>
        </Receiver>
    </ReceiverList>
    <Schedule><!--opt-->
        <AllDay><!--rw,req,xs:boolean, true, false--></AllDay>
        <TimeBlockList>
            <TimeBlock_0><!--rw,req,xs:string--></TimeBlock_0>
            <TimeBlock_1><!--rw,req,xs:string--></TimeBlock_1>
            <TimeBlock_2><!--rw,req,xs:string--></TimeBlock_2>
            <TimeBlock_3><!--rw,req,xs:string--></TimeBlock_3>
            <TimeBlock_4><!--rw,req,xs:string--></TimeBlock_4>
            <TimeBlock_5><!--rw,req,xs:string--></TimeBlock_5>
            <TimeBlock_6><!--rw,req,xs:string--></TimeBlock_6>
        <TimeBlockList>
    </Schedule>
</EMail>
```
