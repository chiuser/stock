# 设置PPPOE所有参数
##### 简要描述

- ##### 说明

请不要频繁设置网络配置，因为设备端设置的网络配置是异步响应，所以如果经常设置，只响应第一个操作，建议时间间隔设置为3-5s。

##### 请求

**xml**

```
<PPPOE>
    <Config> <!-- rw,req 详情见 /Network/PPPOE/Config--></Config>
</PPPOE>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Config |  | <span class="colour" style="color:rgba(13, 27, 62, 0.65)">PPPOE的配置参数</span> | 是 | 是 |  | 可读可写 |  | 详见：http://zwp2p.p6sai.com:4999/web/#/663863654/149227247 |

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/Network/PPPOE` 

##### 请求方式

- put

{}
