# 设置PPPOE的配置参数
##### 简要描述

- ##### 说明

请不要频繁设置网络配置，因为设备端设置的网络配置是异步响应，所以如果经常设置，只响应第一个操作，建议时间间隔设置为3-5s。
当获取<Config> XML时，<Password>字段不显示，但如果设置中没有<Password>，则密码不会更改，否则密码将被更改。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Config>
    <Enable><!--rw,req,xs:boolean--></Enable>
    <UserName><!--rw,req,xs:string, the max length : 32--></UserName>
    <Password><!--wo,opt,xs:string, the max  length : 32--></Password>
</Config>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | 是否启用PPPoE | 是 | 是 | 否 | 可读可写 | false/true |  |
| UserName | string | PPPoE用户名，最大长度32 | 是 | 是 | 否 | 可读可写 | 最大长度32 |  |
| Password | string | PPPoE用户密码，最大长度32 | 否 | 是 | 否 | 只写 | 最大长度32 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/Network/PPPOE/Config` 

##### 请求方式

- put
