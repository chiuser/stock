# 获取PPPOE的状态
##### 简要描述

- ##### 说明

当<State>是“connected”的值时，<IPAddress>，<SubnetMask>和<Gateway>将有效。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Status>
    <State><!--ro,opt,xs:string, connecting, connected, disconnected, disconnecting--></State>
    <IPAddress><!--ro,opt,xs:string,  the max length : 16--></IPAddress>
    <SubnetMask><!-- ro,opt, xs:string, subnet mask for IPv4 address,  the max length : 16 --></SubnetMask>
    <Gateway><!--ro,opt,xs:string, the max  length : 16--></Gateway>
</Status>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| State | string | <span class="colour" style="color:rgb(106, 153, 85)">PPPoE 连接状态(只读),disconnected表示没有连接，connecting表示正在连接，connected表示连接成功，disconnecting表示正在挂断</span> | 否 | 是 | 否 | 只读 | 动态数组 |  |
| IPAddress | string | <span class="colour" style="color:rgb(106, 153, 85)">PPPoE IP地址(只读)，最大长度16</span> | 否 | 是 | 否 | 只读 | <span class="colour" style="color:rgb(106, 153, 85)">最大长度16</span> |  |
| SubnetMask | string | <span class="colour" style="color:rgb(106, 153, 85)">PPoE 子网掩码(只读)，最大长度16</span> | 否 | 是 | 否 | 只读 | <span class="colour" style="color:rgb(106, 153, 85)">最大长度16</span> |  |
| Gateway | string | <span class="colour" style="color:rgb(106, 153, 85)">PPPoE 网关(只读)，最大长度16</span> | 否 | 是 | 否 | 只读 | <span class="colour" style="color:rgb(106, 153, 85)">最大长度16</span> |  ||

##### 请求URL

 - `/Network/PPPOE/Status` 

##### 请求方式

- get
