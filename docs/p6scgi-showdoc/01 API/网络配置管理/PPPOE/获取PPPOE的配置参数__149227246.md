# 获取PPPOE的配置参数
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Config>
    <Enable><!--rw,req,xs:boolean--></Enable>
    <UserName><!--rw,req,xs:string, the max length : 32--></UserName>
</Config>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | 是否启用PPPoE | 是 | 是 | 否 | 可读可写 | false/true |  |
| UserName | string | PPPoE用户名，最大长度32 | 是 | 是 | 否 | 可读可写 | 最大长度32 |  ||

##### 请求URL

 - `/Network/PPPOE/Config` 

##### 请求方式

- get

```
[]
```
