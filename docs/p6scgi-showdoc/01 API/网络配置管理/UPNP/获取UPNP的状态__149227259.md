# 获取UPNP的状态
##### 简要描述

 ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Status>
    <HTTPPortState><!--ro,req,xs:string,”success,failed,mapping” --></HTTPPortState>
    <MobliePortState><!--ro,req,xs:string,”success,failed,mapping” --></HTTPMoblieState>
    <CommandPortState><!--ro,req,xs:string,”success,failed,mapping”--></CommandPortState>
    <MediaPortState><!--ro,req,xs:string,”success,failed,mapping”--></MediaPortState>
</Status>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| HTTPPortState | string | <span class="colour" style="color:rgb(106, 153, 85)">HTTP端口映射状态 success成功  failed失败  mapping映射中</span> | 是 | 是 | 否 | 只读 | 动态数组 |  |
| MobliePortState | string | <span class="colour" style="color:rgb(106, 153, 85)">手机端口映射状态 success成功  failed失败  mapping映射中</span> | 是 | 是 | 否 | 只读 | 动态数组 |  |
| CommandPortState | string | <span class="colour" style="color:rgb(106, 153, 85)">信令端口映射状态 success成功  failed失败  mapping映射中</span> | 是 | 是 | 否 | 只读 | 动态数组 |  |
| MediaPortState | string | <span class="colour" style="color:rgb(106, 153, 85)">媒体端口映射状态 success成功  failed失败  mapping映射中</span> | 是 | 是 | 否 | 只读 | 动态数组 |  ||

 - `/Network/UPNP/Status`
