# 设置UPNP的配置参数
##### 简要描述

- ##### 说明

请不要频繁设置网络配置，因为设备端设置的网络配置是异步响应，所以如果经常设置，只响应第一个操作，建议时间间隔设置为3-5s。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Config>
    <Enable><!--rw,req,xs:boolean--></Enable>
    <LocalHTTPPort><!--rw,req,xs:integer--></LocalHTTPPort>
    <ExportHTTPPort><!--rw,req,xs:integer--></ExportHTTPPort>
    <LocalMobliePort><!--rw,req,xs:integer--></LocalMobliePort>
    <ExportMobliePort><!--rw,req,xs:integer--></ExportMobliePort>
    <LocalCommandPort><!--rw,req,xs:integer--></LocalCommandPort>
    <ExportCommandPort><!--rw,req,xs:integer--></ExportCommandPort>
    <LocalMediaPort><!--rw,req,xs:integer--></LocalMediaPort>
    <ExportMediaPort><!--rw,req,xs:integer--></ExportMediaPort>
</Config>
```
