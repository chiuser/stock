# 设置UPNP的所有参数
##### 简要描述

- ##### 说明

请不要频繁设置网络配置，因为设备端设置的网络配置是异步响应，所以如果经常设置，只响应第一个操作，建议时间间隔设置为3-5s。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<UPNP>
    <Config><!--rw,req, 详情见 /Network/UPNP/Config --></Config>
</UPNP>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Config | UPNP<span class="colour" style="color:rgba(13, 27, 62, 0.65)">的配置参数</span> |  | 是 | 是 |  | 可读可写 |  | 详见：http://zwp2p.p6sai.com:4999/web/#/663863654/149227258 |

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/Network/UPNP` 

##### 请求方式

- put
