# 设置有线网卡的DHCP
##### 简要描述

- ##### 说明

请不要频繁设置网络配置，因为设备端设置的网络配置是异步响应，所以如果经常设置，只响应第一个操作，建议时间间隔设置为3-5S。
网卡1支持URI /Network/Interfaces/NetworkCardID/IPAddress/DHCP，但是网卡2不支持。
网卡2中的<Status>的值是无效。
默认情况下，“NetworkCardID”的值为1表示有线网络，“NetworkCardID”的值为2表示无线网卡。对于未来，为了支持更多的网卡，此处依次增加。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<DHCP>
    <Enable><!--rw,req,xs:boolean--></Enable>
</DHCP>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否启用DHCP;否-false,是-true</span> | 是 | 是 | 否 | 可读可写 | false/true |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/Network/Interfaces/1/IPAddress/DHCP` 

##### 请求方式

- put

{}
