# 获取有线网卡的DNS
##### 简要描述

- ##### 说明

网卡1支持URI /Network/Interfaces/NetworkCardID/IPAddress/DNS，但是网卡2不支持。.
默认情况下，“NetworkCardID”的值为1表示有线网络，“NetworkCardID”的值为2表示无线网卡。对于未来，为了支持更多的网卡，此处依次增加。

##### 请求
**xml**
无
**字段说明**
无

##### 响应
**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<DNS>
    <Enable><!--rw,req,xs:boolean--></Enable>
    <PrimaryDNS><!--rw,req,xs:string,  the max length: 16--></PrimaryDNS>
    <SecondaryDNS><!--rw,req,xs:string,  the max length: 16--></SecondaryDNS>
</DNS>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否自动获取DNS;否-false,是-true</span> | 是 | 是 | 否 | 可读可写 | false/true |  |
| PrimaryDNS | string | <span class="colour" style="color:rgb(106, 153, 85)">主DNS</span> | 是 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(85, 85, 85)">最大长度16</span> |  |
| SecondaryDNS | string | <span class="colour" style="color:rgb(106, 153, 85)">次DNS</span> | 是 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(85, 85, 85)">最大长度16</span> |  ||


##### 请求URL

 - `/Network/Interfaces/1/IPAddress/DNS` 

##### 请求方式

- get

[]
