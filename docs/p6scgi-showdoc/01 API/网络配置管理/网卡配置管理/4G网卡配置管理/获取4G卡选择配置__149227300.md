# 获取4G卡选择配置
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<_4GCardSelectCfg>
    <ICCID><!--rw,opt,xs::string,, the max length 64--></ICCID>
    <AutoSwitchCard><!--rw,opt,xs::integer,0,不自动切换，1，自动切换--></AutoSwitchCard>
</_4GCardSelectCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ICCID | string | ICCID，<span class="colour" style="color: rgb(64, 64, 64);">SIM卡的唯一标识号码，</span>eg:"898608331923D2038732" | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 最大长度64 |  |
| AutoSwitchCard | integer | 卡切换方式；0,不自动切换，1，自动切换；场景: 设备有两张4G卡，且卡切换方式为自动切换时，如果其中一张4G卡的流量用完或识别异常，设备会自动切换使用另一张4G卡<span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 0/1 |  ||

##### 请求URL

 - `/Network/4GCardSelectCfg` 

##### 请求方式

- get

[]
