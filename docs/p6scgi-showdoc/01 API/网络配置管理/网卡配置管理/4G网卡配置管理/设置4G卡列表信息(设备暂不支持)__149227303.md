# 设置4G卡列表信息(设备暂不支持)
##### 简要描述

- ##### 说明

设备端实际不支持设置

##### 请求

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<_4GCardCfgList>
    <_4GCardCfg>
        <CardType><!--rw,opt,xs:integer,0,内置卡，1，外置卡--></CardType>
        <ICCID><!--rw,opt,xs:string, the max length : 64--></ICCID>
        <CardStatus><!--rw,opt,xs:integer,0，没有卡，1有卡--></CardStatus>
    </_4GCardCfg>
</_4GCardCfgList>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| _4GCardCfg |  | 4G卡信息 | 否 | 是 |  |  |  |  |
| CardType | integer | <span class="colour" style="color:rgb(106, 153, 85)">卡类型，0，内置卡，1，外置卡</span> | 否 | 是 | 否 | 只读 | 0/1 |  |
| ICCID | string | <span class="colour" style="color:rgb(106, 153, 85)">ICCID</span><span class="colour" style="color:rgb(85, 85, 85)">，</span><span class="colour" style="color:rgb(64, 64, 64)">SIM卡的唯一标识号码，</span><span class="colour" style="color:rgb(85, 85, 85)">eg:"898608331923D2038732"</span><span class="colour" style="color:rgb(106, 153, 85)"></span> | 否 | 是 | 否 | 只读 | 最大长度64 |  |
| CardStatus | integer | <span class="colour" style="color:rgb(106, 153, 85)">卡状态；0,没有卡，1，有卡</span> | 否 | 是 | 否 | 只读 | 0/1 |  ||

##### 响应

**xml**
无
**字段说明**
无

 - `/Network/4GCardCfgList`
