# 获取设备 SIM 卡信息
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<DeviceSIMCardInfo>
    <CardInfo>
        <IsInUse><!--rw,opt,xs:boolean,是否正在使用--></IsInUse>
        <Operator><!-- rw,opt,xs:string, 运营商, the max length : 64--></Operator>
        <SignalStrength><!-- rw,opt,xs:integer, 信号强度--></SignalStrength>
        <ICCID><!-- rw,opt,xs:string, ICCID, the max length : 32--></ICCID>
        <IMEI><!-- rw,opt,xs:string, IMEI, the max length : 16--></IMEI>
        <_4GModuleVersion><!-- rw,opt,xs:string, 4G 版本, the max length : 128--></_4GModuleVersion>
        <CardWorkMode><!-- rw,opt,xs:string, "PhysicalCardMode,CloudCardMode"--></CardWorkMode>
        <RegisterStatus><!-- rw,opt,xs:string, "success,locked,failed"--></RegisterStatus>
        <IMSI><!--ro,opt,xs:string, the max length : 16--></IMSI>
        <ACT><!--ro,opt,xs:string, the max length : 16--></ACT>
    </CardInfo>
</DeviceSIMCardInfo>
```
