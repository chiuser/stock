# wifi测试
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<ConnectionConfig>
    <SSID><!--wo,req,xs:string, max length 128--></SSID>
    <MACAddress><!--wo,req,xs:string, max length 18--></MACAddress>
    <NetworkType><!--wo,req,xs:string, "Managed","Ad-hoc"--></NetworkType>
    <AuthMode><!--wo,req,xs:string,"OPEN,SHARED,WEPAUTO,WPAPSK,WPA2PSK,WPANONE,WPA,WPA2,NOPASSWORD"--></AuthMode>
    <Enable><!--wo,opt,xs:boolean;false,true--></Enable>
    <SignalValue><!--wo,opt,xs:integer--></SignalValue>
    <WifiSignalBoostMode><!--wo,opt,xs:boolean;false,true--></WifiSignalBoostMode>
    <WEP>
        <KeyID><!--wo,req,xs:integer--></KeyID>
        <keyList>
            <Key>
                <ID><!--wo,req,xs:integer--></ID>
                <KeyType><!--wo,req,xs:string;"HEX,ASCII"--></KeyType>
                <KeyValue><!--wo,opt,xs:string, max length 128--></KeyValue>
                <KeyValueBase64><!--wo,opt,xs:string, max length 128--></KeyValueBase64> 
            </Key>
        </keyList>
    </WEP>
    <WPA>
        <EncryptType><!--wo,req,xs:string,"NONE,WEP,TKIP,AES"--></EncryptType>
        <Key>
            <ID><!--wo,req,xs:integer--></ID>
            <KeyType><!--wo,req,xs:string;"HEX,ASCII"--></KeyType>
            <KeyValue><!--wo,opt,xs:integer, max length 128--></KeyValue>
            <KeyValueBase64><!--wo,opt,xs:integer, max length 128--></KeyValueBase64> 
        </Key>
    </WPA>
</ConnectionConfig>
```

##### WIFI验证方式
  目前wifi的配置的验证方式，是以wpa为主，本身其实也是支持wep的方式
  
###### wpa验证方式实例

```
<ConnectionConfig Version='1.0'
    xmlns='http://www.zwcloud.wang/ver10/XMLSchema'>
    <Enable>true</Enable>
    <SSID>TP_LINK_KHY</SSID>
    <MACAddress>60:fb:00:73:a0:17</MACAddress>
    <NetworkType>Managed</NetworkType>
    <AuthMode>WPAPSK</AuthMode>
    <WEP Version='1.0'
        xmlns='http://www.zwcloud.wang/ver10/XMLSchema'>
        <KeyID></KeyID>
    </WEP>
    <WPA Version='1.0'
        xmlns='http://www.zwcloud.wang/ver10/XMLSchema'>
        <EncryptType>AES</EncryptType>
        <Key Version='1.0'
            xmlns='http://www.zwcloud.wang/ver10/XMLSchema'>
            <ID>1</ID>
            <KeyType>ASCII</KeyType>
            <KeyValue>123456</KeyValue>
            <KeyValueBase64>MTIzNDU2</KeyValueBase64>
        </Key>
    </WPA>
</ConnectionConfig>

```
