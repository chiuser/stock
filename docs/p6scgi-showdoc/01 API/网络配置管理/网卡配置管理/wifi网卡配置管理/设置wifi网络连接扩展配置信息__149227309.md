# 设置wifi网络连接扩展配置信息
##### 简要描述

- ##### **说明**

请不要频繁设置网络配置，因为设备端设置的网络配置是异步响应，所以如果经常设置，只响应第一个操作，建议时间间隔设置为3-5S。
<span class="colour" style="color:rgb(85, 85, 85)">默认情况下，“NetworkCardID”的值为1表示有线网络，“NetworkCardID”的值为2表示无线网卡。对于未来，为了支持更多的网卡，此处依次增加。</span>

##### **请求**

**_xml_**

```
<?xml version="1.0" encoding="UTF-8" ?>
<WlanConnectionInfoEx>
    <WifiName><!--rw,opt,xs:string,  the max length: 128--></WifiName>
    <WifiSignalStrength><!--rw,opt,xs:integer, range [0-100],default 100 --></WifiSignalStrength>
</WlanConnectionInfoEx>
```

**_字段说明_**

| 字段 | 类型 | 描述 | 是否必须 | 字段是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ------ | ----- | ---------------------- | ------- | --- |
| WifiName | string | <span class="colour" style="color:rgb(0, 130, 0)">热点名称</span> | 否 | 是 | 不可为空 | 可读可写 | 最大长度128 |  |
| WifiSignalStrength | integer | <span class="colour" style="color:rgb(0, 130, 0)">Wifi热点信号强度;取值0-100，默认值100</span> | 否 | 是 | 不可为空 | 可读可写 | <span class="colour" style="color:rgb(0, 130, 0)">取值0-100，默认值100</span> |  ||

##### **响应**

**_xml_**
无
**_字段说明_**
无

##### 请求URL

 - `/Network/Interfaces/NetworkCardID/WirelessEx` 

##### 请求方式

- put
