# 设置wifi网络连接配置
##### 简要描述

##### 说明

请不要频繁设置网络配置，因为设备端设置的网络配置是异步响应，所以如果经常设置，只响应第一个操作，建议时间间隔设置为3-5S。
   只有无线网卡支持URI /Network/Interfaces/NetworkCardID/WIFIAccessPointList.
   如果`<AuthMode>`模式为OPEN，SHARED模式，则`<WEP>`有效。 如果`<AuthMode>`模型是WPAPSK，WPA2PSK更多，那么`<WPA>`是有效的。 否则，它们都无效。但它们都会显示出来。
  如果`<AuthMode>`是WPAPSK或WPA2PSK，则`<WPA>`中`<keyvalue>`的值不应为空。
  `<WPA>`中`<KeyType>`的值必须为“ASCII”。
默认情况下，“NetworkCardID”的值为1表示有线网络，“NetworkCardID”的值为2表示无线网卡。对于未来，为了支持更多的网卡，此处依次增加。

##### 请求

<span class="colour" style="color:rgb(85, 85, 85)">**xml**</span>

    <SignalValue><!--rw,opt,xs:integer--></SignalValue>
    <WEP><!--rw,dep,depends on <AuthMode>-->
        <KeyID><!--rw,req,xs:integer,”1-4”--></KeyID>
        <keyList>
            <Key>
                <ID><!--rw,req,xs:integer--></ID>
                <KeyType><!--rw,req,xs:string, "HEX,ASCII"--></KeyType>
                <KeyValue><!--rw,opt,xs:string,  the max length: 128--></KeyValue>
                <KeyValueBase64><!--rw,opt,xs:string,”the length of the source string is 8-31, and this value will be codec by base64”--></KeyValueBase64>
            </Key>
        </keyList>
    </WEP>
    <WPA><!--dep,depends on <AuthMode>-->
        <EncryptType><!--rw,req,xs:string,NONE,WEP,TKIP,AES--></EncryptType>
        <Key>
            <ID><!--rw,req,xs:integer--></ID>
            <KeyType><!--rw,req,xs:string,”HEX, ASCII”--></KeyType>
            <KeyValue><!--rw,opt,xs:string,  the max length: 128--></KeyValue>
            <KeyValueBase64><!--rw,opt,xs:string,”the length of the source string is 8-31, and this value will be codec by base64”--></KeyValueBase64>
        </Key>

</ConnectionConfig>
