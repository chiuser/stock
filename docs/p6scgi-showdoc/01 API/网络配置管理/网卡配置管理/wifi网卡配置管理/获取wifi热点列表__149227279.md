# 获取wifi热点列表
##### 简要描述

##### 说明

只有无线网卡支持URI  /Network/Interfaces/NetworkCardID/WIFIAccessPointList。
无线模式：

1. legacy 11B only
2. legacy 11A only
3. legacy 11a/b/g mixed
4. legacy 11G only
5. 11ABGN mixed
6. 11N only
7. 11GN mixed
8. 11AN mixed
9. 11BGN mixed
默认情况下，“NetworkCardID”的值为1表示有线网络，“NetworkCardID”的值为2表示无线网卡。对于未来，为了支持更多的网卡，此处依次增加。

##### 请求

**xml**
无
**字段说明**
无
