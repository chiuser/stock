# 设置wifi的IP等配置
##### 简要描述

- ##### 说明

请不要频繁设置网络配置，因为设备端设置的网络配置是异步响应，所以如果经常设置，只响应第一个操作，建议时间间隔设置为3-5S。
默认情况下，“NetworkCardID”的值为1表示有线网络，“NetworkCardID”的值为2表示无线网卡。对于未来，为了支持更多的网卡，此处依次增加。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<IPAddress>
    <ipAddress><!—rw,req,xs:string,  the max length: 16--></ipAddress>
    <SubnetMask><!—rw,req,xs:string,  the max length: 16--></SubnetMask>
    <Gateway><!—rw,req,xs:string,  the max length: 16--></Gateway>
    <IPAdaptive><!—rw,opt,xs:string,  the max length: 32, "open,close"--></IPAdaptive>
    <DHCP>
        <Enable><!—rw,req,xs:boolean--></Enable>
    </DHCP>
    <DNS>
        <Enable><!—rw,req,xs:boolean--></Enable>
        <PrimaryDNS><!—rw,req,xs:string,  the max length: 16--></PrimaryDNS>
        <SecondaryDNS><!—rw,req,xs:string,  the max length: 16--></SecondaryDNS>
    </DNS>
</IPAddress>
```
