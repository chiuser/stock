# 获取wifi的DHCP
##### 简要描述

 ##### 说明

网卡1支持URI /Network/Interfaces/NetworkCardID/IPAddress/DHCP，但是网卡2不支持。
网卡2中的`<Status>`的值是无效。
默认情况下，“NetworkCardID”的值为1表示有线网络，“NetworkCardID”的值为2表示无线网卡。对于未来，为了支持更多的网卡，此处依次增加。

##### 请求
**xml**
无
**字段说明**
无

##### 响应
**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<DHCP>
    <Enable><!--rw,req,xs:boolean--></Enable>
    <Status><!--ro,req,xs:string,”initializing,obtaining,obtained” --></Status>
</DHCP>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | 是否启用DHCP;否-false,是-true | 是 | 是 | 否 | 可读可写 | false/true |  |
| Status | string | DHCP状态；initializing正在初始化，obtaining正在获取中，obtained获取成功 | 是 | 是 | 否 | 只读 | 动态数组 |  ||


##### 请求URL

 - `/Network/Interfaces/2/IPAddress/DHCP`

##### 请求方式

- get

##### 成功返回示例
```
[]
```
