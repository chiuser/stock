# 获取wifi的状态
##### 简要描述

- ##### 说明

    只有无线网卡支持URI /Network/Interfaces/NetworkCardID/WIFIAccessPointList.
默认情况下，“NetworkCardID”的值为1表示有线网络，“NetworkCardID”的值为2表示无线网卡。对于未来，为了支持更多的网卡，此处依次增加。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<WIFIStatus><!--opt-->
    <State><!--ro,opt,xs:string,”open,close,notsupport” --></State>
</WIFIStatus>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Status | string | <span class="colour" style="color:rgb(106, 153, 85)">WIFI状态；open表示开启，close表示关闭, notsupport表示不支持/网卡未找到</span> | 否 | 是 | 否 | 只读 | 动态数组 |  ||

##### 请求URL

 - `/Network/Interfaces/NetworkCardID/WIFIStatus` 

##### 请求方式

- get
 
##### 成功返回示例  
```
[]

```
