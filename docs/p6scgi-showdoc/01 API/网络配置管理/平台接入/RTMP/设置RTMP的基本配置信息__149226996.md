# 设置RTMP的基本配置信息
##### 简要描述

- ##### 说明

<模式>“动态”或“手动”。
<PushURLGeneratorServer>是服务器URL，此服务器必须由我们的协议规定。 如果你想建立一个服务器，你应该联系我们。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<BasicConfig>
    <Mode><!--rw,req,xs:string, "dynamic, manual"--></Mode>
    <PushURLGeneratorServer><!--rw,req,xs:string, the max length : 128--></PushURLGeneratorServer>
</BasicConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Mode | string | <span class="colour" style="color:rgb(106, 153, 85)">当前从服务器获取推流地址模式；</span><span class="colour" style="color:rgb(206, 145, 120)">dynamic </span><span class="colour" style="color:rgb(106, 153, 85)">自动，</span><span class="colour" style="color:rgb(206, 145, 120)">manual </span><span class="colour" style="color:rgb(106, 153, 85)">手动</span> | 是 | 是 | 否 | 可读可写 | 最大长度32 |  |
| PushURLGeneratorServer | string | <span class="colour" style="color:rgb(106, 153, 85)">推流地址的服务器URL</span> | 是 | 是 | 否 | 可读可写 | 最大长度128 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/RTMP/BasicConfig` 

##### 请求方式

- put
