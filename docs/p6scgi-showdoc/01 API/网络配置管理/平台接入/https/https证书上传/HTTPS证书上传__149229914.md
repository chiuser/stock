# HTTPS证书上传
##### 简要描述
新增文件类型 eTransferHTTPSCertificationFile(36)， eTransferHTTPSCertificationKeyFile(37)，

新增接口实现HTTPS证书上传，支持同时上传两个文件

- ##### 请求

**请求示例**

```
POST /System/HTTPSCertificationUpload HTTP/1.1\r\n
Connection:close\r\n
Host: 192.168.3.166\r\n
Content-Length:\r\n
Content-Type: multipart/form-data; boundary=----WebKitFormBoundaryfG8m1GurwICxbdTW\r\n
\r\n
------WebKitFormBoundaryfG8m1GurwICxbdTW
Content-Disposition: form-data; name="certificationfile"; filename="certificationfile.pem"
Content-Type: application/octet-stream\r\n
\r\n
...
------WebKitFormBoundaryfG8m1GurwICxbdTW--
Content-Disposition: form-data; name="certificationkeyfile"; filename="certificationkeyfile.key"
Content-Type: application/octet-stream\r\n
\r\n
...
------WebKitFormBoundaryfG8m1GurwICxbdTW--
```
其中…表示的就是要上传的公有证书文件和密钥文件。

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| certificationfile | file | 证书文件 | 是 | 是 | 否 | 只写 |  |  |  |  |  |  |
| certificationkeyfile | file | 密钥文件 | 是 | 是 | 否 | 只写 |  |  |  |  |  |  ||


##### 响应
**xml**
无
**字段说明**
无
