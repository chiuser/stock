# HTTPS证书创建
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<HTTPSCertificateCreate>
    <Region><!--wo,opt,xs:string,max length 32--></Region>
    <Address><!--wo,req,xs:string,max length 256--></Address>
    <ValidityPeriod><!--wo,req,xs:integer,unit:day,range [1-5000]--></ValidityPeriod>
    <Province><!--wo,opt,xs:string,max length 64--></Province>
    <Location><!--wo,opt,xs:string,max length 128--></Location>
    <Organization><!--wo,opt,xs:string,max length 64--></Organization>
    <OrganizationUnit><!--wo,opt,xs:string,max length 128--></OrganizationUnit>
</HTTPSCertificateCreate>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Region | string | 设备所在区域 | 否 | 是 | 是 | 只写 | 最大长度32 |  |  |  |  |  |
| Address | string | 设备IP地址或域名 | 是 | 是 | 否 | 可读可写 | 最大长度256 |  |  |  |  |  |
| ValidityPeriod | integer | 证书有效期；单位：天，范围[1-5000]  | 是 | 是 | 否 | 可读可写 | 1-5000 |  |  |  |  |  ||
| Province | string | 设备所在省份 | 否 | 是 | 是 | 可读可写 | 最大长度64 |  |  |  |  |  |
| Location | string | 设备所在地址 | 否 | 是 | 是 | 可读可写 | 最大长度128 |  |  |  |  |  |
| Organization | string | 设备组织 | 否 | 是 | 是 | 可读可写 | 最大长度64 |  |  |  |  |  |
| OrganizationUnit | string | 设备组织单位 | 否 | 是 | 是 | 可读可写 | 最大长度128 |  |  |  |  |  |

##### 响应
**xml**
无
**字段说明**
无
