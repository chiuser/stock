# 设置FTP配置
##### 简要描述

- #### 以T5AI设备为例说明

**说明**
请不要频繁设置网络配置，因为设备端设置的网络配置是异步响应，所以如果经常设置，只响应第一个操作，建议时间间隔设置为3-5S。
   <TransferContentTypeMask>是一个掩码，如“00”，每个位代表一个选项，如果该位的值为“0”，则表示它被选中，否则，未选中，默认，从右到左， 第一位是“图像”，第二位是“视频”。
     当获取<FTP> XML时，<Password>字段不显示，如果设置时，没有<Password>，则密码不会更改，否则密码将被更改。

##### **请求**

_**xml**_

```
<?xml version="1.0" encoding="UTF-8" ?>
<FTP Version="1.0" xmlns="http://www.zwcloud.wang/ver10/XMLSchema">
    <Enable><!—rw,req,xs:boolean--></Enable>
    <UserName><!—rw,req,xs:string,  the max length: 32--></UserName>
    <Password><!--wo,opt,xs:string,  the max length: 32--></Password>
    <IPAddress><!—rw,req,xs:string,  the max length: 128--></IPAddress>
    <Port><!--rw,req,xs:integer--></Port>
    <TransferContentTypeMask><!—rw,req,xs:string,  the max length: 3--></TransferContentTypeMask>
    <FTPMode><!—rw,opt,xs:string,”Active, Passive”--></FTPMode>
    <StorageDirectory><!—rw,opt,xs:string,  the max length: 256--></StorageDirectory>
    <Status><!—ro,opt,xs:string, "not connect", "connected"--></Status>
</FTP>
```
