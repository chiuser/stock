# 获取FTP配置
##### 简要描述

- #### 以T5AI设备为例说明

**说明**
   <TransferContentTypeMask>是一个掩码，如“00”，每个位代表一个选项，如果该位的值为“0”，则表示它被选中，否则，未选中，默认，从右到左， 第一位是“图像”，第二位是“视频”。
     当获取<FTP> XML时，<Password>字段不显示

##### **请求**

**_xml_**
无
**_字段说明_**
无

##### **响应**

**_xml_**

```
<?xml version="1.0" encoding="UTF-8" ?>
<FTP Version="1.0" xmlns="http://www.zwcloud.wang/ver10/XMLSchema">
    <Enable><!—rw,req,xs:boolean--></Enable>
    <UserName><!—rw,req,xs:string,  the max length: 32--></UserName>
    <IPAddress><!—rw,req,xs:string,  the max length: 128--></IPAddress>
    <Port><!--rw,req,xs:integer--></Port>
    <TransferContentTypeMask><!—rw,req,xs:string,  the max length: 3--></TransferContentTypeMask>
    <FTPMode><!—rw,req,xs:string,”Active, Passive”--></FTPMode>
    <StorageDirectory><!—rw,req,xs:string,  the max length: 256--></StorageDirectory>
    <Status><!—rw,req,xs:string, "not connect", "connected"--></Status>
</FTP>
```
