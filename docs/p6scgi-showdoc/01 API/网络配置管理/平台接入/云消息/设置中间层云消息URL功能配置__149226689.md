# 设置中间层云消息URL功能配置
##### 简要描述

- ##### **请求**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<MPServerURLInfo Version="1.0">
    <ServerIpAndPort><!-- rw,opt,xs:string, the max length : 128--></ServerIpAndPort>
    <UrlPathTimeCheck><!-- rw,opt,xs:string, the max length : 128--></UrlPathTimeCheck>
    <UrlPathEventPolicy><!-- rw,opt,xs:string, the max length : 128--></UrlPathEventPolicy>
    <UrlPathEventPost><!-- rw,opt,xs:string, the max length : 128--></UrlPathEventPost>
    <UrlPathSetXmlStatus><!-- rw,opt,xs:string, the max length : 128--></UrlPathSetXmlStatus>
    <SrvMaintenance><!-- rw,opt,xs:string,the max length : 128--></SrvMaintenance>
</MPServerURLInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ServerIpAndPort | string | 服务器IP和端口 | 否 | 是 | 否 | 可读可写 | 最大长度128 |  |
| UrlPathTimeCheck | string | 时间校验url路径 | 否 | 是 | 是 | 可读可写 | 最大长度128 |  |
| UrlPathEventPolicy | string | 事件权限url路径 | 否 | 是 | 是 | 可读可写 | 最大长度128 |  |
| UrlPathEventPost | string | 事件推送url路径 | 否 | 是 | 是 | 可读可写 | 最大长度128 |  |
| UrlPathSetXmlStatus | string | 设置Xml状态的url路径 | 否 | 是 | 否 | 可读可写 | 最大长度128 |  |
| SrvMaintenance | string | 云运维服务器地址 | 否 | 是 | 否 | 可读可写 | 最大长度128 |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/P6SMPServerParam` 

##### 请求方式

- put
