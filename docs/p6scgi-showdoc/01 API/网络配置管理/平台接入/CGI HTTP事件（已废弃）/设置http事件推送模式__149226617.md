# 设置http事件推送模式
##### 简要描述

- ##### 请求

**xml**

```
<HttpEventMode>
    <Mode><!--rw,opt,xs:string,”V1”,”V2”, “Unknown”--></Mode>
</HttpEventMode>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Mode | string | http事件推送模式；V1 V1模式，V2 V2模式 | 否 | 是 | 否 | 可读可写 | 动态数组 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/HTTPEventPushMode` 

##### 请求方式

- put
