# 获取HTTP服务器状态信息
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<HttpEventServerStatus>
    <Status><!--rw,opt,xs:string,"online","offline"--></Status>
</HttpEventServerStatus>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Status | string | HTTP服务器状态；online在线，offline离线 | 否 | 是 | 否 | 可读可写 | 动态数组 |  ||

##### 请求URL

 - `/System/HTTPEventServerStatus` 

##### 请求方式

- get
