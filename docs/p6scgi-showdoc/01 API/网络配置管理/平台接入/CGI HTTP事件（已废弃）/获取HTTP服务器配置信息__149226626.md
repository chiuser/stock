# 获取HTTP服务器配置信息
##### 简要描述

- ##### 说明

仅部分设备支持

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<HttpEventServerCfg>
    <Enable><!--rw,opt,xs:boolean--></Enable>
    <Protocol><!--rw,opt,xs:string,"http","https"--></Protocol>
    <Host><!--rw,opt,xs:string,the max length is 256--></Host>
    <URLPath><!--rw,opt,xs:string,the max length is 256--></URLPath>
    <Port><!--rw,opt,xs:interger,default 80--></Port>
    <UserName><!--rw,opt,xs:string,the max length is 32--></UserName>
    <Password><!--rw,opt,xs:string,the max length is 32--></Password>
    <DataTransfer2ServerTimeout><!--rw,opt,xs:interger,default 3，the unit is second--></DataTransfer2ServerTimeout>
</HttpEventServerCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否使能，false-否，true-是</span> | 否 | 是 | 否 | 可读可写 | false/true |  |
| Protocol | string | <span class="colour" style="color:rgb(106, 153, 85)">协议；http表示http协议，https表示https协议（暂不支持）</span> | 否 | 是 | 否 | 可读可写 | 动态数组 |  |
| Host | string | <span class="colour" style="color:rgb(106, 153, 85)">服务器的地址，可以是IP地址，也可以是域名</span> | 否 | 是 | 否 | 可读可写 | 最大长度256 |  |
| URLPath | string | <span class="colour" style="color:rgb(106, 153, 85)">服务的URL路径</span> | 否 | 是 | 否 | 可读可写 | 最大长度256 |  |
| Port | integer | <span class="colour" style="color:rgb(106, 153, 85)">端口，默认为80</span> | 否 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(106, 153, 85)">默认为80</span> |  |
| UserName | string | <span class="colour" style="color:rgb(106, 153, 85)">服务器的用户名</span> | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| Password | string | <span class="colour" style="color:rgb(106, 153, 85)">服务器的密码</span> | 否 | 是 | 是 | 可读可写 | 最大长度32 |  |
| DataTransfer2ServerTimeout | integer | <span class="colour" style="color:rgb(106, 153, 85)">和服务器交互超时时间,单位是秒</span> | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  ||

##### 请求URL

 - `/System/HTTPEventServerConfig` 

##### 请求方式

- get
