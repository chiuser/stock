# 设置MQTT配置
##### 简要描述

- ##### 说明

<span class="colour" style="color:rgb(23, 43, 77)">URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。对于IPC，ChannelID恒为1</span>

##### 请求

**xml**

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<MQTTConfig Version="1.0">
    <Enable><!--rw,opt:boolean;false, true--></Enable>
    <DeviceID><!--rw,opt:string; max size 64--></DeviceID>
    <Address><!--rw,opt:string; max size 16--></Address>
    <Port><!--rw,opt:integer--></Port>
    <UserName><!--rw,opt:string; max size 64--></UserName>
    <PasswordV2><!--rw,opt:string; max size 64--></PasswordV2>
    <MainTopic><!--rw,opt:string; max size 128--></MainTopic>
    <OperateDevice><!--rw,opt:string; max size 128--></OperateDevice>
    <PublishEvent><!--rw,opt:string; max size 128--></PublishEvent>
    <ServerConnectState><!--rw,opt:integer;--></ServerConnectState>
    <IsConfigReadOnly><!--rw,opt:boolean;false, true;--></IsConfigReadOnly>
    <CacheEventEnable><!--rw,opt:boolean;false, true;--></CacheEventEnable>
</MQTTConfig>
```
