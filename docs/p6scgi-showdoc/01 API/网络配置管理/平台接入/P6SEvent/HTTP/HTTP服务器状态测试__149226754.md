# HTTP服务器状态测试
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<HTTPEventServerTest>
    <Test><!--wo,req,xs:string,the max length is 256--></Test>
</HTTPEventServerTest>
```

**字段说明**

| 字段 | 类型 | 说明 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Test | string | 自定义内容 | 是 | 是 | 是 | 只写 | 最大长度256 |  |  | <span class="colour" style="color: rgb(206, 145, 120);">配置-网络-平台接入-HTTP-测试</span> |  |  ||

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<HTTPEventServerTest>
    <StatusCode><!--ro,opt,xs:string,the max length is 32--></StatusCode>
    <EventID><!--ro,opt,xs:interger--></EventID>
    <Time><!--ro,opt,xs:string,the max length is 32--></Time>
    <Info><!--ro,opt,xs:string,the max length is 1024--></Info>
</HTTPEventServerTest>
```

**字段说明**

| 字段 | 类型 | 说明 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| ErrorCode | string | 服务器返回码 | 否 | 是 | 否 | 只读 | 最大长度32 |  |  | <span class="colour" style="color: rgb(206, 145, 120);">配置-网络-平台接入-HTTP-测试</span> |  |  |
| EventID | integer | 事件ID | 否 | 是 | 否 | 只读 | 从1递增 |  |  | <span class="colour" style="color: rgb(206, 145, 120);">配置-网络-平台接入-HTTP-测试</span> |  |  |
| Time | string | 时间 | 否 | 是 | 否 | 只读 | 最大长度32 |  |  | <span class="colour" style="color: rgb(206, 145, 120);">配置-网络-平台接入-HTTP-测试</span> |  |  |
