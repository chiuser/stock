# 版本说明
#### 版本说明
http服务器配置信息和http服务器状态信息有V1、V2两个版本，区别在版本的功能模块不同

#### V1版本
V1版本的http服务器配置信息 和 http服务器状态信息，在cgi协议内部实现，支持的http事件少、功能简单、时间较早，目前默认已不支持

#### V2版本
V2版本的http服务器配置信息 和 http服务器状态信息，单独拆分成p6sevent协议，支持的http事件多、功能丰富
