# 设置MQTT服务器配置信息
##### 简要描述

- ##### 说明

仅部分设备支持

##### 请求

**xml**

```
<MQTTServerConfig>
    <Enable><!--rw,opt,xs:boolean--></Enable>
    <DeviceID><!--rw,opt,xs:string,the max length is 64--></DeviceID>
    <ServerAddress><!--rw,opt,xs:string,domain or ip,the max length is 128--> </ServerAddress>
    <ServerPort><!--rw,opt,xs:interger--></ServerPort>
    <Direction><!--rw,opt,xs:string,"none,enter,exit"--></Direction>
    <ServerUserName><!--rw,opt,xs:string,the max length is 64--></ServerUserName>
    <ServerPassword><!--rw,opt,xs:string,the max length is 64--></ServerPassword>
    <MainTopic><!--rw,opt,xs:string,the max length is 128--></MainTopic>
</MQTTServerConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否启用mqtt服务器，false-否，true-是</span> | 否 | 是 | 否 | 可读可写 | false/true |  |
| DeviceID | string | <span class="colour" style="color:rgb(106, 153, 85)">Mqtt协议传输中，设备的唯一标记</span> | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| ServerAddress | string | <span class="colour" style="color:rgb(106, 153, 85)">Mqtt服务器地址，可以是IP，也可以是域名</span> | 否 | 是 | 否 | 可读可写 | 最大长度128 |  |
| ServerPort | integer | <span class="colour" style="color:rgb(106, 153, 85)">Mqtt协议服务端口</span> | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| Direction | string | <span class="colour" style="color:rgb(106, 153, 85)">出入口方向，none无方向，enter进入，exit退出</span> | 否 | 是 | 否 | 可读可写 | 动态数组 |  |
| ServerUserName | string | <span class="colour" style="color:rgb(106, 153, 85)">Mqtt服务器用户名</span> | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| ServerPassword | string | <span class="colour" style="color:rgb(106, 153, 85)">Mqtt服务器密码</span> | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| MainTopic | string | <span class="colour" style="color:rgb(106, 153, 85)">主的topic，可以用来获取和设置</span> | 否 | 是 | 否 | 可读可写 | 最大长度128 |  ||

**xml**
无
**字段说明**
无
