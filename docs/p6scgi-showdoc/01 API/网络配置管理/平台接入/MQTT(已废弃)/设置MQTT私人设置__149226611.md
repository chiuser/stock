# 设置MQTT私人设置
##### 简要描述

- ##### 请求

**xml**

```
<PrivateSettings>
    <PushSetting>
        <IsIncludeFace><!--rw,req,xs:boolean,”true”,”false”--></IsIncludeFace>
        <IsIncludeTemperature><!--rw,req,xs:boolean,”true”,”false”--></IsIncludeTemperature>
    </PushSetting>
    <LogSetting>
        <IsIncludeFace><!--rw,req,xs:boolean,”true”,”false”--></IsIncludeFace>
        <IsIncludeTemperature><!--rw,req,xs:boolean,”true”,”false”--></IsIncludeTemperature>

    <DisplaySetting>
        <IsIncludeFace><!--rw,req,xs:boolean,”true”,”false”--></IsIncludeFace>
        <IsIncludeTemperature><!--rw,req,xs:boolean,”true”,”false”--></IsIncludeTemperature>
    </DisplaySetting>
</PrivateSettings>
```
