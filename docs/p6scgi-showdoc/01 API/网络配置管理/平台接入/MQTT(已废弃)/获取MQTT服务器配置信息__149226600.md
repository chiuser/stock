# 获取MQTT服务器配置信息
##### 简要描述

- ##### 说明

仅部分设备支持

##### 请求

**xml**
无
**字段说明**
无

##### **响应**

**xml**

```
<MQTTServerConfig>
    <Enable><!--rw,req,xs:boolean--></Enable>
    <DeviceID><!--rw,req,xs:string,the max length is 64--></DeviceID>
    <ServerAddress><!--rw,req,xs:string,domain or ip,the max length is 128--> </ServerAddress>
    <ServerPort><!--rw,req,xs:interger--></ServerPort>
    <Direction><!--rw,req,xs:string,"none,enter,exit"--></Direction>
    <ServerUserName><!--rw,req,xs:string,the max length is 64--></ServerUserName>
    <ServerPassword><!--rw,req,xs:string,the max length is 64--></ServerPassword>
    <ConnectStatus><!--ro,req,xs:string,”init,success,erro_userorpassword,error_id_conflict,error_network_except ion,unknown"--></ConnectStatus>
    <MainTopic><!--rw,req,xs:string,the max length is 128 --></MainTopic>
    <OperateDeviceTopic><!--ro,req,xs:string,the max length is 128--> </OperateDeviceTopic>
    <PublicEventTopic><!--ro,req,xs:string,the max length is 128--> </PublicEventTopic>
</MQTTServerConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否启用mqtt服务器，false-否，true-是</span> | 是 | 是 | 否 | 可读可写 | false/true |  |
| DeviceID | string | <span class="colour" style="color:rgb(106, 153, 85)">Mqtt协议传输中，设备的唯一标记</span> | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |
| ServerAddress | string | <span class="colour" style="color:rgb(106, 153, 85)">Mqtt服务器地址，可以是IP，也可以是域名</span> | 是 | 是 | 否 | 可读可写 | 最大长度128 |  |
| ServerPort | integer | <span class="colour" style="color:rgb(106, 153, 85)">Mqtt协议服务端口</span> | 是 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| Direction | string | <span class="colour" style="color:rgb(106, 153, 85)">出入口方向，none无方向，enter进入，exit退出</span> | 是 | 是 | 否 | 可读可写 | 动态数组 |  |
| ServerUserName | string | <span class="colour" style="color:rgb(106, 153, 85)">Mqtt服务器用户名</span> | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |
| ServerPassword | string | <span class="colour" style="color:rgb(106, 153, 85)">Mqtt服务器密码</span> | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |
| ConnectStatus | string | <span class="colour" style="color:rgb(106, 153, 85)">连接服务器状态，init初始化状态 success成功，erro\_userorpassword用户名或密码错误，error\_id\_conflict ID冲突，error\_network\_exception网络异常，unknown其他未知错误</span> | 是 | 是 | 否 | 只读 | 动态数组 |  |
| MainTopic | string | <span class="colour" style="color:rgb(106, 153, 85)">主的topic，可以用来获取和设置</span> | 是 | 是 | 否 | 可读可写 | 最大长度128 |  |
| OperateDeviceTopic | string | <span class="colour" style="color:rgb(106, 153, 85)">设备操作topic，只读，用来显示</span> | 是 | 是 | 否 | 只读 | 最大长度128 |  |
| PublicEventTopic | string | <span class="colour" style="color:rgb(106, 153, 85)">事件推送topic，只读，用来显示</span> | 是 | 是 | 否 | 只读 | 最大长度128 |  ||
