# 设置设备GB28181安装信息
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**

```
<GB28181DeviceInstallInfoList>
    <GB28181DeviceInstallInfo>
        <Company><!--rw,opt,xs:string, the max length : 21--></Company>
        <TelNum><!--rw,opt,xs:string, the max length : 21--></TelNum>
        <InstallTime><!--rw,opt,xs:string, eg : 20210805T080102--></InstallTime>
        <LastMaintainTime><!--rw,opt,xs:string, eg : 20220906T090203--></LastMaintainTime>
        <InstallAddress><!--rw,opt,xs:string, the max length : 128--></InstallAddress>
    <GB28181DeviceInstallInfo>
</GB28181DeviceIntallInfoList>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| GB28181DeviceInstallInfo |  | 设备GB28181安装信息 | 否 | 是 |  |  |  |  |
| Company | string | 公司名称 | 否 | 是 | 是 | 可读可写 | 最大长度21 |  |
| TelNum | string | 公司电话号码 | 否 | 是 | 是 | 可读可写 | 最大长度21 |  |
| InstallTime | string | 安装时间 | 否 | 是 | 是 | 可读可写 | 最大长度14 |  |
| LastMaintainTime | string | 最后一次维护日期 | 否 | 是 | 是 | 可读可写 | 最大长度14 |  |
| InstallAddress | string | 安装地址 | 否 | 是 | 是 | 可读可写 | 最大长度128 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/ChannelID/GB28181DeviceInstallInfo` 

##### 请求方式

- put
