# 设置设备GB28181信息
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**

```
<GB28181DeviceInfo>
    <Country><!--rw,opt,xs:string, the max length : 32--></Country>
    <City><!--rw,opt,xs:string,the max  length : 32--></City>
    <Manaufacture><!--rw,opt,xs:string, the max length : 32--></Manaufacture>
    <Model><!--rw,opt,xs:string,the max  length : 32--></Model>
    <Owner><!--rw,opt,xs:string,the max  length : 32--></Owner>
    <Secrecy><!--rw,opt,xs:boolean--></Secrecy>
    <SafeMode><!--rw,opt,xs:integer, default : 0,  0:不采用; 2:S/MIME 签名方式; 3:S/MIME加密签名同时采用方式; 4:数字摘要方式--></SafeMode>
    <RegisterWay><!--rw,opt,xs:integer, default : 1, 1:符合IETFRFC3261标准的认证注册模式; 2:基于口令的双向认证注册模式; 3:基于数字证书的双向认证注册模式-->></RegisterWay>
</GB28181DeviceInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Country | string | 国家 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| City | string | 城市 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| Manaufacture | string | 生产商 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| Model | string | 型号 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| Owner | string | 设备归属 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| Secrecy | boolean | 保密属性；false：不涉密 true：涉密 | 否 | 是 | 否 | 可读可写 | false/true |  |
| SafeMode | <span class="colour" style="color:black">integer</span> | 信令安全模式；1：不采用2：S/MIME签名方式3：S和MIME解密签名同时采用4：数字摘要方式 | 否 | 是 | 否 | 可读可写 | 1/2/3/4 |  |
| RegisterWay | <span class="colour" style="color:black">integer</span> | 注册方式；1：符合IETFRFC3261标准的认证注册模式2：基于口令的双向认证注册模式3：基于数字证书的双向认证注册模式 | 否 | 是 | 否 | 可读可写 | 1/2/3 |  ||

##### 响应

**xml**
无
**字段说明**
无
