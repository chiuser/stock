# 设置云存储录像计划
##### 简要描述

- ##### 请求

<span class="colour" style="color:rgb(85, 85, 85)">**xml**</span>

```
<?xml version="1.0" encoding="utf-8"?>
<RecordPlan>
    <StreamMode><!—rw,req,xs:string”MainStream”,”SubStream”,”SecondSubStream”--></StreamMode>
    <RecordMode><!—rw,req,xs:string”ManualRecord”,”AutoRecord”,”CloseRecord”--></RecordMode>
    <TimeBlockList>
        <TimeBlock_0>111111111111111111111111111111111111111111111111</TimeBlock_0>
        <TimeBlock_1>111111111111111111111111111111111111111111111111</TimeBlock_1>
        <TimeBlock_2>111111111111111111111111111111111111111111111111</TimeBlock_2>
        <TimeBlock_3>111111111111111111111111111111111111111111111111</TimeBlock_3>
        <TimeBlock_4>111111111111111111111111111111111111111111111111</TimeBlock_4>
        <TimeBlock_5>111111111111111111111111111111111111111111111111</TimeBlock_5>
        <TimeBlock_6>111111111111111111111111111111111111111111111111</TimeBlock_6>
    </TimeBlockList>
    <EventTimeSlotList>
        <SchedTimeSlot>
            <ID><!—rw,req,xs:integer--></ID>
            <Enable><!—rw,req,xs:boolean, "fallse, true"--></Enable>
            <StartTime><!—rw,req,xs:string, the max length 32--></StartTime>
            <EndTime><!—rw,req,xs:string, the max length 32--></EndTime>
            <Weekday><!—rw,req,xs:string, the max length 8--></Weekday>
        </SchedTimeSlot>
    </EventTimeSlotList>
</RecordPlan>
```
