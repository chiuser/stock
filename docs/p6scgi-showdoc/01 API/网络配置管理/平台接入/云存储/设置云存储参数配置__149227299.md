# 设置云存储参数配置
##### 简要描述

- ##### **请求**

**XML**

```
<?xml version = "1.0" encoding = "utf-8"?>
<CloudStorageParamConfig Version="1.0">
    <CloudStorageSendMediaBufferLen><!--rw,opt,xs:interger,default 256--></CloudStorageSendMediaBufferLen>
    <CloudStorageAnnulusBufferLen><!--rw,opt,xs:interger,default 768--></CloudStorageAnnulusBufferLen>
    <CloudStorageSendDataRetryCount><!--rw,opt,xs:interger,default 2--></CloudStorageSendDataRetryCount>
    <CloudStorageSendMediaTimeout><!--rw,opt,xs:interger,default 10--></CloudStorageSendMediaTimeout>
    <CloudStorageSendIndexTimeout><!--rw,opt,xs:interger,default 10--></CloudStorageSendIndexTimeout>
    <CloudStorageOtherMyServerTimeout><!--rw,opt,xs:interger,default 10--></CloudStorageOtherMyServerTimeout>
</CloudStorageParamConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| CloudStorageSendMediaBufferLen | interger | <span class="colour" style="color:rgb(106, 153, 85)">云存储发送媒体缓冲区大小，该大小设置确保要大于I帧，默认是256，单位是Byte</span> | 否 | 是 | 否 | 可读可写 | 默认是256，[0-384] |  |
| CloudStorageAnnulusBufferLen | interger | <span class="colour" style="color:rgb(106, 153, 85)">云存储环形缓冲区大小，默认是768，建议环形缓冲区的大小至少是nCloudStorageSendMediaBufferLen的1.5倍，单位是Byte</span> | 否 | 是 | 否 | 可读可写 | 默认是768，[0-768] |  |
| CloudStorageSendDataRetryCount | interger | <span class="colour" style="color:rgb(106, 153, 85)">云存储媒体发送数据重试次数，默认为2次</span> | 否 | 是 | 否 | 可读可写 | 默认为2次，[0-5] |  |
| CloudStorageSendMediaTimeout | interger | <span class="colour" style="color:rgb(106, 153, 85)">云存储媒体发送超时时间，默认10秒，建议发送超时按每128KB/秒 + 1秒（抖动时间）进行设置，同时减少重试次数，单位是秒</span> | 否 | 是 | 否 | 可读可写 | 默认10秒，[0-300] |  |
| CloudStorageSendIndexTimeout | interger | <span class="colour" style="color:rgb(106, 153, 85)">云存储索引发送超时时间 ，默认10秒，因为索引文件相对大小比较固定，所以使用默认值即可，单位是秒</span> | 否 | 是 | 否 | 可读可写 | 默认10秒，[0-300] |  |
| CloudStorageOtherMyServerTimeout | interger | <span class="colour" style="color:rgb(106, 153, 85)">云存储服务与我们自己的服务器交互超时时间 ，默认10秒，单位是秒</span> | 否 | 是 | 否 | 可读可写 | 默认10秒，[0-300] |  ||
