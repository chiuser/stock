# 设置云存储基本配置
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<BaseConfig>
    <EnableStatus><!—rw,req,xs:string”true”,”false”--></EnableStatus>
</BaseConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| EnableStatus | boolean | <span class="colour" style="color:rgb(106, 153, 85)">开启/关闭云存储设备功能</span> | 是 | 是 | 否 | 可读可写 | false/true |  ||

##### 响应

**xml**
无
**字段说明**
无
