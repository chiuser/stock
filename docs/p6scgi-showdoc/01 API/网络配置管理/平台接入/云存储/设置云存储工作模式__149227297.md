# 设置云存储工作模式
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<CloudStorageWorkMode>
    <WorkMode><!—rw,opt,xs:string,”domestic,foreign”--></WorkMode>
</CloudStorageWorkMode>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| WorkMode | string | <span class="colour" style="color:rgb(106, 153, 85)">工作模式：</span>domestic<span class="colour" style="color:rgb(106, 153, 85)">,国内，</span>foreign<span class="colour" style="color:rgb(106, 153, 85)">，海外</span> | 否 | 是 | 否 | 可读可写 | 动态数组 |  ||

##### 响应

**xml**
无
**字段说明**
无

 - `/Network/CloudStorage/WorkMode`
