# 设置事件推送间隔配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<PushEventInterval Version="1.0">
    <Motion><!--rw,opt,xs:integer, in second--></Motion>
    <People><!--rw,opt,xs:integer, in second--></People>
    <AssistLine><!--rw,opt,xs:integer, in second--></AssistLine>
    <AlarmIn><!--rw,opt,xs:integer, in second--></AlarmIn>
    <Car><!--rw,opt,xs:integer, in second--></Car>
    <AreaDetect><!--rw,opt,xs:integer, in second--></AreaDetect>
    <CrossBorderDetect><!--rw,opt,xs:integer, in second--></CrossBorderDetect>
    <OffDutyDetect><!--rw,opt,xs:integer, in second--></OffDutyDetect>
    <PassgerStatics><!--rw,opt,xs:integer, in second--></PassgerStatics>
    <FireDetect><!--rw,opt,xs:integer, in second--></FireDetect>
    <CryScream><!--rw,opt,xs:integer, in second--></CryScream>
    <TrafficStatistics><!--rw,opt,xs:integer, in second--></TrafficStatistics>
</PushEventInterval>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Motion | integer | 移动侦测事件推送间隔，单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| People | integer | 人形跟踪事件推送间隔，单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| AssistantLine | integer | 拌线检测事件推送间隔，单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| AlarmIn | integer | 报警输入事件推送间隔，单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| Car | integer | 车形事件推送间隔，单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| AreaDetect | integer | 区域检测事件推送间隔，单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| CrossBorderDetect | integer | 越界侦测事件推送间隔，单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| OffDutyDetect | integer | 离岗侦测事件推送间隔，单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| PassgerStatics | integer | 客流统计事件推送间隔，单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| FireDetect | integer | 火焰检测事件推送间隔，单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| CryScream | integer | 哭声检测事件推送间隔，单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| TrafficStatistics | integer | 车流统计事件推送间隔，单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  ||
