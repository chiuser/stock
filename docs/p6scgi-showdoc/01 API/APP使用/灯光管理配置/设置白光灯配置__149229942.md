# 设置白光灯配置
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<WhiteLightEnable>
    <Enable><!--rw,opt,xs:boolean,"true,false"--></Enable>
</WhiteLightEnable>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">白光灯是否开启。false - 关闭； true - 开启</span> | 否 | 是 | 否 | 可读可写 | false/true |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/WhiteLightEnable` 

##### 请求方式

- put

```
[]
```
