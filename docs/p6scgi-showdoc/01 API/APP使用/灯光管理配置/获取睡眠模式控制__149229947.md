##### 简要描述

- ##### **请求**

**xml**
无
**字段说明**
无

##### **响应**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<DeviceSleepControl>
    <SleepControl><!--rw,opt,xs::interger,0,立即休眠，1，立即唤醒--></SleepControl>
```

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |

| SleepControl | integer | 0,立即休眠，1，立即唤醒<span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 0/1 |  ||
