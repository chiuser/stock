# 设置设备一键夜灯信息
##### 简要描述

- ##### **请求**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<NightLedInfo>
    <Enable><!--rw,opt,xs::boolean--></Enable>
    <Duration><!--rw,opt,xs::interger--></Duration>
</NightLedInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | false表示只设置配置，true表示用户在预览界面开启夜灯 | 否 | 是 | 否 | 可读可写 | false/true |  |
| Duration | integer | 亮灯持续时长 ,单位：秒 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/NightLedInfo` 

##### 请求方式

- put
 
##### 成功返回示例  
```
{}
```
