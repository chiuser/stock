# 设置勿扰模式配置
##### 简要描述

- ##### 请求

**xml**

```
<DoNotDisturbMode>
    <Enable><!--rw,opt,xs:boolean; "false","true"--></Enable>
    <Duration><!--rw,opt,xs:integer,单位：分钟--></Duration>
</DoNotDisturbMode>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | <span class="colour" style="color:rgb(0, 51, 102)">是否开启勿扰模式。</span>false <span class="colour" style="color:rgb(0, 51, 102)">\- 否，</span> true <span class="colour" style="color:rgb(0, 51, 102)">\- 是 </span> | 否 | 是 | 否 | 可读可写 | false/true |  |
| Duration | integer | <span class="colour" style="color:rgb(0, 51, 102)">勿扰模式持续时间（单位：分钟）</span> | 否 | 是 | 否 | 可读可写 | 取值范围需与设备确认 |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/DoNotDisturbMode` 

##### 请求方式

- put
