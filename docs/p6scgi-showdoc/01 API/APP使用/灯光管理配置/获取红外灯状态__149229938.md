# 获取红外灯状态
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<IRStatus>
    <ChannelID><!--ro,req,xs:Integer--></ChannelID>
    <ADCValue><!--ro,req,xs:Integer--></ADCValue>
</IRStatus>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ChannelID | integer | 通道ID，自1递增 | 是 | 是 | 否 | 只读 | [1-32] |  |
| ADCValue | integer | 红外灯状态值 | 是 | 是 | 否 | 只读 | 取值需与设备确认 |  ||

##### 请求URL

 - `/System/ChannelID/IRStatus` 

##### 请求方式

- get
