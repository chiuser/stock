# 设置看护位属性配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**

```
<WatchCarePresetAttribute>
    <WatchCareIndex><!--rw,opt,xs:integer, Start increasing from 0--></WatchCareIndex>
    <ReturnTime><!--rw,opt,xs:integer, default 15， range [10-30] --></WatchCareEnable>
</WatchCarePresetAttribute>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| WatchCareIndex | integer | 看守位编号，[0-255] | 否 | 是 | 否 | 可读可写 | [0-255] |  |
| ReturnTime | integer | 回归看守位时间；单位秒，默认15s，范围[10-30] | 否 | 是 | 否 | 可读可写 | 默认15s，范围[10-30] |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/PTZ/ChannelID/WatchCarePresetAttribute` 

##### 请求方式

- put

{}
