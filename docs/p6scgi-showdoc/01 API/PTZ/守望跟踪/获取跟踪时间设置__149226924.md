# 获取跟踪时间设置
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<PTZTrackTimeSlot>
    <EventTimeSlotList>
        <SchedTimeSlot>
            <ID><!--rw,req,xs:integer"--></ID>
            <Enable><!--rw,req,xs:boolean,"true","false"--></Enable>
            <StartTime><!--rw,req,xs:string,"hh:mm"--></StartTime>
            <EndTime><!--rw,req,xs:string,"hh:mm"--></EndTime>
            <Weekday><!--rw,req,xs:string--></Weekday>
          </SchedTimeSlot>
    </EventTimeSlotList>
</PTZTrackTimeSlot>
```
