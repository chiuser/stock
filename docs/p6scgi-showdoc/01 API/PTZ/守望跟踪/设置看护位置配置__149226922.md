# 设置看护位置配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**

```
<WatchCarePreset>
    <Preset><!--rw,opt,xs:integer, Start increasing from 0--></Preset>
    <Type><!--rw,opt,xs:string, "preset,watchCare"--></Type>
    <WatchCareEnable><!--rw,opt,xs:boolean, "true,false"--></WatchCareEnable>
</WatchCarePreset>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| <span class="colour" style="color:black">Preset</span> | integer | 预置点编号，[0-255] | 否 | 是 | 否 | 可读可写 | [0-255] |  |
| <span class="colour" style="color:rgb(0, 0, 0)">Type</span> | string | 点类型；preset表示以Preset对应的预置点为看守位(旧版本设备)，watchCare表示独立的看守位(新版本设备，此时Preset表示看守位编号，目前仅有一个看守位可忽略) | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| <span class="colour" style="color:rgb(0, 0, 0)">WatchCareEnable</span> | boolean | 是否使能看守位(新版本设备Type为watchCare时有效) | 否 | 是 | 否 | 可读可写 | false/true |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/PTZ/ChannelID/WatchCarePreset` 

##### 请求方式

- put
