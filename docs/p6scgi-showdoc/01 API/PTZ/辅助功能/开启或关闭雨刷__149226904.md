# 开启或关闭雨刷
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。<ChannelID>从1开始.
有一个参数是“Param1”，如果“Param1”是“1”，它存在打开，否则，它存在关闭，

##### 示例

URL：[http://192.168.1.46/PTZ/1/RainBrush](http://192.168.1.46/PTZ/1/RainBrush)

##### http示例

```
PUT /PTZ/1/RainBrush HTTP/1.1\r\n
Connection:close\r\n
Host: 192.168.0.46\r\n
Content-Length:\r\n
\r\n
Param1=1
```
