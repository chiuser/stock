# 设置云台高级配置信息
##### 简要描述

| 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| ---------------- | ---------------- | ---------- | --------- |
|  | <span class="colour" style="color: rgb(206, 145, 120);">web没有调用</span> |  |  ||

##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**

```
<PTZAdvance>
    <CruiseEnable><!--rw,req,xs:boolean,”true,false”--></CruiseEnable>
    <BeginPresetNumForCruise><!--rw,req,xs:interger--></BeginPresetNumForCruise>
    <BeginPresetActionForCruise><!--rw,req,xs:string, "none, set, call, clear"--></BeginPresetActionForCruise>
    <EndPresetNumForCruise><!--rw,req,xs:interger--></EndPresetNumForCruise>
    <EndPresetActionForCruise><!--rw,req,xs:string, "none, set, call, clear"--></EndPresetActionForCruise>
    <WatchEnable><!--rw,req,xs: boolean,”true,false”--></WatchEnable>
    <BeginPresetNumForWatch><!--rw,req,xs:interger--></BeginPresetNumForWatch>
    <BeginPresetActionForWatch><!--rw,req,xs:string, "none, set, call, clear"--></BeginPresetActionForWatch>
    <EndPresetNumForWatch><!--rw,req,xs:interger--></EndPresetNumForWatch>
    <EndPresetActionForWatch><!--rw,req,xs:string, "none, set, call, clear"--></EndPresetActionForWatch>
    <TrackEnable><!--rw,req,xs: boolean,”true,false”--></TrackEnable>
    <BeginPresetNumForTrack><!--rw,req,xs:interger--></BeginPresetNumForTrack>
    <BeginPresetActionForTrack><!--rw,req,xs:string, "none, set, call, clear"--></BeginPresetActionForTrack>
    <EndPresetNumForTrack><!--rw,req,xs:interger--></EndPresetNumForTrack>
    <EndPresetActionForTrack><!--rw,req,xs:string, "none, set, call, clear"--></EndPresetActionForTrack>
</PTZAdvance>
```
