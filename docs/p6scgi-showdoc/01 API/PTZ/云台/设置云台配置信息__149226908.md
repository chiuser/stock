# 设置云台配置信息
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
<WatchMode>表示在几秒钟后开始观看。<WatchMode>的值为秒。
<PTZActionID>的值为0,1 ....，该值的范围取决于<PTZActionType>的值，如果<PTZActionType>为“preset”，则范围为0-15，如果<PTZActionType >是“巡航”或“跟踪”，<PTZActionID>的值必须为0。
<Protocol>的值必须是<PTZProtocolList>中<ProtocolName> int的值之一。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<PTZConfigChannel>
    <Enable><!--rw,req,xs:bool--></Enable>
    <Address><!—-rw,req,xs:string--></Address>
    <Bitrate><!—req,xs:string--></Bitrate>
    <Protocol><!—-rw,req,xs:string, the max length: 48--></Protocol>
    <Speed><!--rw,opt,xs:integer--></Speed>
    <PTZWatch>
        <Enable><!--rw,req,xs:boolean--></Enable>
        <WatchMode><!--rw,req,xs:integer,in second--></WatchMode>
        <PTZActionType><!--rw,req,xs:string,”preset,cruise,track”--></PTZActionType>
        <PTZActionID><!--rw,req,xs:integer--></PTZActionID>
    </PTZWatch>
    <PTZProtocolList>
        <ProtocolCount><!--rw,req,xs:string--></ProtocolCount>
        <PTZProtocol>
            <ProtocolName><!--rw,req,xs:string, the max length: 48--></ProtocolName>
        </PTZProtocol>
    </PTZProtocolList>
</PTZConfigChannel>
```
