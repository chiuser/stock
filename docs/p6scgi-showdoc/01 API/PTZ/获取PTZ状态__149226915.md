# 获取PTZ状态
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<PTZStatus>
    <ChannelID><!—-ro.req,xs:integer--></ChannelID>
    <Status><!—-ro.req,xs:string, 0 - "Running", 1 - "ArriveBottomLimit", 2 - "ArriveTopLimit"--></Status>
</PTZStatus>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ChannelID | integer | 通道ID，从1递增 | 是 | 是 | 是 | 只读 | 从1递增 |  |
| Status | string | 状态；<span class="colour" style="color:rgb(206, 145, 120)">Running</span>运行中，<span class="colour" style="color:rgb(206, 145, 120)">ArriveBottomLimit</span>到达下限，<span class="colour" style="color:rgb(206, 145, 120)">ArriveTopLimit</span>到达上限，<span class="colour" style="color:rgb(206, 145, 120)">Stop</span>停止 | 是 | 是 | 否 | 只读 | 最大长度32 |  ||

##### 请求URL

 - `/PTZ/ChannelID/Status` 

##### 请求方式

- get
