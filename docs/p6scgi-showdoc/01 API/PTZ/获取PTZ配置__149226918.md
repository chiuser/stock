# 获取PTZ配置
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<PTZConfig>
    <PTZConfigChannel>
        <Enable><!--rw,req,xs:string--></Enable>
        <Address><!—-rw,req,xs:interger--></Address>
        <Bitrate><!—-rw,req,xs:interger--></Bitrate>
        <Protocol><!--rw,req,xs:string, the max length : 48--></Protocol>
        <Speed><!--rw,opt,xs:integer--></Speed>
        <PTZProtocolList>
            <ProtocolCount><!—-rw,req,xs:interger--></ProtocolCount>
            <PTZProtocol>
                <ProtocolName><!--rw,req,xs:string, the max length : 48--></ProtocolName>
            </PTZProtocol>
        </PTZProtocolList>
        <PTZWatch>
            <Enable><!--rw,req,xs:string”true”,”false”--></Enable>
            <WatchMode><!—-rw,req,xs:interger--></WatchMode>
            <PTZActionType><!--rw,req,xs:string, "preset, cruise, track"--></PTZActionType>
            <PTZActionID><!—-rw,req,xs:interger--></PTZActionID>
        </PTZWatch>
    </PTZConfigChannel>
</PTZConfig>
```
