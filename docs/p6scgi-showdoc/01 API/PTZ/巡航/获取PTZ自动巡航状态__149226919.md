# 获取PTZ自动巡航状态
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<PTZCuriseStatus>
    <ChannelID><!--ro,opt,xs:interger--></ChannelID>
    <Enable><!--ro,opt,xs:boolean,”true”,”false”--></Enable>
</PTZCuriseStatus>
```

**字段说明**

| 字段说明 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| ---- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ChannelID | integer | 通道ID | 否 | 是 | 否 | 只读 | [1-32] |  |
| Enable | boolean | 是否使能配置；false 否，true 是 | 否 | 是 | 否 | 只读 | false/true |  ||

##### 请求URL

 - `/PTZ/ChannelID/CuriseStatus`
