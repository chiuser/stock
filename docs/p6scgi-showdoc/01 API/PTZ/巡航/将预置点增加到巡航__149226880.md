# 将预置点增加到巡航
##### 简要描述

| 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| ---------------- | ---------------- | ---------- | --------- |
|  | <span class="colour" style="color: rgb(206, 145, 120);">web没有调用</span> |  |  ||

##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
 有四个参数：
参数“Param1” 巡航号.范围是 0—15.
参数“Param2” 预置点, 范围是 0--127
参数“Param3” 停留时间.时间单位是秒.
参数“Param4” 移动速度,范围是 1-10.

##### 示例

URL：[http://192.168.1.46/PTZ/1/Cruise/AddPresetToCruise](http://192.168.1.46/PTZ/1/Cruise/AddPresetToCruise)

##### http示例

```
PUT /PTZ/1/Cruise/AddPresetToCruise HTTP/1.1\r\n
Connection:close\r\n
Host: 192.168.0.46\r\n
Content-Length:\r\n
\r\n
Param1=1&Param2=1&Param3=1&Param4=1
```

##### 请求URL

 - `/PTZ/ChannelID/Cruise/AddPresetToCruise` 

##### 请求方式

- put
 
##### 成功返回示例  
```
{}
```
