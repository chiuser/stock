# 获取设备数字倍数
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<DeviceDigitalMultiple>
    <DigitalMultiple><!--rw,opt,xs:integer--></DigitalMultiple>
    <DigitalMultipleDouble><!--rw,opt,xs:double--></DigitalMultipleDouble>
    <DeviceDigitalMultipleType><!--rw,opt,xs:integer--></DeviceDigitalMultipleType>
    <IPCSupportedBoardDigitalMaxMultiple><!--rw,opt,xs:float--></IPCSupportedBoardDigitalMaxMultiple>
    <CustomBoardDigitalMaxMultiple><!--rw,opt,xs:float--></CustomBoardDigitalMaxMultiple>
</DeviceDigitalMultiple>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| DigitalMultiple | integer | <span class="colour" style="color:rgb(106, 153, 85)">数字变倍倍数，DeviceDigitalMultipleType=0时有效</span> | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| DigitalMultipleDouble | double | <span class="colour" style="color:rgb(106, 153, 85)">数字变倍倍数(浮点)，DeviceDigitalMultipleType=0时有效</span> | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| DeviceDigitalMultipleType | integer | <span class="colour" style="color:rgb(106, 153, 85)">数字变倍倍数类型,当前数字变倍倍数是使用小数还是是整数; 0-整数,1-小数(浮点)</span> | 否 | 是 | 否 | 可读可写 | 0/1 |  |
| IPCSupportedBoardDigitalMaxMultiple | float | <span class="colour" style="color: rgb(106, 153, 85);">IPC支持的机芯数字变倍最大倍数, 类似设备能力, 表示设备能支持的最大倍数</span> | 否 | 是 | 否 | 可读可写 | [0-10] |  |
| CustomBoardDigitalMaxMultiple | float | <span class="colour" style="color: rgb(106, 153, 85);">定制的机芯数字变倍最大倍数（小于等于IPCSupportedBoardDigitalMaxMultiple）,表示设备当前可以使用的最大倍数,可以通过EasyVMS修改</span> | 否 | 是 | 否 | 可读可写 | <span class="colour" style="color: rgb(106, 153, 85);">小于等于IPCSupportedBoardDigitalMaxMultiple</span> |  ||

##### 请求URL

 - `/System/DeviceDigitalMultiple` 

##### 请求方式

- get
