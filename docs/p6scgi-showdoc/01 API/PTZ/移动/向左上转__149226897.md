# 向左上转
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。<ChannelID>从1开始。
  有两个参数。 第一个参数的名称是“Param1”，第二个参数的名称是“Param2”，如果“Param1”是“1”，表示开始，否则，表示停止，“Param2” 是速度，值的范围是1-10，

##### 示例

URL：[http://192.168.1.46/PTZ/1/TurnUpLeft](http://192.168.1.46/PTZ/1/TurnUpLeft)

##### http示例

```
PUT /PTZ/1/TurnDown HTTP/1.1\r\n
Connection:close\r\n
Host: 192.168.0.46\r\n
Content-Length:\r\n
\r\n
Param1=1&Param2=3
```
