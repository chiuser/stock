# 开始轨迹
##### 简要描述

| 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| ---------------- | ---------------- | ---------- | --------- |
|  | <span class="colour" style="color: rgb(206, 145, 120);">web没有调用</span> |  |  ||

##### 说明

URI中的<ChannelID>显示通道编号。<ChannelID>从1开始。

##### 示例

URL：[http://192.168.1.46/PTZ/1/Track/StartTrack](http://192.168.1.46/PTZ/1/Track/StartTrack)

##### http示例

```
PUT /PTZ/1/Track/StartTrack HTTP/1.1\r\n
Connection:close\r\n
Host: 192.168.0.46\r\n
Content-Length:\r\n
\r\n
Param1=1
```

##### 请求URL

 - `/PTZ/ChannelID/Track/StartTrack` 

##### 请求方式

- put
 
##### 成功返回示例  
```
{}

```
