# 设置车位配置
##### 简要描述

- ##### 请求

**xml**

```
<ParkingSpaceCfg>
    <Enable><!--rw,opt,xs:boolean,是否启用--></Enable>
    <CarFrame><!--rw,opt,xs:boolean,是否启用--></CarFrame>
    <CarPlateFrame><!--rw,opt,xs:boolean,是否启用--></CarPlateFrame>
    <DebugInfo><!--rw,opt,xs:boolean,是否启用--></DebugInfo>
    <ShowSchedFrame><!--rw,opt,xs:boolean,是否启用--></ShowSchedFrame>
    <ParkingSpaceList>
        <ParkingSpaceInfo>
            <Enable><!--rw,req,xs:boolean,是否启用--></Enable>
            <ParkingSpaceName><!-- rw,req,xs:string,车位名字, the max length : 32--></ParkingSpaceName>
            <ParkingSpaceNumber><!-- rw,req,xs:interger,车位序号--></ParkingSpaceNumber>
            <GroundLockID><!-- rw,req,xs:string,地锁ID, the max length : 32--></GroundLockID>
            <Polygon>
                <Point>
                    <ID><!--rw,req,xs:integer,0-7--></ID>
                    <PosX><!--rw,req,xs:interger,”0-10000”--></PosX>
                    <PosY><!--rw,req,xs:interger,”0-10000”--></PosY>
                </Point>
            </Polygon>
        </ParkingSpaceInfo>
       ...
    <ParkingSpaceList>
</ParkingSpaceCfg>
```
