# 设置数字哨兵平台设备配置信息
##### 简要描述

- ##### **请求**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<SZSBPlatformDeviceCfgInfo>
    <SceneAccount><!--rw,opt,xs:string,max size 64--></SceneAccount>
    <SceneCategory><!--rw,opt,xs:string,max size 8--></SceneCategory>
    <SceneType><!--rw,opt,xs:string,max size 8--></SceneType>
</SZSBPlatformDeviceCfgInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| SceneAccount | string | 场所编码，例:123 | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| SceneCategory | string | 场所一级分类，例:1002,详见《SZSB平台接入规范V1.1-达式》附录中 场景分类 | 否 | 是 | 否 | 可读可写 | 最大长度8 |  |
| SceneType | string | 场所二级分类，例:1018，详见《SZSB平台接入规范V1.1-达式》附录中 场景分类 | 否 | 是 | 否 | 可读可写 | 最大长度8 |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/SZSBPlatformDeviceCfgInfo` 

##### 请求方式

- put
