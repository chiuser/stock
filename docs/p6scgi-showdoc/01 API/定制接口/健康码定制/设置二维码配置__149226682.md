# 设置二维码配置
##### 简要描述

- ##### **请求**

**xml**

```
<QRCodeConfigure>
    <QRCodeIdentySwitch><!-- rw,opt,xs:boolean,”true”,”false”--></QRCodeIdentySwitch>
    <QRCodeUnrepeatInterval><!--rw,opt,xs:integer,2s-30s，default 10--></QRCodeUnrepeatInterval>
</QRCodeConfigure>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| QRCodeIdentySwitch | boolean | 二维码识别开关,true-开,false-关 | 否 | 是 | 否 | 可读可写 | false/true |  |
| QRCodeUnrepeatInterval | integer | 二维码去重间隔时间,2~30秒，默认10秒 | 否 | 是 | 否 | 可读可写 | [2,30] |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/QRCodeConfigure` 

##### 请求方式

- put
 
##### 成功返回示例  
```
{}

```
