# 设置健康码设备和平台信息
##### 简要描述

- ##### **请求**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<HealthCodeDeviceAndPlatInfo Version="1.0">
    <RegionID><!--rw,opt,xs:string,max size 64--></RegionID>
    <GuardID><!--rw,opt,xs:string,max size 64--></GuardID>
    <VillageCode><!--rw,opt,xs:string,max size 64--></VillageCode>
    <ServerAddress><!--rw,opt,xs:string,max size 256--></ServerAddress>
    <token><!--rw,opt,xs:string,max size 64--></token>
    <AppKey><!--rw,opt,xs:string,max size 64--></AppKey>
    <IV><!--rw,opt,xs:string,max size 64--></IV>
</HealthCodeDeviceAndPlatInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| RegionID | string | 封闭区域ID | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| GuardID | string | 门禁ID | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| VillageCode | string | 小区编码 | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| ServerAddress | string | 服务器域名或ip地址、端口 | 否 | 是 | 否 | 可读可写 | 最大长度256 |  |
| token | string | Token | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| AppKey | string | Appkey | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| IV | string | 秘钥偏移量 | 否 | 是 | 否 | 可读可写 | 最大长度64 |  ||

无
