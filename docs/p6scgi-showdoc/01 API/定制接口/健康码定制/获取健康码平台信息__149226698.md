##### **响应**

**xml**

```

<JKMPlatformCfgInfo Version="1.0">
```

| ServerIPAddress | string | 服务器域名或IP | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 最大长度256 |  |
