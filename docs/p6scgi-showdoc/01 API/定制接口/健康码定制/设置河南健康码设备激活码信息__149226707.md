# 设置河南健康码设备激活码信息
##### 简要描述

- ##### **请求**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<HeNanHealthCodeDeviceCDKEYInfo Version="1.0">
    <CDKEY><!--rw,opt,xs:string,max size 128--></CDKEY>
</HeNanHealthCodeDeviceCDKEYInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| CDKEY | string | 激活码 | 否 | 是 | 否 | 可读可写 | 最大长度128 |  ||

##### **响应**

**xml**
无
**字段说明**
无
