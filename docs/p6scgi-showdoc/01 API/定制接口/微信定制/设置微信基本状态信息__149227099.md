# 设置微信基本状态信息
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<WeChatBasicStatus>
    <ImportStatus><!--rw,-opt,xs:boolean,”true”,”false”--></ImportStatus>
    <ActiveStatus><!--rw,opt,xs:boolean,”true”,”false”--></ActiveStatus>
</WeChatBasicStatus>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ImportStatus | boolean | 是否开启导入状态；false 否，true 是 | 否 | 是 | 否 | 可读可写 | false/true |  |
| ActiveStatus | boolean | 是否开启激活状态；false 否，true 是 | 否 | 是 | 否 | 可读可写 | false/true |  |  |

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/WeChat/ChannelID/BasicStatus` 

##### 请求方式

- put

{}
