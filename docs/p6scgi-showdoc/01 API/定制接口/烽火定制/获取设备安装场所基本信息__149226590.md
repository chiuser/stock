# 获取设备安装场所基本信息
##### 简要描述

- ##### 说明

仅烽火定制设备支持

SiteName：车牌号码
SiteAddr：详细地址（包括省市区县路/弄号，即车辆始发站地址或部署场所地址）
DevName：一般为车牌号+设备安装位置
DevAddr：设备地址，设备步数位置信息，如果同一个位置部署了多台设备，请在后面用序号区别开来

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<CameraLocationInfo>
    <SiteName><!--rw,opt,xs:string, the max  length : 256--></SiteName>
    <SiteAddr><!--rw,opt,xs:string,  the max length : 256--></SiteAddr>
    <DevName><!--rw,opt,xs:string, the max  length : 256--></DevName>
    <DevAddr><!--rw,opt,xs:string,  the max length : 256--></DevAddr>
</CameraLocationInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| SiteName | string | 车牌号码 | 否 | 是 | 否 | 可读可写 | 最大长度256 |  |
| SiteAddr | string | 详细地址（包括省市区县路/弄号，即车辆始发站地址或部署场所地址） | 否 | 是 | 否 | 可读可写 | 最大长度256 |  |
| DevName | string | 一般为车牌号+设备安装位置 | 否 | 是 | 否 | 可读可写 | 最大长度256 |  |
| DevAddr | string | 设备地址，设备步数位置信息，如果同一个位置部署了多台设备，请在后面用序号区别开来 | 否 | 是 | 否 | 可读可写 | 最大长度256 |  ||

##### 请求URL

 - `/System/FiberHomeLocationInfo` 

##### 请求方式

- get
