# 设置摄像头所在地区码
##### 简要描述

- ##### 说明

仅烽火定制设备支持

AreaCode：地区码

##### 请求

**xml**

```
<AreaCodeInfo>
    <AreaCode><!--rw,req,xs:string,  the max length : 128--></AreaCode>
</AreaCodeInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| AreaCode | string | 地区码 | 是 | 是 | 否 | 可读可写 | 最大长度128 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/FiberHomeAreaCodeInfo` 

##### 请求方式

- put

{}
