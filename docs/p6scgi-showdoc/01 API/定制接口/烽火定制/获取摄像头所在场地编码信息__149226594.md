# 获取摄像头所在场地编码信息
##### 简要描述

- ##### 说明

仅烽火定制设备支持

LocationID：摄像头所在场地编码信息

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<LocationIDInfo>
    <LocationID><!--rw,opt,xs:string, the max  length : 32--></LocationID>
</LocationIDInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| LocationID | string | 摄像头所在场地编码信息 | 否 | 是 | 是 | 可读可写 | 最大长度32 |  ||

##### 请求URL

 - `/System/FiberHomeLocationID` 

##### 请求方式

- get

```
[]

```
