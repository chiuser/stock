# 获取摄像头基本信息
##### 简要描述

- ##### 说明

仅烽火定制设备支持
ManufactureID：厂商信息
DevMod：摄像头型号
DetailID：详细编号    格式：固定编号（7位）- 自定义编号（2位）  eg:13001SN-01

##### 请求

**xml**
无
**字段说明**
无

##### **响应**

**xml**

```
<CameraBaseInfo>
    <ManufactureID><!--rw,opt,xs:string,the max   length : 32--></ManufactureID>
    <DevMod><!--rw,opt,xs:string,the max   length : 32--></DevMod>
    <DetailID><!--rw,opt,xs:string, the max  length : 32, eg: 13001SN-01--></DetailID>
</CameraBaseInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ManufactureID | string | <span class="colour" style="color:rgb(106, 153, 85)">厂商信息</span> | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| DevMod | string | <span class="colour" style="color:rgb(106, 153, 85)">摄像头型号</span> | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| DetailID | string | <span class="colour" style="color:rgb(106, 153, 85)">详细编号        格式：固定编号(7位)-自定义编号(2位) eg:13001SN-01</span> | 否 | 是 | 否 | 可读可写 | 最大长度32 |  ||
