# 设置摄像头数据中心服务器信息
##### 简要描述

- ##### 说明

仅烽火定制设备支持

DataCenterServer：数据中心服务器信息

##### 请求

**xml**

```
<DataCenterServerInfo>
    <DataCenterServer><!--rw,req,xs:string, the max  length : 64--></DataCenterServer>
</DataCenterServerInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| DataCenterServer | string | 数据中心服务器信息 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/FiberHomeDataCenterServer` 

##### 请求方式

- put

{}
