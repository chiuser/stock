# 获取中心控制服务器配置
##### 简要描述

- ##### 说明

仅烽火定制设备支持

CtrlChnlServer：中心控制服务器信息

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<CtrlChnlServerInfo>
    <CtrlChnlServer><!--rw,opt,xs:string,  the max length : 64--></CtrlChnlServer>
</CtrlChnlServerInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| CtrlChnlServer | string | 中心控制服务器信息 | 否 | 是 | 否 | 可读可写 | 最大长度64 |  ||

##### 请求URL

 - `/System/FiberHomeCtrlChnlServer` 

##### 请求方式

- get

```
[]
```
