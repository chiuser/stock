# 获取长视设备配置
##### 简要描述

- ##### 说明

仅长视定制设备支持

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<LongSeeDeviceInfo>
    <MacAddress><!--rw,req,xs:string, the max  length : 18--></MacAddress>
    <SerialNum><!--rw,req,xs:string, the max  length : 18--></SerialNum>
</LongSeeDeviceInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| MacAddress | string | MAC地址 | 是 | 是 | 否 | 可读可写 | 最大长度18 |  |
| SerialNum | string | 序列号 | 是 | 是 | 否 | 可读可写 | 最大长度18 |  ||

##### 请求URL

 - `/System/LongSeeDeviceConfig` 

##### 请求方式

- get
