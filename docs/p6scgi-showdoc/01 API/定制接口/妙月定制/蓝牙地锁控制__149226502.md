# 蓝牙地锁控制
##### 简要描述

- ##### **请求**

**xml**

```
<GroundLockControl>
    <GroundLockID><!-- wo,opt,xs:string,地锁 ID, the max length : 32--></GroundLockID>
    <Command><!-- wo,opt,xs:integer,地锁控制， 0 - 落下，1 - 升起--></Command>
</GroundLockControl>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| GroundLockID | string | <span class="colour" style="color:rgb(106, 153, 85)">地锁 ID</span> | 否 | 是 | 否 | 只写 | 最大长度32 |  |
| Command | integer | <span class="colour" style="color:rgb(106, 153, 85)">地锁控制命令，0 - 落下； 1 - 升起； 2 - 获取地锁状态</span> | 否 | 是 | 否 | 只写 | 0/1/2 |  ||
