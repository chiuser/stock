# 获取蓝牙地锁车位配置
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<ParkingSpaceCfg>
    <LeftParkingSpace>
        <Enable><!--rw,req,xs:boolean,是否启用--></Enable>
        <Name><!-- rw,req,xs:string,车位名字，the max length : 32--></Name>
        <GroundLockID><!-- rw,req,xs:string,地锁 ID，the max length : 32--></GroundLockID>
        <GroundLockKey><!-- rw,req,xs:string,地锁 Key，the max length : 32--></GroundLockKey>
        <MAC><!-- rw,req,xs:string,MAC 地址，the max length : 16--></MAC>
    </LeftParkingSpace>
    <RightParkingSpace>
        <Enable><!--rw,req,xs:boolean,是否启用--></Enable>
        <Name><!-- rw,req,xs:string,车位名字，the max length : 32--></Name>
        <GroundLockID><!-- rw,req,xs:string,地锁 ID，the max length : 32--></GroundLockID>
        <GroundLockKey><!-- rw,req,xs:string,地锁 Key，the max length : 32--></GroundLockKey>
        <MAC><!-- rw,req,xs:string,MAC 地址，the max length : 16--></MAC>
    </RightParkingSpace>
</ParkingSpaceCfg>
```
