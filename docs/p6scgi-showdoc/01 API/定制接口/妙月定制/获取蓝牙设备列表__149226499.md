##### 响应

**xml**

```
<BTDeviceList>
    <DeviceInfo>
        <DeviceName><!--ro,req, xs:string,设备名称, the max length : 32--></DeviceName>
        <DeviceStatus><!-- ro,req,xs:integer,设备状态， 0 - 落下，1 - 升起--></DeviceStatus>
```
