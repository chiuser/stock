##### 简要描述

- ##### 请求

**xml**

```
<ParkingSpaceBasicCfg>
    <ChargingStationNum><!-- rw,opt,xs:string,充电场站编号， the max length : 32--></ChargingStationNum>
    <DeviceName><!-- rw,opt,xs:string,设备名称， the max length : 32--></DeviceName>
```
