# 设置CUIOT事件间隔和其它设置
##### 简要描述

- ##### 说明

当<IdentifyEventsRespReply>为“true”时，<SameEventUploadInterval>有效

##### **请求**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<CUIOTEventIntervalAndOtherSettingsCfg>
    <CUIOTHeartBeatInterval><!--rw,opt,xs:integer,"10-300"--></CUIOTHeartBeatInterval>
    <CUIOTEventTimeOut><!--rw,opt,xs:integer,"10-300"--></CUIOTEventTimeOut>
    <IdentifyEventsRespReply><!--rw,opt,xs:boolean,"true,false"--></IdentifyEventsRespReply>
    <SameEventUploadInterval><!--rw,opt,xs:integer,"10-1800"--></SameEventUploadInterval>
    <DifferentEventUploadInterval><!--rw,opt,xs:integer,"1-300"--></DifferentEventUploadInterval>
</CUIOTEventIntervalAndOtherSettingsCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| CUIOTHeartBeatInterval | integer | <span class="colour" style="color:rgb(106, 153, 85)">CUIOT协议心跳时间间隔，10s-300s</span> | <span class="colour" style="color:black">否</span> | <span class="colour" style="color:black">是</span> | 否 | 可读可写 | [10,300] |  |
| MQTTHeartBeatInterval | integer | <span class="colour" style="color:rgb(106, 153, 85)">CUIOT事件发送超时时间，10s-300s</span> | 否 | <span class="colour" style="color:black">是</span> | 否 | 可读可写 | [10,300] |  |
| IdentifyEventsRespReply | boolean | 识别事件上报是否需要应答,true-应答，falsse-不应答 | 否 | <span class="colour" style="color:black">是</span> | 否 | 可读可写 | false/true |  |
| SameEventUploadInterval | integer | 同一事件上传间隔，识别事件上报应答模式下该字段才有效,10s-1800s | 否 | <span class="colour" style="color:black">是</span> | 否 | 可读可写 | [10,1800] |  |
| DifferentEventUploadInterval | integer | 不同事件之间重传间隔，1s-300s | 否 | <span class="colour" style="color:black">是</span> | 否 | 可读可写 | [1,300] |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/CUIOTEventIntervalAndOtherSettingsCfg` 

##### 请求方式

- put
