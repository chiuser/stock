# 获取CUIOT历史事件记录上传时间段
##### 简要描述

- ##### 说明

当<HistoryEventUploadType>为“stagger”时，<StartTime>和<EndTime>有效

##### **请求**

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<CUIOTHistoryEventRecordTimeSlotCfg>
    <HistoryEventUploadType><!--rw,opt,xs:string,"no,now,stagger"--></HistoryEventUploadType>
    <StartTime>
        <Hour><!--rw,req,xs:string--></Hour>
        <Minute><!--rw,req,xs:string--></Minute>
    </StartTime>
    <EndTime>
        <Hour><!--rw,req,xs:string--></Hour>
        <Minute><!--rw,req,xs:string--></Minute> 
    </EndTime>
</CUIOTHistoryEventRecordTimeSlotCfg>
```
