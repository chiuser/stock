# 设置CUIOTV服务器参数
##### 简要描述

- ##### 请求

**xml**

```
<CUIOTVServerCfg>
    <Enable><!--rw,opt,xs:boolean--></Enable>
    <MainServerAddress><!--rw,opt,xs:string, the max length : 128--></MainServerAddress>
    <MainServerPort><!--rw,opt,xs:integer--></MainServerPort>
    <MainServerUser><!--rw,opt,xs:string, the max length : 32--></MainServerUser>
    <MainServerPassword><!--rw,opt,xs:string, the max length : 32--></MainServerPassword>
    <FileServerAddress><!--rw,opt,xs:string, the max length : 128--></FileServerAddress>
    <FileServerPort><!--rw,opt,xs:integer--></FileServerPort>
    <FileServerUser><!--rw,opt,xs:string, the max length : 32--></FileServerUser>
    <FileServerPassword><!--rw,opt,xs:string, the max length : 32--></FileServerPassword>
    <UpdateServerAddress><!--rw,opt,xs:string, the max length : 128--></UpdateServerAddress>
    <UpdateServerPort><!--rw,opt,xs:integer--></UpdateServerPort>
    <UpdateServerUser><!--rw,opt,xs:string, the max length : 32--></UpdateServerUser>
    <UpdateServerPassword><!--rw,opt,xs:string,the max  length : 32--></UpdateServerPassword>
    <ServerConnectStatus><!--rw,opt,xs:string,"init,success,erro_userorpassword,error_id_conflict,error_network_except ion,unknown"--></ServerConnectStatus>
</CUIOTVServerCfg>
```

| MainServerPort | integer | 主服务器端口 | 否 | 是 | 否 | 可读可写 | [0,65535] |  |
| MainServerUser | string | 主服务器登录名 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| MainServerPassword | string | 主服务器登录密码 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| FileServerAddress | string | 文件服务器地址或域名 | 否 | 是 | 否 | 可读可写 | 最大长度128 |  |
| FileServerPort | integer | 文件服务器端口 | 否 | 是 | 否 | 可读可写 | [0,65535] |  |

| UpdateServerPort | integer | 升级服务器端口 | 否 | 是 | 否 | 可读可写 | [0,65535] |  |

| ServerConnectStatus | string | 连接服务器状态:init <span class="colour" style="color:rgb(106, 153, 85)">初始化状态</span>,success <span class="colour" style="color:rgb(106, 153, 85)">成功</span>,erro_userorpassword <span class="colour" style="color:rgb(106, 153, 85)">用户名或密码错误</span>\,error\_id\_conflict <span class="colour" style="color:rgb(106, 153, 85)">ID冲突</span>\,error\_network\_exception <span class="colour" style="color:rgb(106, 153, 85)">网络异常</span>,unknown <span class="colour" style="color:rgb(106, 153, 85)">其他未知错误</span> | 否 | 是 | 否 | 可读可写 | 动态数组 |  ||
