# 设置CUIOTV设备鉴权信息
##### 简要描述

- ##### **请求**

**xml**

```
<CUIOTVDeviceAuthInfoCfg>
    <ProductKey><!--rw,opt,xs:string,the max  length : 64--></ProductKey>
    <DeviceKey><!--rw,opt,xs:string, the max length : 64--></DeviceKey>
    <DeviceSecret><!--rw,opt,xs:string, the max length : 64--></DeviceSecret>
</CUIOTVDeviceAuthInfoCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ProductKey | string | 产品Key | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| DeviceKey | string | 设备Key | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| DeviceSecret | string | 设备秘钥 | 否 | 是 | 否 | 可读可写 | 最大长度64 |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/CUIOTVDeviceAuthInfoCfg` 

##### 请求方式

- put

{}
