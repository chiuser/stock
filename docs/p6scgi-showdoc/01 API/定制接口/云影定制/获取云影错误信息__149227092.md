# 获取云影错误信息
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<MegLinkErrorInfo>
    <Ercode><!--ro,opt,xs:integer--></ErrorCode>
    <Message><!--ro,opt,xs:string, the max length : 256--></Message>
</MegLinkErrorInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Ercode | integer | 错误码 | 否 | 是 | 否 | 只读 | 取值范围待与设备端确认 |  |
| Message | string | 错误信息 | 否 | 是 | 否 | 只读 | 最大长度256 |  |  |

##### 请求URL

 - `/MegLink/ChannelID/ErrorInfo` 

##### 请求方式

- get
 
##### 成功返回示例  
```
[]
```
