# 获取云影认证信息
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<MegLinkAuthInfo>
    <Secret><!--ro,opt,xs:string, the max length : 64--></Secret>
    <UUID><!--rw,opt,xs::string, the max length : 64--></UUID>
</MegLinkAuthInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Secret | string | 登录秘钥 | 否 | 是 | 否 | 只读 | 最大长度64 |  |
| UUID | string | 设备UUID，保证唯一性即可 | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |  |

##### 请求URL

 - `/MegLink/ChannelID/AuthInfo` 

##### 请求方式

- get

[]
