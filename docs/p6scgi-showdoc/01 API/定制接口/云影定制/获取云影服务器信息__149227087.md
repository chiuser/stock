# 获取云影服务器信息
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<MegLinkServerAddressInfo>
    <ServerAddress><!--rw,opt,xs:string, the max length : 64--></ServerAddress>
</MegLinkServerAddressInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ServerAddress | string | 服务器地址 | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |  |

##### 请求URL
