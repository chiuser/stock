# 韦根测试
##### 简要描述

- ##### 请求

**xml**

```
<WiegandTestInfo>
    <TestData><!--rw,opt,xs:string--></TestData>
    <Timeout><!--wo,opt,xs:integer--></Timeout>
</WiegandTestInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| TestData | <span lang="EN-US"></span>string | 测试数据，任意字符串，小于64长度，Put响应中返回的TestData值应该等于请求体传入的值<span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 是 | 可读可写 | 最大长度64 |  |
| Timeout | <span lang="EN-US"></span>integer | 超时时间，不限制整数值，该时间内未返回响应体，认为测试失败<span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 只写 | 取值范围需与设备确认 |  |  |

##### 响应

**xml**

```
<WiegandTestInfo>
    <ChannelID><!--ro,opt,xs:Integer--></ChannelID>
    <TestData><!--rw,opt,xs:string--></TestData>
</WiegandTestInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ChannelID | integer | IPC通道 | 否 | 是 | 否 | 只读 | [1-32] |  |
| TestData | string | 测试数据，任意字符串，小于64长度，Put响应中返回的TestData值应该等于请求体传入的值 | 否 | 是 | 是 | 可读可写 | 最大长度64 |  ||

##### 请求URL

 - `/Wiegand/ChannelID/Test` 

##### 请求方式

- put
