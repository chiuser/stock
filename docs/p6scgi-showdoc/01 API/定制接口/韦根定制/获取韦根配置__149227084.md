# 获取韦根配置
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<WiegandSettings>
    <ChannelID><!--ro,opt,xs:Interger--></ChannelID>
    <Enable><!--rw,opt,xs:boolean”true”,”false”--></Enable>
    <Direction><!--rw,opt,xs:string”output”,”input”--></Direction>
    <Mode><!--rw,opt,xs:boolean”wiegand26”,”wiegand34”--></Mode>
    <CardSwitch><!--rw,opt,xs:boolean”true”,”false”--></CardSwitch>
    <PasswordSwitch><!--rw,opt,xs:boolean”true”,”false”--></PasswordSwitch>
    <WiegandID><!--rw,opt,xs:integer--></WiegandID>
    <OutputQRCode><!--rw,opt,xs:boolean,"true,false"--></OutputQRCode>
</WiegandSettings>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否有效 | 是否必须 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ChannelID | integer | <span class="colour" style="color:rgb(106, 153, 85)">媒体通道</span> | 否 | 是 | 否 | 只读 | [1-32] |  |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否使能配置；false 否，true 是</span> | 否 | 是 | 否 | 可读可写 | false/true |  |
| Direction | string | <span class="colour" style="color:rgb(106, 153, 85)">韦根方向；</span><span class="colour" style="color:rgb(206, 145, 120)">output</span><span class="colour" style="color:rgb(106, 153, 85)">-输出；</span><span class="colour" style="color:rgb(206, 145, 120)">input</span><span class="colour" style="color:rgb(106, 153, 85)">-输入，</span><span class="colour" style="color:rgb(206, 145, 120)">unknown </span><span class="colour" style="color:rgb(106, 153, 85)">未知</span> | 否 | 是 | 否 | 可读可写 | 动态数组 |  |
| Mode | string | <span class="colour" style="color:rgb(106, 153, 85)">韦根模式；</span><span class="colour" style="color:rgb(206, 145, 120)">wiegand26，wiegand34，unknown</span> | 否 | 是 | 否 | 可读可写 | 动态数组 |  |
| CardSwitch | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否开启卡开关；false 否，true 是</span> | 否 | 是 | 否 | 可读可写 | false/true |  |
| PasswordSwitch | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否开启密码开关；false 否，true 是</span> | 否 | 是 | 否 | 可读可写 | false/true |  |
| WiegandID | integer | <span class="colour" style="color:rgb(106, 153, 85)">韦根通道</span> | 否 | 是 | 否 | 可读可写 | 取值范围需与设备确认 |  |
| OutputQRCode | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否禁用输出二维码；false 否，true 是</span> | 否 | 是 | 否 | 可读可写 | false/true |  ||
