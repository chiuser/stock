# 获取日志文件(信通定制接口)
##### 简要描述

- 注意：
  FileType的类型值如下
  
```

*  @enum    eTransferFileType
*  @brief   传输文件类型
*/

{

```

GET:格式如下：[http://192.168.3.166/System/DeviceConfigFile?FileType=8](http://192.168.3.166/System/DeviceConfigFile?FileType=8)
“FileType”参数是文件类型, 可选, 取值如下:
a.不传FileType,对应eTransferFileAllLogFile;
b.FileType=1,对应eTransferFileSerialLogFileUpload;
c.FileType=2,对应eTransferFileProcLogFileUpload;
d.FileType=3,对应eTransferFileAxLogFileUpload;URL;
[http://192.168.3.166/System/DeviceConfigFile](http://192.168.3.166/System/DeviceConfigFile)

数据格式:
```
GET /System/DeviceConfigFile?FileType=8 HTTP/1.1\r\n
  Connection:close\r\n
  Host: 192.168.3.166\r\n
  Content-Length:\r\n
\r\n
```
