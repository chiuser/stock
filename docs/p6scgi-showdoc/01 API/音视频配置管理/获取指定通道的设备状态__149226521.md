# 获取指定通道的设备状态
##### 简要描述

- ##### 说明

<FirstSubStreamEnable>字段的值表示它是否打开第一个子流。
<SecondSubStreamEnable>字段的值表示它是否打开第二个子流。
<RecordState>字段的值为“none”，表示不支持的设备为“不支持”，但支持的设备为“无记录”。
<VideoLostState>字段的值为“false”，表示不支持的设备为“不支持”，但支持的设备为“无视频丢失事件”。
<MotionState>字段的值为“false”，表示不支持的设备为“不支持”，但支持的设备为“无运动事件”。
<AlarmInState>字段的值为“false”，表示不支持的设备为“不支持”，但支持的设备为“无事件警报”。
<AlarmInState>字段的值为“false”，表示不支持的设备为“不支持”，但支持的设备为“no alarm out event”。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<DeviceStatus>
    <ID><!--ro,req,xs:integer--></ID>
    <MainStreamVideoBitrate><!--ro,req,xs:integer --></MainStreamVideoBitrate>
    <FirstSubStreamEnable><!--ro,req,xs:boolean; "false","true"--></FirstSubStreamEnable>
    <FirstSubStreamVideoBitrate><!--ro,req,xs:integer--></FirstSubStreamVideoBitrate>
    <SecondSubStreamEnable><!--ro,req,xs:boolean; "false","true"--></SecondSubStreamEnable>
    <SecondSubStreamVideoBitrate><!--ro,req,xs:integer--></SecondSubStreamVideoBitrate>
    <RecordState><!--ro,req,xs:string,”none,alarm,normal,manual,motion”--></RecordState>
    <VideoLostState><!--ro,req,xs:boolean; "false","true"--></VideoLostState>
    <MotionState><!--ro,req,xs:boolean; "false","true"--></MotionState>
    <AlarmInState><!--ro,req,xs:boolean; "false","true"--></AlarmInState>
    <AlarmOutState><!--ro,req,xs:boolean; "false","true"--></AlarmOutState>
</DeviceStatus>
```
