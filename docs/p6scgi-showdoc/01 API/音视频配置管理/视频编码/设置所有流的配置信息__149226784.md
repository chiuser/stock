# 设置所有流的配置信息
##### 简要描述

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<StreamList>
    <Stream>
        <ID><!--rw,req,xs:integer--></ID>
        <StreamConfigList>
            <StreamConfig><!--opt-->
                <ID><!--rw,req,xs:integer--><ID>
                <StreamType><!--rw,req,xs:string,”Video,VideoAndAudio”--></StreamType>
                <VideoCodecType><!--rw,opt,xs:string,”H.264,H.265,MJPEG,H.265+,H.264+”--></VideoCodecType>
                <ResolutionWidth><!--rw,req,xs:integer--></ResolutionWidth>
                <ResolutionHeigth><!--rw,req,xs:integer--></ResolutionHeigth>
                <FrameRate><!--rw,req,xs:integer, maximum frame rate x100--></FrameRate>
                <BitrateType><!--rw,req,xs:string,"CBR,VBR,SmartAVC"--></BitrateType>
                <Bitrate><!--rw,opt, xs:integer, in kbps--></Bitrate>
                <FixedQuality><!--rw,req,xs:integer,"0-5"--></FixedQuality>
                <keyFrameInterval> <!-- rw,opt, xs:integer--> </keyFrameInterval>
                <IsMute><!--rw,req,xs:string, the max length : 256--></IsMute>
                <IsMaxVolume><!--rw,req,xs:string, the max length : 256--></IsMaxVolume>
            </StreamConfig>
        </StreamConfigList>
    </Stream>
</StreamList>
```
