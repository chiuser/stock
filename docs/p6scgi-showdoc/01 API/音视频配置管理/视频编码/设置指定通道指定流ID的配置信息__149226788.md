# 设置指定通道指定流ID的配置信息
##### 简要描述

##### 说明

URI中的<ChannelID>显示通道编号，<ChannelID>从1开始。
<StreamID>表示流类型，通常“1”表示主流，“2”表示“第一子流”，“3”表示“第二子流”，依此类推。
<FrameRate>字段表示帧速率，如果值为25500，则表示帧速率是全帧速率。
<FixedQuality>字段表示质量，值越小，质量越高。
如果<StreamID>对应于子流，则<StreamType>，<VideoCodecType>，<FixedQuality>无效，<BitrateType>始终是CBR（恒定比特率）。
不支持<keyFrameInterval>。
分辨率和帧速率范围指的是<StreamCapability>
如果<StreamID>对应于快照流，则<StreamType>，<VideoCodecType>，<FixedQuality>无效，<BitrateType>始终是CBR（恒定比特率）。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<StreamConfig>
    <ID><!--rw,req,xs:integer--><ID>
    <StreamType><!--rw,req,xs:string,”Video,VideoAndAudio”--></StreamType>
    <VideoCodecType><!—rw,req,xs:string,”H.264,H.265,MJPEG,H.265+,H.264+”--></VideoCodecType>
    <ResolutionWidth><!--rw,req,xs:integer--></ResolutionWidth>
    <ResolutionHeigth><!--rw,req,xs:integer--></ResolutionHeigth>
    <FrameRate><!--rw,req,xs:integer, maximum frame rate x100--></FrameRate>
    <BitrateType><!--rw,req,xs:string,"CBR,VBR,SmartAVC"--></BitrateType>
    <Bitrate><!--rw,req, xs:integer, in kbps--></Bitrate>
    <FixedQuality><!--rw,req,xs:integer,"0-5"--></FixedQuality>
    <keyFrameInterval> <!-- rw,req, xs:integer--> </keyFrameInterval>
    <IsMute><!--rw,opt,xs:string, the max length : 256--></IsMute>
    <IsMaxVolume><!--rw,opt,xs:string, the max length : 256--></IsMaxVolume>
</StreamConfig>
```
