# 设置设备智能算法工作模式
##### 简要描述

- ##### 说明

PeopleMode：设备智能算法以人形模式工作
FaceMode：设备智能算法以人脸模式工作

##### 请求

**xml**

```
<AIWorkMode>
    <WorkMode><!--rw,opt,xs:string “PeopleMode”,”FaceMode”--></WorkMode>
</AIWorkMode>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| WorkMode | string | 工作模式工作；PeopleMode：设备智能算法以人形模式工作，FaceMode：设备智能算法以人脸模式工作 | 否 | 是 | 否 | 可读可写 | 动态数组 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/AIWorkMode` 

##### 请求方式

- put
 
##### 成功返回示例  
```
{}

```
