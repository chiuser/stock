# 恢复出厂配置
##### 简要描述

- ##### 说明

恢复所有的设备参数到出厂时的设置

##### 请求

**xml**

```
<ExtendContent>
    <IsSimulateReset><!--wo,,req,xs:boolean; "false","true"--></IsSimulateReset>
    <IsLeaveFactory><!--wo,req,xs:boolean; "false","true"--></IsLeaveFactory>
</ExtendContent>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| IsSimulateReset | boolean | <span class="colour" style="color:rgb(106, 153, 85)">模拟硬件复位，false-否，true-是</span> | 是 | 是 | 否 | 只写 | false/true |  |  |  |  |  |
| IsLeaveFactory | boolean | <span class="colour" style="color:rgb(106, 153, 85)">出厂，false-否，true-是</span> | 是 | 是 | 否 | 只写 | false/true |  |  | <span class="colour" style="color: rgb(206, 145, 120);">配置-系统设置-系统维护手动维护-恢复出厂配置</span> |  |  ||

##### 响应

**xml**
无
**字段说明**
无
