# 设备模块恢复默认配置
##### 简要描述

- ##### 说明

##### 请求

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<DeviceModuleResetDefault Version="1.0">
    <Volume><!--rw,opt:boolean;false, true--></Volume>
    <Audio><!--rw,opt:boolean;false, true--></Audio>
    <Video><!--rw,opt:boolean;false, true--></Video>
    <Image><!--rw,opt:boolean;false, true--></Image>
    <Network><!--rw,opt:boolean;false, true--></Network>
</DeviceModuleResetDefault>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Volume | boolean | 是否设置 输入与输出音量 功能模块恢复默认配置；false 否，true 是 | 否 | 是 | 否 | 只写 | false/true |  |
| Audio | boolean | 是否设置  音频 功能模块恢复默认配置 | 否 | 是 | 否 | 只写 | false/true |  |
| Video | boolean | 是否设置 视频 功能模块恢复默认配置 | 否 | 是 | 否 | 只写 | false/true |  |
| Image | boolean | 是否设置 图像 功能模块恢复默认配置 | 否 | 是 | 否 | 只写 | false/true |  |
| Network | boolean | 是否设置 网络 功能模块恢复默认配置 | 否 | 是 | 否 | 只写 | false/true |  ||

##### 响应

**xml**
无
**字段说明**
无

 - `/System/DeviceModuleResetDefault`
