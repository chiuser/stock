# 恢复默认配置版本说明
#### 说明
恢复默认配置功能有3个版本

#### V1版本
url: /System/FactoryDefault
恢复设备除网络、用户管理、OSD之外的配置

#### V2版本
url: /System/FactoryDefaultV2
1.若IsSimulateReset=false且IsLeaveFactory= false,或请求中xml没有参数项,则设备恢复所有配置包括网络、用户管理、OSD
2.若IsSimulateReset=true且IsLeaveFactory= false, 恢复所有配置包括网络、用户管理、OSD,同时解绑设备(类似硬件服务)
3.若IsLeaveFactory=true; 设备恢复出厂配置

#### V3版本
url: /System/DeviceModuleResetDefault
只恢复指定模块的配置, 支持同时恢复多个模块的配置
