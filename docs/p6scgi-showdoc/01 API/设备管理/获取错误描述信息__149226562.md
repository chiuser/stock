# 获取错误描述信息
##### 简要描述

- ##### 说明

<ErrorCode> it is a returnd error code by the http server.
<ErrorDescription>it is a returnd error ErrorDescription by the http server.
  Example:
      [http://192\.168\.1\.11/System/ErrorInfoMap?ErrorCode=\(0\|1\|2\|\.\.\.\.\)](http://192.168.1.11/System/ErrorInfoMap?ErrorCode=(0%7C1%7C2%7C....))

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<ErrorInfo><!--req-->
    <ErrorCode><!--ro,req,xs:integer--></ErrorCode>
    <ErrorDescription><!--ro,req,xs:string,  the max length : 128--></ErrorDescription>
</ErrorInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ErrorCode | integer | <span class="colour" style="color:rgb(106, 153, 85)">错误码</span> | 是 | 是 | 否 | 只读 | 取值需与设备确认 |  |
| ErrorDescription | string | <span class="colour" style="color:rgb(106, 153, 85)">错误描述</span> | 是 | 是 | 否 | 只读 | 最大长度128 |  ||

##### 请求URL

 - `/System/ErrorInfoMap` 

##### 请求方式

- get

```
[]
```
