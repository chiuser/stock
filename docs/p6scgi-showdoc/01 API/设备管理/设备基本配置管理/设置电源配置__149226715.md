# 设置电源配置
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<PowerConfig>
    <PowerVoltage><!--rw,opt,xs:interger,0,低，1，中，2，高--></PowerVoltage>
    <PowerStatus><!--rw,opt,xs:interger,0,无状态，1，放电中，2，充电中，3，已充满--></PowerStatus>
    <AutoPowerSavingMode><!--rw,opt,xs:interger,0，关，1，开--></AutoPowerSavingMode>
    <CurrentPowerPercentage><!--rw,opt,xs:interger--></CurrentPowerPercentage>
    <SetPowerSavingPercentage><!--rw,opt,xs:interger--></SetPowerSavingPercentage>
    <IsPsmState><!--rw,opt,xs:interger;0-否,1-是--></IsPsmState>
    <LowBatteryAlarmSwitch><!--rw,opt,xs:interger--></LowBatteryAlarmSwitch>
    <WakeUpDuration><!--rw,opt,xs:interger--></WakeUpDuration>
    <WakeUpIntervalTimeSwitch><!--rw,opt,xs:interger--></WakeUpIntervalTimeSwitch>
    <WakeUpIntervalTime><!--rw,opt,xs:interger--></WakeUpIntervalTime>
    <PowerSupplyType><!--rw,opt,xs:interger--></PowerSupplyType>
    <ShutdownAlarmSwitch><!--rw,opt,xs:boolean；“true，false”--></ShutdownAlarmSwitch>
    <IsSupportAOVPopWindow><!--rw,opt,xs:interger--></IsSupportAOVPopWindow>
</PowerConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| PowerVoltage | integer | <span class="colour" style="color:rgb(106, 153, 85)">电源电压0,低，1，中，2.高</span> | 否 | 是 | 否 | 可读可写 | 0/1/2 |  |
| PowerStatus | integer | <span class="colour" style="color:rgb(106, 153, 85)">供电状态，0，无状态，1，放电中，2，充电中，3，已充满</span> | 否 | 是 | 否 | 可读可写 | 0/1/2/3 |  |
| AutoPowerSavingMode | integer | <span class="colour" style="color:rgb(106, 153, 85)">自动进入省电模式开关，0，关，1，开</span> | 否 | 是 | 否 | 可读可写 | 0/1 |  |
| CurrentPowerPercentage | integer | 当前电量百分比 | 否 | 是 | 否 | 可读可写 | [0-100] |  |
| SetPowerSavingPercentage | integer | 设置省电模式电量百分比 | 否 | 是 | 否 | 可读可写 | [0-100] |  |
| IsPsmState | integer | 当前设备是否处于省电模式状态;0-否,1-是 | 否 | 是 | 否 | 可读可写 | 0/1 |  |
| LowBatteryAlarmSwitch | boolean | 低电量报警开关, false-关,true-开 | 否 | 是 | 否 | 可读可写 | false/true |  |
| WakeUpDuration | integer | 唤醒持续时间 | 否 | 是 | 否 | 可读可写 | 取值范围需与设备确认 |  |
| WakeUpIntervalTimeSwitch | boolean | 唤醒间隔时间开关, false-关,true-开 | 否 | 是 | 否 | 可读可写 | false/true |  |
| WakeUpIntervalTime | integer | 唤醒间隔时间 | 否 | 是 | 否 | 可读可写 | 取值范围需与设备确认 |  |
| PowerSupplyType | integer | <span class="colour" style="color:rgb(106, 153, 85)">电池供电类型; 0. 无状态  1. 电源线供电  2. 太阳能供电  3. 仅电池供电</span> | 否 | 是 | 否 | 可读可写 | 0/1/2/3 |  |
| ShutdownAlarmSwitch | boolean | <span class="colour" style="color:rgb(106, 153, 85)">关机报警开关;false-关,true-开</span> | 否 | 是 | 否 | 可读可写 | false/true |  |
| IsSupportAOVPopWindow | integer | <span class="colour" style="color:rgb(106, 153, 85)">支持 AOV 弹窗模式;0：不支持，5 分钟弹窗,1：支持，2 分钟弹窗</span> | 否 | 是 | 否 | 可读可写 | 0/1 |  ||
