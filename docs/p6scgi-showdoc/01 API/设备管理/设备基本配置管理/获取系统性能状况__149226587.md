# 获取系统性能状况
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<SystemPerformanceStatus>
    <CPUPercent><!--ro,opt,xs:double；eg：”80%”--></CPUPercent>
    <MemoryPercent><!--ro,opt,xs:double；eg：”80%”--></MemoryPercent>
    <StroagePercent><!--ro,opt,xs:double；eg：”80%”--></StroagePercent>
    <UpTime><!--ro,opt,xs:Integer--></UpTime>
    <OpenDoorCount><!--ro,opt,xs:Integer--></OpenDoorCount>
    <BootCount><!--ro,opt,xs:Integer--></BootCount>
    <MemorySize><!--ro,opt,xs:Integer--></MemorySize>
</SystemPerformanceStatus>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| CPUPercent | double | <span class="colour" style="color:rgb(106, 153, 85)">CPU利用率</span> | 否 | 是 | 否 | 只读 | [0,100] |  |
| MemoryPercent | double | <span class="colour" style="color:rgb(106, 153, 85)">内存利用率</span> | 否 | 是 | 否 | 只读 | [0,100] |  |
| StroagePercent | double | <span class="colour" style="color:rgb(106, 153, 85)">存储利用率</span> | 否 | 是 | 否 | 只读 | [0,100] |  |
| UpTime | integer | <span class="colour" style="color:rgb(106, 153, 85)">启动时间（秒）</span> | 否 | 是 | 否 | 只读 | 取值需与设备确认 |  |
| OpenDoorCount | integer | <span class="colour" style="color:rgb(106, 153, 85)">开门次数</span> | 否 | 是 | 否 | 只读 | 取值需与设备确认 |  |
| BootCount | integer | <span class="colour" style="color:rgb(106, 153, 85)">重启次数</span> | 否 | 是 | 否 | 只读 | 取值需与设备确认 |  |
| MemorySize | integer | <span class="colour" style="color:rgb(106, 153, 85)">内存大小</span> | 否 | 是 | 否 | 只读 | 取值需与设备确认 |  ||
