# 设置IPC受控状态
##### 简要描述

- ##### 说明
设置IPC与NVR连接时的受控模式
ChannelID代表通道号，对于IPC只有一个通道，使用的时候需替换为数字，取值从1开始

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<AlarmOut>
    <ControlMode><!--rw,req,xs:boolean:”true”,”false”--></ControlMode>
</AlarmOut>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ControlMode | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否受控状态；false 否，true 是</span> | 是 | 是 | 否 | 可读可写~~~~ | false/true |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/Alarm/AlarmOut/ChannelID/ControlMode` 

##### 请求方式

- put

```
{}
```
