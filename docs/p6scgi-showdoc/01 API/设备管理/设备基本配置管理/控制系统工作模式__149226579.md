# 控制系统工作模式
##### 简要描述

- ##### 说明

**重启后自动恢复设置之前的工作模式**

##### **请求**

**xml**

```
<SystemWorkMode>
    <WorkMode><!--rw,req,xs:string”TestMode”,”NormalMode”--></WorkMode>
</SystemWorkMode>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| WorkMode | string | 工作模式；TestMode测试模式，NormalMode正常模式 | 是 | 是 | 否 | 可读可写 | 动态数组 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/WorkModeControl` 

##### 请求方式

- put

```
{}
```
