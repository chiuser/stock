# 获取云升级固件列表
##### 简要描述

- ##### 示例

Example:
      [http://192.168.1.11/System/CloudUpgradeFirmwareList?VersionType=all](http://192.168.1.11/System/CloudUpgradeFirmwareList?VersionType=all) \| default \(all, 表示获取所有的固件版本, default，表示获取最新的版本信息\)

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<FirmwareList><!--req-->
    <Firmware>
        <Name><!--ro,req,xs:string, the max  length : 128--></Name>
        <Desc><!--ro,req,xs:string, the max  length : 4096--></Desc>
        <Version><!--ro,req,xs:string, the max  length : 64--></Version>
        <TotalSize><!--ro,req,xs:integer--></TotalSize>
   </Firmware>
</FirmwareList>
```
