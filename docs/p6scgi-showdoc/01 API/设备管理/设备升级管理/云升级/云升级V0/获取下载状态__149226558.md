# 获取下载状态
##### 简要描述

- ##### 示例

Example:
      [http://192.168.1.11/System/CloudUpgradeDownloadStatus?Passport=abc](http://192.168.1.11/System/CloudUpgradeDownloadStatus?Passport=abc) (这个“abc”是由客户端生成的)

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Status><!--req-->
    <Status><!--ro,req,xs:string, "0,空闲 1,正在下载 2,下载完成 3,下载失败"--></Status>
    <TotalSize><!--ro,req,xs:string--></TotalSize>
    <SentSize><!--ro,req,xs:string--></SentSize>
    <Passport><!--ro,req,xs:string,  the max length : 64--></Passport>
</Status>
```
