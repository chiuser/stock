# 云升级功能说明
#### 简介
1.云升级有V0、V1两个版本，主要用于app升级设备
2.V0版本云升级,需要APP分别触发“下载”和“升级”操作，分别监控下载状态和升级状态
3.V1版本支持一个请求同时触发下载和升级，简化升级逻辑

#### 流程图说明
云升级步骤
1.app调用/System/DeviceCap获取设备能力，能力字段中OneKey=true,表示设备支持V1版本云升级,若没有能力字段OneKey或OneKey=false,表示设备不支持V1版本云升级
2.若设备不支持V1版本云升级，则使用V0版本云升级
  &ensp;2.1.app调用/System/CloudUpgradeServerInfo向设备设置云升级服务器信息
  &ensp;2.2.设备向云升级服务器获取设备固件列表
  &ensp;2.3.app调用/System/CloudUpgradeFirmwareList向设备获取固件升级包列表
  &ensp;2.4.app调用/System/CloudUpgradeDownloadStart向设备下发 开始下载 请求，设备收到开始下载请求后从云服务器下载固件升级包,在设备下载过程中,app循环调用/System/CloudUpgradeDownloadStatus获取下载状态 
  &ensp;2.5.app获取到设备下载状态为下载完成后，调用/System/CloudUpgradeStartUpgrade向设备下发开始升级
  &ensp;2.6.设备收到开始升级请求后开始升级,在设备升级过程中,app循环调用/System/CloudUpgradeResult获取设备升级结果
  &ensp;2.7.app获取到设备升级完成后,云升级结束
3.若设备支持V1版本云升级
  &ensp;3.1.app调用/System/CloudUpgradeServerInfo向设备设置云升级服务器信息
  &ensp;3.2.设备向云升级服务器获取设备固件列表
  &ensp;3.3.app调用/System/CloudUpgradeFirmwareList向设备获取固件升级包列表
  &ensp;3.4.app调用/System/CloudUpgradeDownloadStartV1向设备下发 云升级启动V1请求，设备收到云升级启动V1请求后从云服务器下载固件升级包,下载完成后自动升级, app循环调用/System/CloudUpgradeResult 获取设备升级结果 
  &ensp;3.5.app获取到设备升级完成后,云升级结束
#### 接口说明
设置云升级服务器信息
/System/CloudUpgradeServerInfo : 只支持PUT，用于向设备设置云升级服务器信息,设备向设置的云升级服务器请求获取设备升级包列表

获取云升级固件列表
/System/CloudUpgradeFirmwareList ： GET, 用于向设备获取固件升级包列表信息, 只返回最新版本固件升级包

开始下载
/System/CloudUpgradeDownloadStart : PUT，用于向设备下发 开始下载 请求

获取下载状态
/System/CloudUpgradeDownloadStatus : GET, 用于向设备获取下载状态

开始升级
/System/CloudUpgradeStartUpgrade : PUT,用于向设备下发 开始升级 请求

获取升级结果
/System/CloudUpgradeResult : GET,用于向设备获取升级结果

云升级启动V1
/System/CloudUpgradeDownloadStartV1 : PUT,用于向设备下发 云升级启动V1 请求，支持V1版本云升级的设备调用

#### 说明
获取云升级基本信息(/CloudUpdate/ChannelID/BasicInfo)接口，由设备端网页调用，用于获取设备的云升级信息,app没有调用该接口
