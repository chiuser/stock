# 固件升级
##### 简要描述
 设备PTZ机芯的程序也会需要更新，新增“AF机芯升级包文件”类型，使用“固件升级”的方式上传 AF机芯升级包文件 升级机芯

 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
 | ---------------- | ---------------- | ---------- | --------- |
 |  | 配置-系统设置-设备升级-AF机芯升级-开始升级 |  |||
