# 机芯升级说明
#### 简介
1.设备PTZ机芯的程序也会需要更新，新增“AF机芯升级包文件”类型，使用“固件升级”的方式上传 AF机芯升级包文件 升级机芯
2.机芯升级适用于Web端，用于升级设备的PTZ机芯，由设备PTZ能力中AFProfessionPTZ下的Upgrade能力字段控制

#### 机芯升级流程图
![](http://zwp2p.p6sai.com:4999/server/index.php?s=/api/attachment/visitFile&sign=671a6486d05b6b3630d176bae45a230d)

#### 机芯升级流程图说明(以web端为例)：
1.web调用/System/PTZCap获取设备PTZ能力，能力字段AFProfessionPTZ下的Upgrade=true,表示设备支持机芯升级
2.若设备支持机芯升级，则调用/System/FirmwareUpgrade 向设备上传机芯文件 升级机芯
3.web循环调用 /System/AFBoardUpgradeStatus 获取机芯升级状态
4.web获取到机芯升级状态后(升级失败、升级成功、升级超时),机芯升级结束

#### 机芯升级相关接口
固件升级
/System/FirmwareUpgrade : POST,通过filetype字段指定升级文件类型，机芯升级 filetype=30

获取AF机芯升级状态
/System/AFBoardUpgradeStatus : GET,用于获取机芯升级状态
