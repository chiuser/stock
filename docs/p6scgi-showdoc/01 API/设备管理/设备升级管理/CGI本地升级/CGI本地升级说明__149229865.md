# CGI本地升级说明
#### 简介
1.主要用于web端升级设备固件

#### CGI本地升级流程图(以web端为例)
![](http://zwp2p.p6sai.com:4999/server/index.php?s=/api/attachment/visitFile&sign=1afc11c4e704b018b25f8bc0478b043f)

#### CGI本地升级流程图说明(以web端为例)
CGI本地升级步骤：以web端为例
1.web调用/System/FirmwareUpgrade 向设备上传固件升级包 ,设备接收完升级包后开始升级
2.若设备升级完成后向web响应升级结果
3.升级结束

#### CGI本地升级相关接口
固件升级
/System/FirmwareUpgrade : POST,CGI本地升级不需要filetype字段指定升级文件类型,默认是CGI本地固件升级
