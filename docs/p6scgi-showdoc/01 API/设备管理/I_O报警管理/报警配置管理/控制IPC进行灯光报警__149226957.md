# 控制IPC进行灯光报警
##### 简要描述

- ##### 说明

AlarmID代表报警通道号，使用的时候需替换为数字，取值从1开始

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<LightAlarm><!--req-->
    <LightWarning><!--wo,req,xs:string,”Twinkle,Open,Close”--></LightWarning>
    <TwinkleTime><!--wo,req,xs:interger(suggest:2)--></TwinkleTime>
</LightAlarm>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| LightWarning | string | 灯光报警模式；<span class="colour" style="color:rgb(206, 145, 120)">Twinkle </span>闪烁，<span class="colour" style="color:rgb(206, 145, 120)">Open </span>常开，<span class="colour" style="color:rgb(206, 145, 120)">Close </span>常闭 | 是 | 是 | 否 | 只写 | 动态数组 |  |
| TwinkleTime | integer | 灯光闪烁时间，单位秒 | 是 | 是 | 否 | 只写 | 建议值2 |  ||

##### 请求URL

 - `/Alarm/AlarmAction/AlarmID/LightWarning` 

##### 请求方式

- put

{}
