# 设置指定通道音频报警消除信息
##### 简要描述

- ##### 说明

<span class="colour" style="color:rgb(23, 43, 77)">URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。对于IPC，ChannelID恒为1</span>

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8" ?>
<AudioAlarmEliminate>
    <ChannelID><!--rw,opt,xs:integer--></ChannelID>
    <Enable><!--rw,opt,xs:boolean--></Enable>
    <AlarmEliminateAudioType><!--rw,opt,xs:string--></AlarmEliminateAudioType>
    <EBikeDetectEliminateDuration><!--rw,opt,xs:integer--></EBikeDetectEliminateDuration>
    <GasContainerDetectEliminateDuration><!--rw,opt,xs:integer--></GasContainerDetectEliminateDuration>
</AudioAlarmEliminate>
```
