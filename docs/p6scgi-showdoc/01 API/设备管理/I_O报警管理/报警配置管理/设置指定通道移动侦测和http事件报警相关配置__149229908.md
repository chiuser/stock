# 设置指定通道移动侦测和http事件报警相关配置
##### 简要描述

##### 说明
channelID取值1、2

##### 请求

<span class="colour" style="color:rgb(85, 85, 85)">**xml**</span>

```
<?xml version="1.0" encoding="utf-8"?>
<EventCfgList>
    <motion>
        <PreRecordTime><!--rw,req,xs:interger--></PreRecordTime>
        <AlarmInterval><!--rw,req,xs:interger--></AlarmInterval>
        <Message><!--rw,req,xs:string, the max length : 256--></Message>
    </motion>
    <http>
      <PreRecordTime><!--rw,req,xs:interger--></PreRecordTime>
      <AlarmInterval><!--rw,req,xs:interger--></AlarmInterval>
      <Message><!--rw,req,xs:string, the max length : 256--></Message>
    </http>
</EventCfgList>
```

<span class="colour" style="color:rgb(85, 85, 85)">**字段说明**</span>

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| EventCfgList |  |  |  |  |  |  |  |  |
| motion |  | 移动侦测事件配置 | 否 | 是 |  |  |  |  |
| PreRecordTime | integer | 预录像时间，单位：秒 | 是 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| AlarmInterval | integer | 报警间隔，单位：秒 | 是 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| Message | string | 服务器信息 | 是 | 是 | 否 | 可读可写 | 最大长度256 |  |
| http |  | http事件配置 | 否 | 是 |  |  |  |  |
| PreRecordTime | integer | 预录像时间，单位：秒 | 是 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| AlarmInterval | integer | 报警间隔，单位：秒 | 是 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| Message | string | 服务器信息 | 是 | 是 | 否 | 可读可写 | 最大长度256 |  ||
