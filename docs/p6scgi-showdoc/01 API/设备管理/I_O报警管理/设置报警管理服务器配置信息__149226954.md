# 设置报警管理服务器配置信息
##### 简要描述

- ##### 请求

<span class="colour" style="color:rgb(85, 85, 85)">**xml**</span>

```
<?xml version="1.0" encoding="utf-8"?>
<AMS>
    <Enable><!--rw,req,xs:boolean:"false","true" --></Enable>
    <ServerName><!--rw,req,xs:string  , the max length : 64 --></ServerName>
    <UserName><!--rw,req,xs:string  , the max length : 64 --></UserName>
    <Password><!--rw,req,xs:string , the max length : 64  --></Password>
    <Message><!--rw,req,xs:string , the max length : 256--></Message>
</AMS>
```

<span class="colour" style="color:rgb(85, 85, 85)">**字段说明**</span>

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否启用报警服务器配置；false-否, true-是</span> | 是 | 是 | 否 | 可读可写 | false/true |  |
| ServerName | string | <span class="colour" style="color:rgb(106, 153, 85)">报警服务器名称</span> | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |
| UserName | string | <span class="colour" style="color:rgb(106, 153, 85)">用户名</span> | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |
| Password | string | <span class="colour" style="color:rgb(106, 153, 85)">用户密码</span> | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |
| Message | string | <span class="colour" style="color:rgb(106, 153, 85)">报警服务器url经<span class="colour" style="color:rgb(106, 153, 85)">base64编码后的内容</span></span> | 是 | 是 | 否 | 可读可写 | 最大长度256 |  ||
