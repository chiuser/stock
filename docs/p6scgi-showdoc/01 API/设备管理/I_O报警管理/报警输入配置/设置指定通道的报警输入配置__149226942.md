# 设置指定通道的报警输入配置
##### 简要描述

 ##### 说明

<AlarmOutMask>，<SnapshotMask>，<RecordMask>的格式类似于“11111111”或“00000000”，每个位表示通道是否为链接，1表示链接，0表示不链接，例如字符串 “11111111”表示该设备是8个通道，从左到右分别代表通道1，通道2，通道3 ......等等。
    对于单通道设备，<AlarmOutMask>，<SnapshotMask>，<RecordMask>和<PTZActionList>无效。
