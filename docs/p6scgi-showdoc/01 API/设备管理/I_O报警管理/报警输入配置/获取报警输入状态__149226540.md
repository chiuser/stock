# 获取报警输入状态
##### 简要描述

- ##### 说明

<State>的格式类似于“11111111”或“00000000”，每个位表示通道的报警是否打开，NO.1表示触发报警，NO.0表示尚未触发报警输出，例如，字符串“11111111”表示设备是8个通道，从左到右，代表通道1，通道2，通道3 ......等等。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<AlarmInState><!--req-->
    <State><!--ro,req,xs:string,”00000000000000” --></State>
</AlarmInState>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| State | string | <span class="colour" style="color:rgb(106, 153, 85)">报警输入通道状态，0-31位分别表示报警输入通道0-31的状态</span> | 是 | 是 | 否 | 只读 | 最大长度32 |  ||

##### 请求URL

 - `/System/AlarmInstate` 

##### 请求方式

- get
