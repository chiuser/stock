# 设置指定通道拌线布防计划配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

<span class="colour" style="color:rgb(85, 85, 85)"><span class="colour" style="color:rgb(85, 85, 85)">**xml**</span></span>

```
<AssisstantLineSchedule>
    <ChannelID><!--rw,req,xs:integer--></ChannelID>
    <AllDay><!--rw,req,xs:string,”false”,”true”--></AllDay>
    <TimeBlockList>
        <TimeBlock_0><!--rw,req,xs:string,”111111111111111111111111111111111111111111111111”--></TimeBlock_0>
        <TimeBlock_1><!--rw,req,xs:string,”111111111111111111111111111111111111111111111111”--> </TimeBlock_1>
        <TimeBlock_2><!--rw,req,xs:string,”111111111111111111111111111111111111111111111111”--></TimeBlock_2>
        <TimeBlock_3><!--rw,req,xs:string,”111111111111111111111111111111111111111111111111”--></TimeBlock_3>
        <TimeBlock_4><!--rw,req,xs:string, ”111111111111111111111111111111111111111111111111”--></TimeBlock_4>
        <TimeBlock_5><!--rw,req,xs:string, ”111111111111111111111111111111111111111111111111”--></TimeBlock_5>
        <TimeBlock_6><!--rw,req,xs:string, ”111111111111111111111111111111111111111111111111”--></TimeBlock_6>
    </TimeBlockList>
</AssisstantLineSchedule>
```
