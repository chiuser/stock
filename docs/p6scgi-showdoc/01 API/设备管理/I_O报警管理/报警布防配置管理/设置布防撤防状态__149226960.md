# 设置布防撤防状态
##### 简要描述

- ##### 说明

设置后重启自动恢复之前的状态

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<AlarmPreventionControl>
    <Status><!--rw,opt,xs:string,"Disable","Enable"--></Status>
</AlarmPreventionControl>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Status | string | 布防状态；<span class="colour" style="color:rgb(206, 145, 120)">Disable </span>撤防，<span class="colour" style="color:rgb(206, 145, 120)">Enable </span>布防 | 否 | 是 | 否 | 可读可写 | 动态数组 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/Alarm/PreventionControl` 

##### 请求方式

- put

```
{}
```
