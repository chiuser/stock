# 设置指定通道多边形检测配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
PolygonLineNum：多边形边数量
Direction：多边形的每一边探测方向
Point：多边形的顶点，数量是变化的，可以有多个Point节点，比如PolygonLineNum数量是5，代表五边形，那么Point节点就有5个

UseForMotionDetect：该多边形探测区域是否对移动侦测生效
UseForPeopleDetect：该多边形探测区域是否对人形探测生效
UseForFaceDetect：该多边形探测区域是否针对人脸探测生效

关于Point坐标值：此处为万分比，假如APP运行设备实际分辨率为1080*1920，此时在APP中绘制的某个点为(100,200)，则传递到CGI协议的点值为：(100/1080*10000,200/1920*10000)。

##### 请求

**xml**

```
<PolygonConfig>
    <PolygonLineNum><!--rw,req,xs:interger--></PolygonLineNum>
    <Direction><!--rw,req,xs:string, ”forward_direction”,”opposite_direction”,”two_way”--></Direction>
    <TrackZoom><!--rw,req,xs:boolean; "false","true"--></TrackZoom>
    <Point>
        <PosX><!--rw,req,xs:interger,”0-703”--></PosX>
        <PosY><!--rw,req,xs:interger,”0-575”--></PosY>
    </Point>
    ……
    <PolygonUseful>
        <UseForMotionDetect><!--rw,req,xs:boolean,”false”,”true”--></UseForMotionDetect>
        <UseForPeopleDetect><!--rw,req,xs:boolean,”false”,”true”--></UseForPeopleDetect>
        <UseForFaceDetect><!--rw,req,xs:boolean,”false”,”true”--></UseForFaceDetect>
        <UseForCarDetect><!--rw,req,xs:boolean,”false”,”true”--></UseForCarDetect>
    </PolygonUseful>
    <Trigger>
        <NotifyAMS>
            <Enable><!--rw,req,xs:boolean; "false","true"--></Enable>
        </NotifyAMS>
        <BeepAlert>
            <Enable><!--rw,req,xs:boolean; "false","true"--></Enable>
        </BeepAlert>
        <FullScreen>
            <Enable><!--rw,req,xs:boolean; "false","true"--></Enable>
        </FullScreen>
        <Mail>
            <Enable><!--rw,req,xs:boolean; "false","true"--></Enable>
        </Mail>
        <AlarmOut>
            <Enable><!--rw,req,xs:boolean; "false","true"--></Enable>
            <AlarmOutMask><!--rw,req,xs:string,” 111111111111111”--></AlarmOutMask>
        </AlarmOut>
        <Snapshot>
            <Enable><!--rw,req,xs:boolean; "false","true"--></Enable>
            <SnapshotMask><!--rw,req,xs:string,” 111111111111111”--></SnapshotMask>
        </Snapshot>
        <Record>
            <Enable><!--rw,req,xs:boolean; "false","true"--></Enable>
            <RecordMask><!--rw,req,xs:string,” 111111111111111”--></RecordMask>
        </Record>
        <PTZ>
            <Enable><!--rw,req,xs:boolean; "false","true"--></Enable>
            <PTZActionList>
                <ptzChannelID> <!--rw,req, xs:string --></ptzChannelID>
                <ActionName><!-- rw,req, xs:string,”none,preset, pattern, patrol” --></ActionName>
               <ActionNum><!--rw,req,xs:integer,depend on <ActionName>--></ActionNum>
            </PTZActionList>
        </PTZ>
        <LightAlarm Version="1.0">
            <Enable><!--rw,req,xs:boolean; "false","true"--></Enable>
        </LightAlarm>
    </Trigger>
</PolygonConfig>
```
