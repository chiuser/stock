# 设置指定通道报警输出配置
##### 简要描述

- ##### 说明

如果<Delay>的值为“keep”，则报警保持输出。如果<Delay>的值为5，则报警将保持5秒输出。
Gate：控制门禁高低电平输出

##### 请求

<span class="colour" style="color:rgb(85, 85, 85)">**xml**</span>

```
<?xml version="1.0" encoding="utf-8"?>
<AlarmOut>
    <ID><!--rw,req,xs:integer --></ID>
    <Name><!--rw,req,xs:string,max length little than 32--></Name>
    <Delay><!--rw,req,xs:string,”keep,custom(the unit is second)”--></Delay>
    <Gate><!--rw,opt,xs:string,”AlwayOpen”,”AlwayClose”--></Gate>
</AlarmOut>
```

<span class="colour" style="color:rgb(85, 85, 85)">**字段说明**</span>

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ID | integer | 通道ID，从1递增 | 是 | 是 | 否 | 可读可写 | [1-32] |  |
| Name | string | 通道名 | 是 | 是 | 否 | 可读可写 | 最大长度32 |  |
| Delay | string | 报警输出延时；如果值为“keep”，报警保持输出。如果值为5，则报警将保持5秒输出 | 是 | 是 | 否 | 可读可写 | 最大长度32 |  |
| Gate | string | 门禁报警状态；<span class="colour" style="color:rgb(206, 145, 120)">AlwayOpen </span>常开，<span class="colour" style="color:rgb(206, 145, 120)">AlwayClose </span>常闭 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/Alarm/AlarmOut/ChannelID` 

##### 请求方式

- put
