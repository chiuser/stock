# 试听当前选择的报警音频
##### 简要描述

- ##### 请求

<span class="colour" style="color:rgb(85, 85, 85)">**xml**</span>

```
<?xml version="1.0" encoding="utf-8"?>
<AudioAlarm><!--req-->
    <Enable><!--wo,req,xs:boolean--></Enable>
    <Type><!--wo,req,xs:string,“custom,alarm,dog,warning area,monitoring area,welcome,Deep Water Warning,Private territory,danger zone,Valuable objects,High Warning,Private Parking,Ding Dong,HasMask,NoMask,MindPersonalBelongings,CatchThief,Help,classification,recyclable waste,household food waste,hazardous waste,residual waste,ClassificationAll,CarCustom,NotAllowPark,FireCustom,ThankYou,YouHaveOffDuty,ForestFirePrevention,FireAlarm”--></Type>
    <Delay><!--wo,req,xs:interger,the unit is second--></Delay>
    <Volume><!--wo,req,xs:interger,0--100--></Volume>
</AudioAlarm>
```

<span class="colour" style="color:rgb(85, 85, 85)">**字段说明**</span>

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | 使能<span class="colour" style="color:rgb(106, 153, 85)">，false-否，true-是</span> | 是 | 是 | 否 | 只写 | false/true |  |
| Type | string | 声音报警类型；custom：自定义，alarm：警报，dog：犬吠，warning area：警戒区域，monitoring area：监控区域，welcome：欢迎光临，Deep Water Warning：深水警告，Private territory：私人领地，danger zone：危险区域，Valuable objects：贵重物品，High Warning：高处危险，Private Parking：私家价位，Ding  Dong：叮咚,    HasMask:有口罩,     NoMask:无口罩    MindPersonalBelongings：注意私人物品     CatchThief：抓小偷     Help：救命       classification：分类       recyclable waste：可回收垃圾        household food waste：家庭食物垃圾  hazardous waste：危险废物       residual waste：残余垃圾     ClassificationAll：全部分类    CarCustom：车形自定义        NotAllowPark：禁止停车   FireCustom：消防定制    ThankYou：谢谢    YouHaveOffDuty：你已离岗    ForestFirePrevention：森林防火  FireAlarm：火焰报警 | 是 | 是 | 否 | 只写 | 最大长度64 |  |
| Delay | integer | 语音报警延时,单位秒 | 是 | 是 | 否 | 只写 | 取值需与设备确认 |  |
| Volume | integer | 语音报警音量1~100，如果音量为0，那么音量设为默认值50 | 是 | 是 | 否 | 只写 | [1,100] |  ||
