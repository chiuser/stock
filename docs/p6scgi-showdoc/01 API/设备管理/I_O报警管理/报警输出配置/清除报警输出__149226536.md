# 清除报警输出
##### 简要描述

- URI中的<ChannelID>是通道编号。<ChannelID>从1开始。
URI中的<ID>显示警报类型，请将ID设置为0。

##### 请求URL

 - `/System/ChannelID/RemoteAlarmOutClear/ID` 

##### 请求方式

- put
