# 试听指定通道当前选择的报警音频
##### 简要描述


 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
 | ---------------- | ---------------- | ---------- | --------- |
 |  | <span class="colour" style="color: rgb(206, 145, 120);">配置-普通事件/智能分析-事件-联动方式-声音报警-试听</span> |  |||

##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。对于IPC，ChannelID恒为1
