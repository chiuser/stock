# 获取报警输出配置
##### 简要描述

- #### 以T5AI设备为例说明

##### **请求**

**_xml_**
**_无_**
**_字段说明_**
无

##### **响应**

**_xml_**

```
<?xml version="1.0" encoding="utf-8"?>
<AlarmOutList>
    <AlarmOut><!--option-->
        <ID><!--rw,req,xs:interger--></ID>
        <Name><!--rw,req,xs:string,max length little than 32--></Name>
        <Delay><!--rw,req,xs:string,”keep,custom(the unit is second)”--></Delay>
        <Gate><!--rw,req,xs:string,”AlwayOpen”,”AlwayClose”--></Gate>
    </AlarmOut>
</AlarmOutList>
```

**_字段说明_**

| 字段 | 类型 | 功能描述 | 是否必须 | 字段是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | ---- | ---- | ------ | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| AlarmOut |  |  |  |  |  |  |  |  |  |  | <span class="colour" style="color: rgb(0, 0, 0);">设备能力专用URL：/System/DeviceCap；能力定义：Device->AlarmInCount</span> |  |
| ID | integer | 通道ID | 是 | 是 | 不可为空 | 可读可写 | 从1开始递增，最大支持32通道 | 建议值：1 |  | <span class="colour" style="color:rgb(206, 145, 120)">配置-系统设置-I/O报警-报警输出-报警输出</span> |  | <span class="colour" style="color: rgb(85, 85, 85);">无</span> |
| Name | string | 报警输出通道名称 | 是 | 是 | 不可为空 | 可读可写 | 最大长度32 | 建议值：AO01 |  | <span class="colour" style="color:rgb(206, 145, 120)">配置-系统设置-I/O报警-报警输出-报警输出名称</span> |  | <span class="colour" style="color: rgb(85, 85, 85);">无</span> |
| Delay | string | 报警输出延时，如果\<Delay>的值为“keep”，则报警保持输出。如果\<Delay>的值为5，则报警将保持5秒输出，最大不能超过1800s | 是 | 是 | 不可为空 | 可读可写 | 最大长度32 | 建议值：10 |  | <span class="colour" style="color:rgb(206, 145, 120)">配置-系统设置-I/O报警-报警输出-报警输出延迟</span> |  | <span class="colour" style="color: rgb(85, 85, 85);">无</span> |
| Gate | string | 控制门禁高低电平输出；<span class="colour" style="color:rgb(206, 145, 120)">AlwayClose-</span>常闭，<span class="colour" style="color:rgb(206, 145, 120)">AlwayOpen-</span>常开 | 是 | 是 | 不可为空 | 可读可写 | 动态数组 | 建议值：<span class="colour" style="color:rgb(206, 145, 120)">AlwayClose</span> |  |  |  |  ||
