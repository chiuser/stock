# 设置系统NTP配置
##### 简要描述

- ##### 说明

TimeZone：必须以“CST”开头。

##### 请求

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<NTP>
    <Enable><!--rw,req,xs:boolean; "false","true"--></Enable>
    <ServerName><!--rw,req,xs:string,”example: time.windows.com”--></ServerName>
    <TimeZone><!--rw,req, xs:string, POSIX time zone string,”CST-09:00:00”--></TimeZone>
    <TimeSyncInterval><!--rw,opt,xs:integer--></TimeSyncInterval>
    <IsSynchronizeNTPNow><!--wo,opt, xs:boolean; "false","true"--></IsSynchronizeNTPNow>
</NTP>
```

| ServerName | string | <span class="colour" style="color:rgb(106, 153, 85)">Ntp服务器地址</span> | 是 | 是 | 否 | 可读可写 | 最大长度256 |  | <span class="colour" style="color: rgb(85, 85, 85);">“设置”-时间设置-“模式选择”-网络对时-服务器</span> | <span class="colour" style="color: rgb(206, 145, 120);">配置-系统设置-日期时间-日期/时间-服务器地址</span> |  |  |
