# 获取系统DST配置
##### 简要描述

- ##### 说明

当<Mode>为“date”时，<DateModeStart>和<DateModeStop>有效，当<Mode>为“week”时，<WeekModeStart>和<WeekModeStop>有效
<TimeDifference>单位为秒，例如：3600为3600秒
<DateModeStart>和<DateModeStop>：接受并返回ISO 8601日期/时间字符串。
<WeekModeStart>和<WeekModeStop>：“3-1-1-2-3-6”的第一个数字是3月，第二个是第一个星期的第一个星期，第三个是第一个星期一，第四个星期一 是2小时，第五是3分钟，第六是6秒

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<DST Version="1.0" xmlns="http://www.zwcloud.wang/ver10/XMLSchema">
    <Enable><!--rw,req,xs:boolean; "false","true"--></Enable>
    <Mode><!--rw,req,xs:string,”date,week”--></Mode>
    <TimeDifference><!--rw,req,xs:string, --></TimeDifference>
    <DateModeStart><!---rw,req,xs:datetime,” 20040503T173008+08”--></DateModeStart>
    <DateModeStop><!---rw,req,xs:datetime,” 20040503T173008+08”--></DateModeStop>
    <WeekModeStart><!---rw,req,xs:string,” 3-1-1-2-3-6”--></WeekModeStart>
```
