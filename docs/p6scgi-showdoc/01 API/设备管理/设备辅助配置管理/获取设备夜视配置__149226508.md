# 获取设备夜视配置
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<DeviceNightVisionCfg>
    <NightVisionMode><!-- rw,opt,xs:integer, 夜视模式 ； 0 - 自动模式， 1 - 定时模式， 2 - 关闭补光--></NightVisionMode>
    <StartTime><!-- rw,opt,xs:string, 开灯开始时间，仅在定时模式下生效，格式hh:mm,24小时制--></StartTime>
    <EndTime><!-- rw,opt,xs:string, 开灯结束时间，仅在定时模式下生效，格式hh:mm,24小时制--></EndTime>
    <FillLightBrightness><!-- rw,opt,xs:integer, defualt 20,range [10-50]--></FillLightBrightness>
</DeviceNightVisionCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| NightVisionMode | integer | <span class="colour" style="color:rgb(106, 153, 85)">夜视设置， 0 - 自动模式； 1 - 定时模式； 2 - 关闭补光</span> | 否 | 是 | 否 | 可读可写 | 0/1/2 |  |
| StartTime | string | <span class="colour" style="color:rgb(106, 153, 85)">开灯开始时间，仅在定时模式下生效; 格式hh:mm,24小时制</span> | 否 | 是 | 是 | 可读可写 | 最大长度32 |  |
| EndTime | string | <span class="colour" style="color:rgb(106, 153, 85)">开灯结束时间，仅在定时模式下生效; 格式hh:mm,24小时制</span> | 否 | 是 | 是 | 可读可写 | 最大长度32 |  |
| FillLightBrightness | integer | <span class="colour" style="color:rgb(106, 153, 85)">补光灯亮度，设置范围10%~50%，默认20%</span> | 否 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(106, 153, 85)">默认20，[10,50]</span> |  ||
