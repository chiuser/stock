# 控制辅助接口状态
##### 简要描述

- ##### 说明

重启后恢复之前的接口状态

##### 请求

**xml**

```
<AssistantInterfaceList>
    <AssistantInterface>
        <AssistantInterfaceType><!--rw,req,xs:string”WhiteLight”,”BrustLight”,”InfraredLight”,”PilotLight”,”RedLight”,”GreenLight”--></AssistantInterfaceType>
        <Status><!--rw,req,xs:string”Disable”,”Enable”--></Status>
    </AssistantInterface>
    …
</AssistantInterfaceList>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| AssistantInterface |  |  | 否 |  |  |  |  |  |
| AssistantInterfaceType | string | 辅助接口类型；”WhiteLight”-<span class="colour" style="color:rgb(106, 153, 85)">白光灯</span>,”BrustLight”-<span class="colour" style="color:rgb(106, 153, 85)">爆闪灯</span>,”InfraredLight”-<span class="colour" style="color:rgb(106, 153, 85)">红外灯</span>,”PilotLight”-<span class="colour" style="color:rgb(106, 153, 85)">指示灯</span>,”RedLight”-<span class="colour" style="color:rgb(106, 153, 85)">红灯</span>,”GreenLight”-<span class="colour" style="color:rgb(106, 153, 85)">绿灯</span> | 是 | 是 | 否 | 可读可写 | 动态数组 |  |
| Status | string | 状态，Disable去使能，Enable使能 | 是 | 是 | 否 | 可读可写 | 动态数组 |  ||

##### 响应

**xml**
无
**字段说明**
无

 - `/System/ChannelID/AssistantInterfaceControl`
