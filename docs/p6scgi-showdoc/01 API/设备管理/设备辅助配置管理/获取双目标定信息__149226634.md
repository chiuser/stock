```
<DoubleCameraCalibrationList>
```

| DoubleCameraCalibration |  | 双目标定信息 | 否 | 是 |  |  |  |  |
| ChannelID | integer | IPC通道，从1递增<span lang="EN-US"></span> | <span lang="EN-US"></span>是 | 是 | 否 | 只读 | [1-32] |  |
| Distance | integer | 双目摄像头标定距离；不限制整数值，单位:cm<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| Status | boolean | <span class="colour" style="color:rgb(106, 153, 85)">标定状态；false：未标定 true：已标定</span><span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 只读 | false/true |  ||
