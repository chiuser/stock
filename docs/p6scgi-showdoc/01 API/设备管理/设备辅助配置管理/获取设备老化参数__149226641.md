# 获取设备老化参数
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<AgingTest>
    <Enable><!--rw,opt,xs:boolean--></Enable>
    <Interval><!--rw,opt,xs:integer--></Interval>
</AgingTest>
```

**字段说明**<span lang="EN-US"></span>

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| <span class="colour" style="color:black">Enable</span><span lang="EN-US"></span> | boolean | 设备老化功能是否启动<span class="colour" style="color:rgb(106, 153, 85)">，false-否，true-是</span><span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | false/true |  |
| <span class="colour" style="color:black">Interval</span> | integer | 开启设备老化后，GPIO5\_2/GPIO2\_2 按照此时间间隔定时输出一个方波，单位：ms | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 取值需与设备确认 |  ||

##### 请求URL

 - `/System/ChannelID/AgingTest` 

##### 请求方式

- get
 
##### 成功返回示例  
```
[]

```
