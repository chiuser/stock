# 获取设备绑定配置
##### 简要描述

- ##### 说明

**SCodeValid此字段在Put的时候不要填写(请遵循)**

##### **请求**

**xml**
无
**字段说明**
无

##### **响应**

**xml**

```
<DeviceBindConfig>
    <SCodeValid><!--ro,req,xs:boolean”true”,”false”--></SCodeValid>
    <SCode><!--rw,req,xs:string, the max  length: 64--></SCode>
</DeviceBindConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| SCodeValid | boolean | 绑定码是否有效 | 是 | 是 | 否 | 只读 | false/true |  |
| SCode | string | 绑定码字符串 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  ||

##### 请求URL

 - `/System/DeviceBindConfig` 

##### 请求方式

- get

```
[]
```
