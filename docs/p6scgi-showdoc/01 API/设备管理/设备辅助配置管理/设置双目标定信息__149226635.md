# 设置双目标定信息
##### 简要描述

- ##### 请求

**xml**

```
<DoubleCameraCalibrationInfo>
    <Distance><!--rw,req,xs:integer--></Distance>
</DoubleCameraCalibrationInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Distance | integer | 双目摄像头标定距离；不限制整数值，单位:cm<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 取值需与设备确认 |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/ChannelID/DoubleCameraCalibration` 

##### 请求方式

- put
