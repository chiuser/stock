# 设置平台模式配置
##### 简要描述

- ##### 请求

**xml**

```
<DevicePlatformMode>
    <PlatformMode><!--rw,opt,xs:string,”MQTT”,”MegLink”,”JGPlatform”,”HTTP”,”CUIOT”,”Unknown”--></PlatformMode>
</DevicePlatformMode>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| PlatformMode | string | 平台模式；MQTT-MQTT平台，MegLink-Meglink平台，JGPlatform-济工网平台，HTTP-http平台，CUIOT-联通格物平台，Unknown-未知 | 否 | 是 | 否 | 可读可写 | 动态数组 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/ChannelID/PlatformMode` 

##### 请求方式

- put
 
##### 成功返回示例  
```
{}

```
