# 设置中心服务器配置信息
##### 简要描述

- ##### 请求

**xml**

```
<cms>
    <Enable><!--rw,req,xs:boolean--></Enable>
    <ServerAddress><!--rw,req,xs:string, the max  length: 256--></ServerAddress>
    <Port><!--rw,req,xs:interger--></Port>
    <RegisterInterval><!--rw,req,xs:interger--></RegisterInterval>
</cms>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否启用中心管理服务器，false-否，true-是</span> | 是 | 是 | 否 | 可读可写 | false/true |  |
| ServerAddress | string | <span class="colour" style="color:rgb(106, 153, 85)">远程管理主机地址，长度考虑域名</span> | 是 | 是 | 否 | 可读可写 | 最大长度256 |  |
| Port | integer | <span class="colour" style="color:rgb(106, 153, 85)">远程管理主机端口</span> | 是 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| RegisterInterval | integer | <span class="colour" style="color:rgb(106, 153, 85)">注册间隔时间，单位为秒</span> | 是 | 是 | 否 | 可读可写 | 取值需与设备确认 |  ||

##### 响应

**xml**
无
**字段说明**
无

 - `/System/DeviceCMS` 

##### 请求方式

- put
