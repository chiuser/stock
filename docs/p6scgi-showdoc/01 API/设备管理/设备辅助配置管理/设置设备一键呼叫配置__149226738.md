# 设置设备一键呼叫配置
##### 简要描述

- ##### **请求**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<DeviceOneButtonCall Version="1.0">
    <OneButtonCall><!--wo,opt,xs:boolean,"true,false"--></OneButtonCall>
</DeviceOneButtonCall>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| OneButtonCall | boolean | 一键呼叫;false-挂断一键呼叫,true-接听一键呼叫<span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 只写 | false/true |  ||

##### 响应

**xml**
无
**字段说明**
无
