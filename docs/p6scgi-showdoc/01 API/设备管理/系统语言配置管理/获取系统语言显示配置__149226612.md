# 获取系统语言显示配置
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### **响应**

**xml**

```
<LanguageDisplayStatusList>
    <ChannelID><!--ro,req,xs:Integer--></ChannelID>
    <LanguageDisplayStatus>
        <LanguageIndex><!--ro,req,xs:Integer--></LanguageIndex>
        <LanguageKey><!--ro,req,xs:string, the max length : 32 --></LanguageKey>
        <LanguageName><!--ro,req,xs:string, the max length : 32--></LanguageName>
        <IsDisplay><!--ro,req,xs:boolean,”true”,”false”--></IsDisplay>
    </LanguageDisplayStatus>
…
</LanguageDisplayStatusList>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ChannelID | integer | 通道ID，自1递增 | 是 | 是 | 否 | 只读 | [1-32] |  |
| LanguageDisplayStatus |  | 系统语言显示配置状态 | 否 |  |  |  |  |  |
| LanguageIndex | integer | 语言索引 | 是 | 是 | 否 | 只读 | 取值需与设备确认 |  |
| LanguageKey | string | 语言键 | 是 | 是 | 否 | 只读 | 最大长度32 |  |
| LanguageName | string | 语言名称 | 是 | 是 | 否 | 只读 | 最大长度32 |  |
| IsDisplay | boolean | 是否显示<span class="colour" style="color:rgb(106, 153, 85)">，false-否，true-是</span> | 是 | 是 | 否 | 只读 | false/true |  ||

##### 请求URL

 - `/System/ChannelID/LanguageDisplayStatus` 

##### 请求方式

- get
