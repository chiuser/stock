# 获取设备能力
##### 简要描述

- ##### 说明

随着设备的升级和功能的增加，以下XML不断更新。
详情见 [http://cap.p6sai.com/DeviceCap.htm](http://cap.p6sai.com/DeviceCap.htm)

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<Device>										
    <AlarmOutCount><!--ro,req,xs:integer--></AlarmOutCount>
    <AlarmInCount><!--ro,req,xs:integer--></AlarmInCount> 			
    <FunctionList>
        <SD><!--ro,req,xs:boolean--></SD>
        <WIFI><!--ro,req,xs:boolean--></WIFI>
        <TwoWayAudio><!--ro,req,xs:boolean--></TwoWayAudio>
        <AP><!--ro,req,xs:boolean--></AP>
        <Wavelink><!--ro,req,xs:boolean--></Wavelink>
        <Smartlink><!--ro,req,xs:boolean--></Smartlink>
        <Email><!--ro,req,xs:boolean--></Email>
        <FTP><!--ro,req,xs:boolean--></FTP>
        <RemoteReboot><!--ro,req,xs:boolean--></RemoteReboot> 
        <Restore><!--ro,req,xs:boolean--></Restore>
        <PasswordModify><!--ro,req,xs:boolean--></PasswordModify>
    </FunctionList>
    <FunctionListAboutChannel>
        <ChannelList>
            <Channel ChannelID="0"> 
                <Audio><!--ro,req,xs:boolean--></Audio>
                <Motion><!--ro,req,xs:boolean--></Motion>
                <EnablePedestrianfiltering><!--ro,opt,xs:boolean--></EnablePedestrianfiltering>
                <ColorNight><!--ro,req,xs:boolean--></ColorNight>
                <IntelligentNight><!--ro,req,xs:boolean--></IntelligentNight>
                <MotionSenstive>
                    <Highest><!--ro,req,xs:boolean--></Highest>
                    <Higher><!--ro,req,xs:boolean--></Higher>
                    <High><!--ro,req,xs:boolean--></High>
                    <Middle><!--ro,req,xs:boolean--></Middle>
                    <Low><!--ro,req,xs:boolean--></Low>
                    <Lower><!--ro,req,xs:boolean--></Lower>
                    <Lowest><!--ro,req,xs:boolean--></Lowest>
                </MotionSenstive>
                <multi_osd><!--ro,req,xs:boolean--></multi_osd>
                <mosd_cnt><!--ro,req,xs:integer--></mosd_cnt>
                <mosd_cord><!--ro,req,xs:integer--></mosd_cord>
            </Channel>
        </ChannelList>
    </FunctionListAboutChannel>
</Device>
```
