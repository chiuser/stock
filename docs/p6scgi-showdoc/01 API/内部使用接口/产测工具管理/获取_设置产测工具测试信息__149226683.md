# 获取/设置产测工具测试信息
##### 简要描述

- ##### 请求

**xml**

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<ProductTestTool>
    <CmdType><!--wo,req,xs:string--></CmdType>
    <MainType><!--wo,req,xs:integer--></MainType>
    <SubType><!--wo,req,xs:integer--></SubType>
    <Info><!--wo,opt,xs:string--></Info>
</ProductTestTool>
```

**字段说明**<span lang="EN-US"></span>

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| CmdType | string | 命令类型<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 只写 | 动态数组 |  |
| MainType | integer | 主命令值<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 只写 | 取值需与设备确认 |  |
| SubType | integer | 次命令值<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 只写 | 取值需与设备确认 |  |
| Info | string | 扩展信息，自定义<span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 是 | 只写 | 动态数组 |  ||
