# 获取产测工具台灯配置
##### 简要描述

- ##### **请求**

**xml**
无
**字段说明**
无

##### 响应

**XML**

```
<?xml version = "1.0" encoding = "utf-8"?>
<LampCfg Version="1.0">
    <LampSwitch><!-- rw,opt,xs:boolean, true,false --></LampSwitch>
    <LampBrightness><!-- rw,opt,xs:integer,range [0-100], --></LampBrightness>
</LampCfg>
```

**字段解释**<span lang="EN-US"></span>

| 字段 | 类型 | 功能描述 | 是否必须 | 字段是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | ---- | :--- | ------ | ----- | ---------------------- | ------- | --- |
| LampSwitch | boolean | 台灯开关;0-关,1-开 <span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | false/true |  |
| LampBrightness | integer | 台灯亮度;0-100 | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | [0,100] |  ||
