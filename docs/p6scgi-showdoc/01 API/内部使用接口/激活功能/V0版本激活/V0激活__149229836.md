# V0激活
## 简介
1.内置激活叫激活码，外置激活叫激活文件
2.V0仅支持内置激活，且最多支持激活32个功能

## 流程图
![](http://zwp2p.p6sai.com:4999/server/index.php?s=/api/attachment/visitFile&sign=343bd4918e8668430ea8eed60ffde30f)

### 激活功能流程
1. 客户端通过/System/DeviceInfo获取设备激活信息，并根据响应信息中的是否包含ActiveMethodV2字段及ActiveMethodV2的值，判断设备是否支持V2版本激活，若有ActiveMethodV2字段，且ActiveMethodV2=true表示设备支持V2版本激活，反之不支持
2. 若设备不支持V2版本激活，根据客户端支持的激活功能版本，选择V0版本或V1版本激活，
3. V0版本激活(仅支持内置激活),客户端选择要激活的功能，然后通过/System/DeviceInfo PUT请求设置内置激活功能

## 接口说明
##### 激活码信息
**/System/DeviceInfo**  支持GET和PUT
[GET](http://zwp2p.p6sai.com:4999/web/#/663863654/149226518 "GET")请求用于获取设备的激活功能及对应的激活状态，若获取的xml中包含ActiveMethodV2字段，且ActiveMethodV2=true表示设备支持V2版本激活，反之不支持
[PUT](http://zwp2p.p6sai.com:4999/web/#/663863654/149226519 "PUT")请求用于激活设备的功能，仅只支持V0版本激活(内置激活)，且一个激活码对应多个功能，每一次激活时都是以覆盖的方式来激活功能
