# V2激活
## 简介
1.内置激活叫激活码，外置激活叫激活文件
2.V2支持内置激活和外置激活，同时支持激活32个以上的功能

## 流程图
![](http://zwp2p.p6sai.com:4999/server/index.php?s=/api/attachment/visitFile&sign=7cfd747cbc269bd8974e5a7b60e82ced)

### 激活功能流程
1. 客户端通过/System/DeviceInfo获取设备激活信息，并根据响应信息中的是否包含ActiveMethodV2字段及ActiveMethodV2的值，判断设备是否支持V2版本激活，若有ActiveMethodV2字段，且ActiveMethodV2=true表示设备支持V2版本激活，反之不支持
2. V2版本激活，客户端通过/System/ActiveStatusInfoList获取激活信息，客户端选择要激活的功能，若是内置激活功能，则向服务器获取激活码，再通过/System/DeviceConfigFile POST请求激活功能，若是外置激活，则先通过/System/DeviceConfigFile GETT请求从设备获取指纹文件，通过指纹文件向服务器获取授权文件，最后使用授权文件通过/System/DeviceConfigFile POST请求激活功能，V2版本激活的/System/DeviceConfigFile POST请求中新增了ActiveIndexArray，表示V2版本的激活掩码

## 接口说明
##### 激活码信息
**/System/DeviceInfo**  支持GET和PUT
[GET](http://zwp2p.p6sai.com:4999/web/#/663863654/149226518 "GET")请求用于获取设备的激活功能及对应的激活状态，若获取的xml中包含ActiveMethodV2字段，且ActiveMethodV2=true表示设备支持V2版本激活，反之不支持

##### 激活状态信息列表
[/System/ActiveStatusInfoList](http://zwp2p.p6sai.com:4999/web/#/663863654/149229637 "/System/ActiveStatusInfoList") 仅支持GET，不支持PUT，用于获取设备激活状态信息，调用这个url前，需先调用/System/DeviceInfo判断设备是否支持V2版本激活

##### 激活
**/System/DeviceConfigFile**
[GET](http://zwp2p.p6sai.com:4999/web/#/663863654/149226541 "GET")请求用于获取设备的指纹文件
参数FileType表示文件类型，激活功能中FileType=26；
参数EncryptType表示文件的加密类型，EncryptType=0 表示DES加密，EncryptType=1表示TDES加密，
参数m表示要激活的功能，参数内容最大长度是18个字节，从左到右，每两个字符为一组，表示激活功能序号对应的十六进制值，eg：m=31，表示0x31，对应激活第个49功能，m=314671，表示0x31，0x46，0x71，对应激活第49、70、113个功能，依此类推；
详见接口文档
[POST](http://zwp2p.p6sai.com:4999/web/#/663863654/149226543 "POST")请求用于激活功能，支持V2版本激活，支持激活32个以上的功能；请求消息如下：
```
<DeviceConfigFile>
    <FileType>26</FileType>
    <FileList>
        <AuthFile>
            <ActivedFeatureMask>28</ActivedFeatureMask>
            <ActiveIndexArray>1，2，3</ActiveIndexArray>
            <ActivationType>0</ActivationType>
            <ActiveCode>C6B18DFCCE923AB7</ActiveCode>
            <AuthFileInfo>eyJmIjoiODltbzNHb05ORGovWTgvQmx5RlFlR3NML1JhTDFOdm0zNldYUWJQWENiWnc1Z0ZGK1B4b08zdkxJRlkrNE1qbyIsImkiOiJOMTk1OTE5RUY2RTRFRjJBQUQyOTg3NCIsInQiOiJUNDFfQ09NQy44NzAuOTkwIiwidiI6IlYzLjAuMCJ9</AuthFileInfo>
        </AuthFile>
    </FileList>
</DeviceConfigFile>
```
