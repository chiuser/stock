# 设置设备配置文件(POST)
##### 简要描述

- ##### 说明

_GET:格式如下：[http://192.168.3.166/System/DeviceConfigFile?FileType=8](http://192.168.3.166/System/DeviceConfigFile?FileType=8)_
_PUT:有一个参数是“FileType”是文件类型，类型值由eTransferFileType决定。_

该 URL 当 FileType 为 8 时为旷世激活。支持两种方式的激活，单个激活和多个算法激活

_单个激活，比如:_
_URL：[http://192.168.3.166/System/DeviceConfigFile](http://192.168.3.166/System/DeviceConfigFile)_
_数据格式:_
_  PUT /System/DeviceConfigFile HTTP/1.1\r\n_
_  Connection:close\r\n_
_  Host: 192.168.3.166\r\n_
_  Content-Length:\r\n_
_\r\n_
_FileType=8&EncryptType=1_...
   其中…表示的就是要上传的数据。

多个激活：
_URL：[http://192.168.3.166/System/DeviceConfigFile](http://192.168.3.166/System/DeviceConfigFile)_
_数据格式:_
_  PUT /System/DeviceConfigFile HTTP/1.1\r\n_
_  Connection:close\r\n_
_  Host: 192.168.3.166\r\n_
_  Content-Length:\r\n_
_\r\n_

##### POST请求

**xml**

```
<DeviceConfigFile>
   <FileType><！-- wo,req,xs:interger, 文件类型--></FileType>
   <EncryptType><！-- wo,req,xs:interger, 是否 Des 加密；0，否，1，是--></FileType>
   <FileList>
       <AuthFile>
           <ActivationType><!-- wo,req,xs:interger,表示激活类型，0 - 内部激活，1 - 旷视激活--><ActivationType/>
           <!--当激活类型为内部激活时才会有激活码字段-->
           <ActiveCode><！-- wo,req,xs:string, 激活码--></ActiveCode>
           <ActivedFeatureMask><!-- wo,req,xs:interger, V1版本激活掩码--></ActivedFeatureMask>
           <AuthFileInfo><_!--wo,req,xr::string,_授权文件信息，需要经过 base64 编码 --></AuthFileInfo>
		   <ActiveIndexArray><！-- wo,req,xs:string, V2版本的激活码--></ActiveIndexArray>
       </AuthFile>
   <FileList>
</DeviceConfigFile>
```
