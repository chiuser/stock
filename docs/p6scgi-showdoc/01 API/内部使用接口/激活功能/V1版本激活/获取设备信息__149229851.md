# 获取设备信息
##### 简要描述

- ##### 说明

可以设置<DeviceName>和<ActiveCode>。不设置其他。
<ActiveStatus>“成功”表示活动成功，或者是“无效的活动代码”
<IsSupportActiveCode>，如果此字段为false，则客户端不应显示“活动代码”和“活动状态”字段。

##### 请求

**xml**
无
**字段说明**
无
