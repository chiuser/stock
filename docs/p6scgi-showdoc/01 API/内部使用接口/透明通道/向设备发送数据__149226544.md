# 向设备发送数据
##### 简要描述

- ##### 说明

<Data>请将要发送的数据放入字符串类型。数据格式为“12 23 ff fe fc”，最大数量为32.数值范围为0 - ff
“majorType”的值是数字，如0,1,2 ......，当值为0时，串口的类型为RS232，当值为1时，串口类型为RS485，当 值为2，串口类型为RS422。
“minorType”的值也是0,1,2 ......等数字，默认值为0。
     默认值为majorType的值为2，minorType的值为0.其他不支持。
波特率取决于URL /PTZ/ChannelID/Config。
比如：
[http://192.168.1.171/System/TransparentChannel/WriteOnce?majorType=2&minorType=0](http://192.168.1.171/System/TransparentChannel/WriteOnce?majorType=2&minorType=0)

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<TransparentChannelWriteonce><!--req-->
    <Data><!--wo,req,xs:string,  the max length : 256--></Data>
</TransparentChannelWriteonce>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Data | string | <span class="colour" style="color:rgb(106, 153, 85)">发送的数据</span> | 是 | 是 | 是 | 只写 | 最大长度256 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/TransparentChannel/WriteOnce`
