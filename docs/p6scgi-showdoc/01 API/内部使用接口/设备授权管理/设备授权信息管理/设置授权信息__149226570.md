# 设置授权信息
##### 简要描述

- ##### 说明

AuthInfo为空的时候代表取消激活

##### 请求

<span class="colour" style="color:rgb(85, 85, 85)">**xml**</span>

```
<Auth>
    <AuthInfo><!--rw,req,xs:string,  the max length : 512--></AuthInfo>
    <MAC><!--rw,req,xs:string--></MAC>
</Auth>
```

<span class="colour" style="color:rgb(85, 85, 85)">**字段说明**</span>

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| AuthInfo | string | <span class="colour" style="color:rgb(106, 153, 85)">授权信息，目前仅仅只是授权码</span> | 是 | 是 | 否 | 可读可写 | 最大长度512 |  |
| MAC | string | mac地址 | 否 | 是 | 否 | 可读可写 | 动态数组 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/AuthInfo` 

##### 请求方式

- put
 
##### 成功返回示例  
```
{}

```
