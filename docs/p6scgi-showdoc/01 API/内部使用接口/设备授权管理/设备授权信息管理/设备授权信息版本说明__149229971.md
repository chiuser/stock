# 设备授权信息版本说明
#### 版本说明
设备授权信息有V1、V2两个版本，区别在于功能不同

#### 设备信息V1版本
设备授权信息V1版本主要用于获取和设置设备的授权码和MAC地址

#### 设备信息V2版本
设备授权信息V2版本主要用于设置设备P2P相关配置和服务器信息
