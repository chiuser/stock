# 设置授权信息V2
##### 简要描述

- ##### 请求

**xml**

```
<Auth>
    <AuthInfo><!--wo,req,xs:string, the max length : 256--></AuthInfo>
    <MAC><!--wo,req,xs:string--></MAC>
    <P2PConnectInfo>
        <PlatformName><!--wo,req,xs:string, the max length : 16--></PlatformName>
        <Server><!--wo,req,xs:string, the max  length : 256--></Server>
        <AuthWord><!--wo,req,xs:string, the max  length : 32--></AuthWord>
        <DomainList>
            <Domain>
                <Address><!--wo,req,xs:string, the max  length : 64--></Address>
                <IP><!--wo,req,xs:string, the max  length : 16--></IP>
            </Domain>
            …
        </DomainList>
        <PushDomainList>
            <Domain>
                <Address><!--wo,req,xs:string,  the max length : 64--></Address>
            </Domain>
            …
        </PushDomainList>
        <Transparent><!--wo,req,xs:string,  the max length : 1024--></Transparent>
    </P2PConnectInfo>
</Auth>
```
