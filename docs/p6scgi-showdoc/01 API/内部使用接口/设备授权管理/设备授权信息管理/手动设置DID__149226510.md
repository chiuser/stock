# 手动设置DID
##### 简要描述

- ##### 请求

**xml**

```
<?xml version = "1.0" encoding = "utf-8"?>
<ApplyDIDManulCfg>
    <RequestUrl><!-- wo,opt,xs:string,max size 256，请求url(协议+服务器地址/域名+服务器端口+资源路径+参数等,例：http://192.168.1.102/system/zzz,注:可以为空)--></RequestUrl>
</ApplyDIDManulCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| RequestUrl | string | <span class="colour" style="color:rgb(106, 153, 85)">请求url(协议+服务器地址/域名+服务器端口+资源路径+参数等,例：[http://192.168.1.102/system/zzz,注:可以为空](http://192.168.1.102/system/zzz,%E6%B3%A8:%E5%8F%AF%E4%BB%A5%E4%B8%BA%E7%A9%BA)</span> | 否 | 是 | 否 | 只写 | 最大长度256 |  |  | <span class="colour" style="color:rgb(206, 145, 120)">配置-网络-P2P设置-获取</span> |  |  ||
