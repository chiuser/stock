# 设备信息版本说明
#### 版本说明
设备信息有V1、V2两个版本，区别在于功能不同

#### 设备信息V1版本
设备信息V1版本用于设备功能的激活、查询当前设备功能的激活状态

#### 设备信息V2版本
设备信息V2版本主要用于设备序列号的获取和设置
