# 获取设备信息V2版本
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<DeviceInfoV2>
    <SerialCustom><!--ro,req,xs:boolean--></SerialCustom>
    <SerialNumber><!--rw,req,xs:string,  the max length: 32--></SerialNumber>
</DeviceInfoV2>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| SerialCustom | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否序列定制：远程只读；false-否，true-是</span> | 是 | 是 | 否 | 只读 | false/true |  |
| SerialNumber | string | <span class="colour" style="color:rgb(106, 153, 85)">序列号，最大长度32</span> | 是 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(106, 153, 85)">最大长度32</span> |  ||
