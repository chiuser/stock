# 设置指定通道图像的ircut配置的扩展配置
##### 简要描述

##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<IrCutFilterEx>
    <LightSceneControlMode><!--rw,opt,xs:interger,0,1 --></LightSceneControlMode>
    <SceneMode><!--rw,dep,xs:interger,0,6 --><SceneMode>
</IrCutFilterEx>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| <span class="colour" style="color:rgb(0, 0, 0)">LightSceneControlMode</span> | <span class="colour" style="color:rgb(85, 85, 85)">integer</span> | 灯光场景控制模式：<span class="colour" style="color:rgb(85, 85, 85)">0--场景配置模式 1--专家模式</span> | 否 | 是 | 否 | 可读可写 | 0,1 |  |
| <span class="colour" style="color:rgb(0, 0, 0)">SceneMode</span> | <span class="colour" style="color:rgb(85, 85, 85)">integer</span> | <span class="colour" style="color:rgb(85, 85, 85)">场景模式（灯光场景控制模式为0时生效）：0-星光全彩, 1-智能全彩, 2-定时模式. 3-全彩夜视. 4-黑白夜视. 5-智能双光</span> | 否 | 是 | 否 | 可读可写 | [0,6] |  ||

##### 请求URL

 - `/Images/ChannelID/IrCutFilterEx` 

##### 请求方式

- put
