# 设置马赛克相关配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Mosaic>
    <Enable><!--rw,req,xs:boolean; "false","true"--></Enable>
    <MosaicRegionList>
        <Region><!--opt-->
            <ID><!--wo,req,xs:integer--></ID>
            <TopLeftX><!--wo,req,xs:integer,0-703--></TopLeftX>
            <TopLeftY><!--wo,req,xs:integer,0-575--></TopLeftY>
            <BottomRightX><!--wo,req,xs:integer,0-703--></BottomRightX>
            <BottomRightY><!--wo,req,xs:integer,0-575--></BottomRightY>
        </Region>
    </MosaicRegionList>
</Mosaic>
```
