# 获取指定通道OSD配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
在设置OSD配置时，不要让时间坐标和名称坐标相同。 另外，OSD的坐标值的精度为8，也就是说如果这些数字设置为8,9,10,11,12,13,14,15过去，则重新获取时仍为8。

##### 请求

**xml**
无
**字段说明**
无
