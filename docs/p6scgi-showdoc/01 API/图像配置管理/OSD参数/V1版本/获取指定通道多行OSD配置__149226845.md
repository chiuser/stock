# 获取指定通道多行OSD配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
在设置OSD配置时，不要让时间坐标和名称坐标相同。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<MultiOSD>
    <OSD><!--req-->
        <ID><!--rw,req,xs:interger--></ID>
        <Text><!--rw,req,xs:string--></Text>
        <x><!--rw,req,xs:integer,0-703--></x>
        <y><!--rw,req,xs:integer,0-575--></y>
    </OSD>
    …
    <Resolution>
        <Show><!--rw,req,xs:boolean”true”,”false”--></Show>
        <x><!--rw,req,xs:integer,0-703--></x>
        <y><!--rw,req,xs:integer,0-575--></y>
    </Resolution>
    <Bitrate>
        <Show><!--rw,req,xs:boolean”true”,”false”--></Show>
        <x><!--rw,req,xs:integer,0-703--></x>
        <y><!--rw,req,xs:integer,0-575--></y>
    </BitRate>
</MultiOSD>
```
