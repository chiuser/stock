# 设置指定通道多行OSD配置V2
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
在设置OSD配置时，不要让时间坐标和名称坐标相同。
OSD节点的Text标签多行OSD之间使用^分隔
假设第一行OSD为”你好”，第二行为”世界”
则Text标签为
<Text>你好^世界</Text>

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<MultiLineOSD>
    <Version><!--rw,option,xs:string, “V4”--></Version>
    <OSDKind><!--rw,option,xs:string, “TextOSD”，“PictureOSD”--></OSDKind>
    <DisplayTime><!--req-->
        <Enable><!--rw,req,xs:boolean--></Enable>
        <PosX><!--rw,req,xs:integer,0-703--></PosX>
        <PosY><!--rw,req,xs:integer,0-575--></PosY>
    </DisplayTime>
    <OSD><!--req-->
        <ID><!--rw,req,xs:interger--></ID>
        <Enable><!--rw,req,xs:boolean,"true,false"--></Enable>
        <Text><!--rw,req,xs:string, the max lengt: 512--></Text>
        <x><!--rw,req,xs:integer,0-703--></x>
        <y><!--rw,req,xs:integer,0-575--></y>
    </OSD>
</MultiLineOSD>
```
