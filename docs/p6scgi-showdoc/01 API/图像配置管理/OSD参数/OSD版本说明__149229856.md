# OSD版本说明
###简介
OSD共有4个版本
####V0版本
url：/Pictures/ChannelID/OSD
说明：最早的OSD，只支持显示一个OSD，且不支持换行
####V1版本
url：/Pictures/ChannelID/MultiOSD
说明：最多支持8个OSD，支持换行,设备端以文本的形式将OSD坐标、文字内容、分辨率、码率等以特殊字符拼接后保存在一个变量
####V2版本
url：/Pictures/ChannelID/MultiOSDV2
说明：最多支持4个OSD，支持换行,设备端以文本的形式将文字内容、分辨率、码率等以特殊字符拼接后保存在一个变量，OSD坐标和时间单独保存
####V3版本
url：/Pictures/ChannelID/MultiOSDV2
说明：以前V0-V2版本OSD均依赖字库，设备的Flash的空间有限没法放入很多的字库，且支持不同语言存在对接的工作量。传统方式比较复杂且受限，在V2版本上支持通过位图的方式兼容不同国家的语言配置。


#### APP
app只使用了/Pictures/ChannelID/OSD 和 V2版本、V3版本的/Pictures/ChannelID/MultiOSDV2
1.若设备能力支持 mosd_cntv2和 MatrixOSD，则app调用V3版本的/Pictures/ChannelID/MultiOSDV2;
2.若设备能力支持 mosd_cntv2, 不支持MatrixOSD，则app调用V2版本的/Pictures/ChannelID/MultiOSDV2;
3.若设备能力不支持 mosd_cntv2, 不支持MatrixOSD，则app调用/Pictures/ChannelID/OSD;

#### EasyVMS
1.若设备能力支持 mosd_cntv2和 MatrixOSD，则调用V3版本的/Pictures/ChannelID/MultiOSDV2;
2.若设备能力支持 mosd_cntv2, 不支持MatrixOSD，则调用V2版本的/Pictures/ChannelID/MultiOSDV2;
3.若设备能力不支持 mosd_cntv2, 不支持MatrixOSD，支持multi_osd且mosd_cnt> 1 则调用/Pictures/ChannelID/MultiOSD;
4.若设备能力不支持 mosd_cntv2, 不支持MatrixOSD，不支持multi_osd 则调用/Pictures/ChannelID/OSD;

#### NVR
nvr只使用了/Pictures/ChannelID/OSD 和 V2版本、V3版本的/Pictures/ChannelID/MultiOSDV2
1.若设备能力支持 mosd_cntv2和 MatrixOSD，则调用V3版本的/Pictures/ChannelID/MultiOSDV2;
2.若设备能力支持 mosd_cntv2, 不支持MatrixOSD，则调用V2版本的/Pictures/ChannelID/MultiOSDV2;
3.若设备能力不支持 mosd_cntv2, 不支持MatrixOSD，则调用/Pictures/ChannelID/OSD;
