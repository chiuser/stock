# 获取指定通道图像的ircut配置的扩展配置
##### 简要描述

##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**
无
**字段说明**
无

##### **响应**

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<IrCutFilterEx>
    <LightSceneControlMode><!--rw,opt,xs:interger,0,1 --></LightSceneControlMode>
    <SceneMode><!--rw,dep,xs:interger,0,6 --><SceneMode>
</IrCutFilterEx>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- |
| <span class="colour" style="color:rgb(0, 0, 0)">LightSceneControlMode</span> | integer | 灯光场景控制模式：0--场景配置模式 1--专家模式 | 是 | 是 | 否 | 可读可写 | 0,1 |  |  |
| <span class="colour" style="color:rgb(0, 0, 0)">SceneMode</span> | integer | 场景模式（灯光场景控制模式为0时生效）：0-星光全彩, 1-智能全彩, 2-定时模式. 3-全彩夜视. 4-黑白夜视. 5-智能双光 | 是 | 是 | 否 | 可读可写 | [0-6] |  | | |

##### 请求URL

 - `/Images/ChannelID/IrCutFilterEx` 

##### 请求方式

- get

[]
