# 设置指定通道的ISP的白平衡相关配置
##### 简要描述

##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
当<Mode>为“manual”时，<GainRed>和<GainBlue>有效，否则无效。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<WhiteBlance>
    <Mode><!--rw,req,xs,string,”auto,incandescent,warm,fluorescent,natural,manual,Locked,auto,indoor,outdoor,whitebalance1,whitebalance2”--></Mode>
    <GainRed><!--rw,req,xs:integer,0-100--></GainRed>
    <GainBlue><!--rw,req,xs:integer,0-100--></GainBlue>
</WhiteBlance>
```
