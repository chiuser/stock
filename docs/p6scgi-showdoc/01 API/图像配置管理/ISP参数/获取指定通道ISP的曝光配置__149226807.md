# 获取指定通道ISP的曝光配置
##### 简要描述

##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Exposure>
    <IrisType><!--rw,req,xs:string,”manual, DC-Iris”--></IrisType>
    <shutter><!--rw,req,xs:string,”auto, 1/1, 1/2, 1/3, 1/8, 1/12, 1/15,1/25,1/30,1/50,1/60,1/100, 1/120, 1/240, 1/480, 1/960, 1/1000, 1/2000, 1/4000, 1/8000, 1/10000,”--></shutter>
    <Gain><!--rw,req,xs:string,”auto,6dB,12dB,18dB,24dB,30dB,36dB,42dB” --></Gain>
    <Shuttermode><!--rw,req,xs:string,”auto,manual”--></Shuttermode>
</Exposure>
```
