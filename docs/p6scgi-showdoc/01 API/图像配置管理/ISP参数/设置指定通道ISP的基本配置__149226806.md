# 设置指定通道ISP的基本配置
##### 简要描述

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Basic>
    <powerLineFrequencyMode><!--rw,req,xs:string, "50HZ","60HZ","close" --></powerLineFrequencyMode>
    <NoiseReduce><!--rw,req,xs:string,”close,weak,normal,strong”--></NoiseReduce>
    <BLC><!--rw,req,xs:string,”close,open,notsupport”--></BLC>
    <WDR><!--rw,req,xs:string, “close,weak,normal,strong,automatic,notsupport”--></WDR>
    <FlipMode><!--rw,req,xs:string,”close,leftright,updown,center,notsupport”--></FlipMode>
    <powerLineFrequencyStrength><!--rw,opt,xs:string,”strong,weak,close”--></powerLineFrequencyStrength>
</Basic>
```
