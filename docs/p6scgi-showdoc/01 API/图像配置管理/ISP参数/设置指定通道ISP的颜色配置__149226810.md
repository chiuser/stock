# 设置指定通道ISP的颜色配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
<Mode>显示自动调整亮度。当模式为“auto”时，设置<Brightness>字段的值不被触发，当模式为“manual”时，设置<Brightness>字段的值有效。 不支持的设备，设置<Brightness>字段的值始终有效。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Color>
    <Mode><!--rw,req,xs:string,”auto,manual,notsupport”--></Mode>
    <Brightness><!--rw,req,xs:integer,0-100--></Bright>
    <Contrast><!--rw,req,xs:integer,0-100--></Contrast>
    <Saturation><!--rw,req,xs:integer,0-100--></Saturation>
    <Hue><!--rw,req,xs:integer,0-100--></Hue>
    <Sharpness><!--rw,req,xs:integer,0-100--></Sharpness>
</Color>
```
