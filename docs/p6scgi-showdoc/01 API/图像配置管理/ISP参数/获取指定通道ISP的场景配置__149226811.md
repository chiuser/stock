# 获取指定通道ISP的场景配置
##### 简要描述

##### 说明

URI中的<ChannelID>显示通道编号，<ChannelID>从1开始。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Scene>
    <Support><!--rw,req,xs:boolean; "false","true"--></Support>
    <Mode><!--rw,req,xs:string,”standard,soft,vivid,custom”--></Mode>
    <LDC><!--rw,req,xs:boolean; "false","true" --></LDC>
    <Fog><!--rw,req,xs:boolean; "false","true" --></Fog>
    <FogValue><!--rw,req,xs:interger,0-100--></FogValue>
    <Corridor><!--rw,req,xs:boolean; "false","true" --></Corridor>
    <Gamma><!--rw,req,xs:interger,0-100--></Gamma>
</Scene>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Scene |  | <span class="colour" style="color:rgb(106, 153, 85)">场景模式</span> | 是 | 是 |  |  |  |  |
| Support | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否支持场景模式；false，表示不支持，true，表示支持</span> | 是 | 是 | 否 | 可读可写 | false/true |  |
| Mode | string | <span class="colour" style="color:rgb(106, 153, 85)">场景模式；选项为“标准”（值为</span><span class="colour" style="color:rgb(206, 145, 120)">standard</span><span class="colour" style="color:rgb(106, 153, 85)">）、“柔和”（值为</span><span class="colour" style="color:rgb(206, 145, 120)">soft</span><span class="colour" style="color:rgb(106, 153, 85)">）、“鲜艳”（值为</span><span class="colour" style="color:rgb(206, 145, 120)">vivid</span><span class="colour" style="color:rgb(106, 153, 85)">）、“自定义”（值为</span><span class="colour" style="color:rgb(206, 145, 120)">custom</span><span class="colour" style="color:rgb(106, 153, 85)">）</span> | 是 | 是 | 否 | 可读可写 | 最大长度32 |  |
| LDC | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否支持LDC处理；false，表示不支持LDC，true，表示支持LDC</span> | 是 | 是 | 否 | 可读可写 | false/true |  |
| Fog | boolean | <span class="colour" style="color:rgb(106, 153, 85)">当前是启用去雾；false,表示关闭，true表示启用</span> | 是 | 是 | 否 | 可读可写 | false/true |  |
| FogValue | integer | <span class="colour" style="color:rgb(106, 153, 85)">去雾模式开启时可以设置去雾等级（0-100）</span> | 是 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(106, 153, 85)">（0-100）</span> |  |
| Corridor | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否支持走廊模式,；false, 表示不支持, true, 表示支持</span> | 是 | 是 | 否 | 可读可写 | false/true |  |
| Gamma | integer | <span class="colour" style="color:rgb(106, 153, 85)">校正值；0-100</span> | 是 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(106, 153, 85)">0-100</span> |  ||

##### 请求URL

 - `/Images/ChannelID/Scene` 

##### 请求方式

- get
