# 获取设备睡眠信息
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<DeviceSleepInfo>
    <SleepStatus><!--rw,opt,xs::interger,0,休眠，1，唤醒--></SleepStatus>
    <Enable><!--rw,opt,xs::boolean--></Enable>
    <SleepEndTime>
        <Lhour><!--rw,req,xs:integer, 距离睡眠结束的时间 0-23代表具体时间点--></Lhour>
        <Lweekday><!--rw,req,xs:integer; 距离睡眠结束的时间 0-6代表星期一到星期日--></Lweekday>
    </SleepEndTime>
    <Schedule>
        <AllDay><!--rw,req,xs:boolean--></AllDay>
        <TimeBlockList>
            <TimeBlock_0><!--rw,req,xs:string--></TimeBlock_0>
            <TimeBlock_1><!--rw,req,xs:string--></TimeBlock_1>
            <TimeBlock_2><!--rw,req,xs:string--></TimeBlock_2>
            <TimeBlock_3><!--rw,req,xs:string--></TimeBlock_3>
            <TimeBlock_4><!--rw,req,xs:string--></TimeBlock_4>
            <TimeBlock_5><!--rw,req,xs:string--></TimeBlock_5>
            <TimeBlock_6><!--rw,req,xs:string--></TimeBlock_6>
        <TimeBlockList>
    </Schedule>
</DeviceSleepInfo>
```
