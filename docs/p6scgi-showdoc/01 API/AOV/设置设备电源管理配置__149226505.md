# 设置设备电源管理配置
##### 简要描述

- ##### 请求

**xml**

```
<DevicePowerManageCfg>
    <WorkMode><!-- rw,opt,xs:integer, 工作模式 ； 0 - 节能模式， 1 - 性能模式,  2 - 自定义模式--></WorkMode>
    <EnergyConserThre><!-- rw,opt,xs:integer,全时录像模式 ； 10 ~ 50--></EnergyConserThre>
    <DeviceWorkMode><!-- rw,opt,xs:integer,设备工作模式， 0 - 混电模式； 1 - 低功耗模式； 2 - 省电模式； 3 - 常电模式； 4 - AOV 模式--></DeviceWorkMode>
    <AovSleepCycle><!-- rw,opt,xs:integer,AOV下休眠周期（单位：秒，nWorkMode为自定义模式下生效）--></AovSleepCycle>
</DevicePowerManageCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| WorkMode | integer | <span class="colour" style="color:rgb(106, 153, 85)">是否启用，0 - 节能模式， 1 - 性能模式， 2 - 自定义模式</span> | 否 | 是 | 否 | 可读可写 | 0/1/2 |  |
| EnergyConserThre | integer | <span class="colour" style="color:rgb(106, 153, 85)">切换全时录像模式电量阈值， 10 ~ 50</span> | 否 | 是 | 否 | 可读可写 | [10,50] |  |
| DeviceWorkMode | integer | <span class="colour" style="color:rgb(106, 153, 85)">设备工作模式， 0 - 混电模式； 1 - 低功耗模式； 2 - 省电模式； 3 - 常电模式； 4 - AOV 模式</span> | 否 | 是 | 否 | 可读可写 | 0/1/2/3/4 |  |
| AovSleepCycle | integer | <span class="colour" style="color:rgb(106, 153, 85)">AOV下休眠周期（单位：秒，nWorkMode为自定义模式下生效）</span> | 否 | 是 | 否 | 可读可写 | 取值范围需与设备确认 |  ||
