# 获取指定通道视频丢失配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
对于视频丢失，支持某些设备，不支持某些设备。对于不支持的设备，虽然它可以获得一些配置，但实际上它没有意义。

##### 请求

**xml**
无
**字段说明**
无
