# 设置指定通道视频丢失布防计划配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
如果<AllDay>的值为true，则表示每天的所有时间对于运动有效，但<TimeBlock>的值无效，如果为false，则<TimeBlock>的值有效。
一天分为48块，这意味着每隔半小时到一段时间，当一块时间被布防时，则块被设置为1，否则，块被设置为0，例如，如果全部 一天的时间有效，则<Block_0>的值为“111111111111111111111111111111111111111111111111”，如果一天中的所有时间都无效，则<Block_0>的值为“000000000000000000000000000000000000000000000000”。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Schedule>
    <AllDay><!--rw,req,xs:Boolean; "false","true"--></AllDay>
    <TimeBlock>
        <Block_0><!--rw,req,xs:string--></Block_0>
        <Block_1><!--rw,req,xs:string--></Block_1>
        <Block_2><!--rw,req,xs:string--></Block_2>
        <Block_3><!--rw,req,xs:string--></Block_3>
        <Block_4><!--rw,req,xs:string--></Block_4>
        <Block_5><!--rw,req,xs:string--></Block_5>
        <Block_6><!--rw,req,xs:string--></Block_6>
    <TimeBlock>
</Schedule>
```
