# 设置所有移动侦测相关配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
<Senstive>某些版本支持Highest, Higher, high,middle,low,Lower and lowes，有些版本仅支持high,middle,low的灵敏度。
