# 获取移动侦测区域相关配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
使用CGI或使用IE设置运动检测区域，这两种方法是相互独立的。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<MotionRegionList>
    <Region><!--opt-->
        <ID><!--rw,req,xs:integer--></ID>
        <TopLeftX><!--rw,req,xs:integer,0-703--></TopLeftX>
        <TopLeftY><!--rw,req,xs:integer,0-575--></TopLeftY>
        <BottomRightX><!--rw,req,xs:integer,0-703--></BottomRightX>
        <BottomRightY><!--rw,req,xs:integer,0-575--></BottomRightY>
    </Region>
</MotionRegionList>
```
