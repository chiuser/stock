# 设置移动跟踪配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### **请求**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<MoveTrack Version="1.0">
    <Enable><!--rw,opt,xs:boolean; "false","true"--></Enable>
</MoveTrack>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| <span class="colour" style="color:black">Enable</span> | boolean | <span class="colour" style="color:rgb(106, 153, 85)">使能配置;0-去使能,1-使能</span> | 否 | 是 | 否 | 可读可写 | false/true |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/Pictures/ChannelID/MoveTrack` 

##### 请求方式

- put

```
{}
```
