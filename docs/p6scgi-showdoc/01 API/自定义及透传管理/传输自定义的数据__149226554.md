# 传输自定义的数据
##### 简要描述


 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
 | ---------------- | ---------------- | ---------- | --------- |
 |  | <span class="colour" style="color: rgb(206, 145, 120);">配置-网络-IP 地址-MAC地址</span> <br> <span class="colour" style="color: rgb(206, 145, 120);">智能事件中语音报警自定义语音</span> |  |||

##### 请求

**示例**
<span class="colour" style="color:black">您可以传输自定义的数据。</span>

```
PUT /System/DeviceCustomFunction HTTP/1.1
Authorization: Basic YWRtaW46
Content-Type: text/plain
User-Agent: PostmanRuntime/7.43.0
Accept: */*
Cache-Control: no-cache
Postman-Token: c40120ff-eea6-4e28-9404-f6e3280afc18
Host: 192.168.6.95
Accept-Encoding: gzip, deflate, br
Connection: keep-alive
Content-Length: 163


Main-Command:”1”\r\n
Assist-Command:”1”\r\n
Payload-Length:”32”\r\n
Content:\r\n
\r\n………………………数据….…………………….
```
