# 设置客户自定义UI提示
##### 简要描述

 ##### **请求**

**xml**

```
<CustomerDefineUIPromptInfo>
    <DisplayDuration><!--rw,opt,xs:interger--></DisplayDuration>
    <PromptContext><!--rw,opt,xs:string, the max length : 128--></PromptContext>
</CustomerDefineUIPromptInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| DisplayDuration | integer | 显示时长 | 否 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| PromptContext | string | 自定义提示内容 | 否 | 是 | 否 | 可读可写 | 最大长度128 |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/CustomerDefineUIPromptInfo` 

##### 请求方式

- put

```
{}
```
