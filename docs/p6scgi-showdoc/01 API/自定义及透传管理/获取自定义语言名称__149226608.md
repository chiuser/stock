# 获取自定义语言名称
##### 简要描述

- ##### 说明

IsExistCustomLanguage:是否存在定制语言

##### **请求**

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<CustomLanguageName>
    <ChannelID><!--ro,req,xs:interger--></ChannelID>		//此字段PUT不用传
    <LanguageName><!--rw,req,xs:string,max length 64--></LanguageName>
    <IsExistCustomLanguage><!--rw,req,xs:boolean,”true”,”false”--></IsExistCustomLanguage>
</CustomLanguageName>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ChannelID | integer | 通道ID，自1递增 | 是 | 是 | 否 | 只读 | [1-32] |  |
| LanguageName | string | 定制语言名称 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |
| IsExistCustomLanguage | boolean | 是否存在定制语言<span class="colour" style="color:rgb(106, 153, 85)">，false-否，true-是</span> | 是 | 是 | 否 | 可读可写 | false/true |  ||

##### 请求URL

 - `/System/ChannelID/CustomLanguageName` 

##### 请求方式

- get
 
##### 成功返回示例  
```
[]
```
