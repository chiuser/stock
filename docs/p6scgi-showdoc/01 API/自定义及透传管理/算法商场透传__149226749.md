# 算法商场透传
##### 简要描述

- 1. /System/AlgoMallServerInfo对应xml消息如下:
```
<AlgoMallServerInfo Version="1.0">
    <AlgoMallUploadServerAddress>\<!--xs:string--></AlgoMallUploadServerAddress>
</AlgoMallServerInfo>
```
2. /System/AlgoMallPetIdentify对应xml消息如下:
```
<AlgoMallPetIdentify Version="1.0">
    <Enable><!--req,xs:boolean,"true,false",启用宠物识别--></Enable>
    <FunctionCfg>
        <IntelligentTrackEnable><!--req,xs:boolean,"true,false",智能跟踪--></IntelligentTrackEnable>
        <LinkVoicePromptEnable><!--req,xs:boolean,"true,false",联动语音提示--></LinkVoicePromptEnable>
        <VoiceType><!--req,xs:string,"custom",声音类型--></VoiceType>
    </FunctionCfg>
</AlgoMallPetIdentify>
```
3. /System/AlgoMallFallDetect
```
<AlgoMallFallDetect Version="1.0">
    <Enable><!--req,xs:boolean,"true,false",启用跌倒检测--></Enable>
    <FunctionCfg>
        <LinkOneBtnCallEnable><!--req,xs:boolean,"true,false",联动一键呼叫--></LinkOneBtnCallEnable>
        <LinkVoicePromptEnable><!--req,xs:boolean,"true,false",联动语音提示--></LinkVoicePromptEnable>
        <SupportVoiceTypeList>
            <VoiceType><!--req,xs:string,"default1,default2,default3",声音类型--></VoiceType>
            <VoiceType><!--req,xs:string,"default1,default2,default3",声音类型--></VoiceType>
            ...
            </SupportVoiceTypeList>
            <SelectVoiceType><!--req,xs:string,SupportVoiceTypeList中取值--></SelectVoiceType>
        <VoicePromptCount></VoicePromptCount>
    </FunctionCfg>
</AlgoMallFallDetect>
```
4. /System/OneClickTeasePet
```
<OneClickTeasePet Version="1.0">
    <FunctionCfg>
        <VoiceType><!--req,xs:string,"custom",声音类型--></VoiceType>
    </FunctionCfg>
</OneClickTeasePet>
```

**XML**字段解释<span lang="EN-US"></span>


| <span class="colour" style="color:black">字段</span><span lang="EN-US"></span> | <span class="colour" style="color:black">值</span><span lang="EN-US"></span> | <span class="colour" style="color:black">解释</span><span lang="EN-US"></span> | <span class="colour" style="color:black">是否必须</span><span lang="EN-US"></span> |
| --- | --- | --- | --- |
| AlgoCustomUrl | String | AlgoCustomUrl为透传的http请求方法(Get,Put)及请求url经过base64编码后的字符串,例:”Get /System/AlgoMallServerInfo”base64后为”R2V0IC9TeXN0ZW0vQWxnb01hbGxTZXJ2ZXJJbmZv”;支持透传的url如下:1. /System/AlgoMallServerInfo2. /System/AlgoMallPetIdentify3. /System/AlgoMallFallDetect4. /System/OneClickTeasePet1.     /System/DeviceCustomFunction2.     /System/CloudUpgradeServerInfo3.     /System/CloudUpgradeFirmwareList?VersionType=all&AlgoType=ANIMAL4.     /System/CloudUpgradeDownloadStart5.     /System/CloudUpgradeDownloadStartV16.     /System/CloudUpgradeDownloadStatus?Passport=abc&AlgoType=ANIMAL7.     /System/CloudUpgradeDownloadTerminate8.     /System/CloudUpgradeStartUpgrade9.     /System/CloudUpgradeResult?Passport=abc&AlgoType=ANIMAL | 否<span lang="EN-US"></span> |
| AlgoCustomXml | String | 1.“AlgoCustomUrl”中为Get方法时, 可以不传AlgoCustomXml节点或AlgoCustomXml为空节点;2.“AlgoCustomUrl”中为Put方法时,AlgoCustomXml节点内容为AlgoCustomUrl中url对应的put消息内容; | 否<span lang="EN-US"></span> |

PUT HTTP请求示例
以“算法商场服务器信息”为例
```
PUT /System/AlgoCustom HTTP/1.1
Authorization: Basic YWRtaW46
Content-Type: application/xml
User-Agent: PostmanRuntime/7.26.10
Accept: */*
Cache-Control: no-cache
Postman-Token: d7e5cf04-2a97-4b87-801a-38bfcc240c0a
Host: 192.168.1.100
Accept-Encoding: gzip, deflate, br
Connection: keep-alive
Content-Length: 3355

<?xml version="1.0" encoding="UTF-8" ?>
<AlgoCustom Version="1.0">
    <AlgoCustomUrl>R2V0IC9TeXN0ZW0vQWxnb01hbGxTZXJ2ZXJJbmZv</AlgoCustomUrl>
    <AlgoCustomXml>
        <AlgoMallServerInfo Version="1.0">
            <AlgoMallUploadServerAddress>[http://192.168.XXX.XXX:port](http://192.168.XXX.XXX:port)</AlgoMallUploadServerAddress>
        </AlgoMallServerInfo>
    </AlgoCustomXml>
</AlgoCustom>
```
