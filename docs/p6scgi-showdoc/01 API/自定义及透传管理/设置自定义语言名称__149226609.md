# 设置自定义语言名称
##### 简要描述

- ##### 请求

**xml**

```
<CustomLanguageName>
    <LanguageName><!--rw,opt,xs:string,max length 64--></LanguageName>
    <IsExistCustomLanguage><!--rw,opt,xs:boolean,”true”,”false”--></IsExistCustomLanguage>
</CustomLanguageName>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| LanguageName | string | 定制语言名称 | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| IsExistCustomLanguage | boolean | 是否存在定制语言<span class="colour" style="color:rgb(106, 153, 85)">，false-否，true-是</span> | 否 | 是 | 否 | 可读可写 | false/true |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/ChannelID/CustomLanguageName` 

##### 请求方式

- put
 
##### 成功返回示例  
```
{}

```
