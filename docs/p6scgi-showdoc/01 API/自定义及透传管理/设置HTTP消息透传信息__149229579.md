# 设置HTTP消息透传信息
##### 简要描述
  定制接口，安智APP使用
##### 请求

**xml**

```
<HTTPMessageTransmission>
      <GeneralEnable><!--rw,req,xs:boolean; "false","true"--></GeneralEnable>
      <FilterTarget><!--rw,req,xs:string--></FilterTarget>
      <EnableFirstPolygon><!--rw,req,xs:boolean; "false","true"--></EnableFirstPolygon>
      <FirstRegion>
            <TopLeftX><!--rw,req,xs:integer--></TopLeftX>
            <TopLeftY><!--rw,req,xs:integer--></TopLeftY>
            <BottomRightX><!--rw,req,xs:integer--></BottomRightX>
            <BottomRightY><!--rw,req,xs:integer--></BottomRightY>
      </FirstRegion>
      <EnableSecondPolygon><!--rw,req,xs:boolean; "false","true"--></EnableSecondPolygon>
      <SecondRegion>
            <TopLeftX><!--rw,req,xs:integer--></TopLeftX>
            <TopLeftY><!--rw,req,xs:integer--></TopLeftY>
            <BottomRightX><!--rw,req,xs:integer--></BottomRightX>
            <BottomRightY><!--rw,req,xs:integer--></BottomRightY>
      </SecondRegion>
</HTTPMessageTransmission>
```
