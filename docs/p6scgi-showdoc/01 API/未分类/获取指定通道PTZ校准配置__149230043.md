# 获取指定通道PTZ校准配置
##### 简要描述

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<PTZCalibration>
	<CalibrationInterval><!--rw,req,xs:integer --></CalibrationInterval>
</PTZCalibration>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| CalibrationInterval | integer | 云台校准间隔;0:立即校准,4:4小时,12:12小时,24:24小时 | 是 | 是 | 否 | 可读可写 | 0/4/12/24 |  |  |  |  |  ||

##### 请求URL

 - `/PTZ/ChannelID/CalibrationCfg`
 ChannelID从1开始

##### 请求方式

- get
