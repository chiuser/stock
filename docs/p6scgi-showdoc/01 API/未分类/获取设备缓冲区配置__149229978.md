# 获取设备缓冲区配置
##### 简要描述

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<SystemBufferSize>
    <PictureBufferLen><!--ro,req,xs:integer --></PictureBufferLen>
	<CGIBufferSize><!--ro,req,xs:integer --></CGIBufferSize>
	<P2PHttpSendBufferLen><!--ro,req,xs:integer --></P2PHttpSendBufferLen>
	<P2PHttpRecvBufferLen><!--ro,req,xs:integer --></P2PHttpRecvBufferLen>
</SystemBufferSize>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| PictureBufferLen | integer | 缩略图缓冲区大小，CGI协议，建议不要超过64KB，单位是Byte | 是 | 是 | 否 | 可读可写 | 建议值64 |  |
| CGIBufferSize | integer | CGI请求缓冲区的大小，可以不设置或设置为0，则使用默认值384k，单位是Byte | 是 | 是 | 否 | 可读可写 | 默认值384k |  |
| P2PHttpSendBufferLen | integer | P2P http 请求最大发送buffer长度 默认值384k | 是 | 是 | 否 | 可读可写 | 默认值384k |  |
| P2PHttpRecvBufferLen | integer | P2P http 请求最大接收buffer长度 默认值384k | 是 | 是 | 否 | 可读可写 | 默认值384k |  ||

##### 请求URL

 - `/System/BufferSize` 

##### 请求方式

- get
