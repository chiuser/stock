# 设置贝福佳WIFI密码配置信息
##### 简要描述

##### 请求

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<BFJWIFIPassword>
    <OldPassword><!--wo,req,xs:string --></OldPassword>
	<WIFIPassword><!--wo,req,xs:string --></WIFIPassword>
</BFJWIFIPassword>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| OldPassword | string | 旧密码，贝福佳定制, 暂不考虑密码长度、特殊字符等其他情况 | 是 | 是 | 否 | 只写 | 最大长度32 |  |
| WIFIPassword | string | WIFI密码，贝福佳定制, 暂不考虑密码长度、特殊字符等其他情况 | 是 | 是 | 否 | 只写 | 最大长度32 |  ||

##### 响应
**xml**
```
<?xml version = "1.0" encoding = "utf-8"?>
<ResponseStatus>
    <requestURL><!-- ro,req:string, the max length : 128 --></requestURL>
    <statusCode><!-- ro,req:integer --></statusCode>
    <message><!-- ro,req:string, the max length : 128 --></message>
</ResponseStatus>
```
**字段说明**

| 字段 | 类型 | 功能描述 | 是否必须 | 字段是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | ---- | ---- | ------ | ----- | ---------------------- | ------- | --- |
| <span class="colour" style="color:rgb(128, 0, 0)">requestURL</span> | String | <span class="colour" style="color:rgb(106, 153, 85)">请求URL</span> | 是 | 是 | <span class="colour" style="color:rgb(106, 153, 85)">不可为空</span> | 只读 | <span class="colour" style="color:rgb(106, 153, 85)">最大长度128</span> |  |
| <span class="colour" style="color:rgb(128, 0, 0)">statusCode</span> | integer | <span class="colour" style="color:rgb(106, 153, 85)">响应状态码</span> | 是 | 是 | <span class="colour" style="color:rgb(106, 153, 85)">不可为空</span> | 只读 | 取值需要设备确认 | <span class="colour" style="color:rgb(106, 153, 85)"><span class="colour" style="color:rgb(106, 153, 85)">参考：</span></span>[http://xrs-api.p6sai.com:8091/project/11074/interface/api/72673](http://xrs-api.p6sai.com:8091/project/11074/interface/api/72673) |
