# 获取指定通道一键报警状态
##### 简要描述

##### 请求

**xml**
无

**字段说明**
无


##### 响应

**xml**
```xml
<?xml version="1.0" encoding="utf-8"?>
<OneClickAlarmStatus>
	<AlarmStatus><!--rw,req,xs:boolean --></AlarmStatus>
	<AlarmTime><!--rw,req,xs:integer --></AlarmTime>
</OneClickAlarmStatus>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| AlarmStatus | boolean | 报警状态；0-报警结束，1-报警中 | 是 | 是 | 否 | 可读可写 | 0/1 |  |  |  |  |  |
| AlarmTime | integer | 报警持续时长；单位秒，取值范围[0-60] | 是 | 是 | 否 | 可读可写 | [0-60] |  |  |  |  |  ||


##### 请求URL

 - `/Alarm/ChannelID/OneClickAlarmStatus`
 ChannelID从1开始

##### 请求方式

- get
