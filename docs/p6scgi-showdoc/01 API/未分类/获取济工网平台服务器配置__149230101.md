# 获取济工网平台服务器配置
##### 简要描述

##### 请求

**xml**
无

**字段说明**
无


##### 响应

**xml**
```xml
<?xml version="1.0" encoding="utf-8"?>
<JGPlatformServerConfig>
	<Enable><!--rw,req,xs:boolean --></Enable>
	<ServerPrefix><!--rw,req,xs:string, max length 64 --></ServerPrefix>
	<AppId><!--rw,req,xs:string, max length 64 --></AppId>
	<Secret><!--rw,req,xs:string, max length 64 --></Secret>
</JGPlatformServerConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | boolean | 是否使能济工网服务器配置。false-否；true-是； | 是 | 是 | 否 | 可读可写 | false,true |  |  |  |  |  |
| ServerPrefix | string | 服务器前缀 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |  |  |  |  |
| AppId | string | AppId | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |  |  |  |  |
| Secret | string | Secret | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |  |  |  |  ||


##### 请求URL

 - `/System/JGPlatformServerConfig`

##### 请求方式

- get
