# 标定
##### 简要描述

| 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| ---------------- | ---------------- | ---------- | --------- |
|  | <span class="colour" style="color: rgb(206, 145, 120);">web没有调用</span> |  |  ||

##### 说明

URI中的`<ChannelID>`显示通道编号。 `<ChannelID>`从1开始。

##### 示例

URL：[http://192.168.1.46/PTZ/1/Calibrate](http://192.168.1.46/PTZ/1/Calibrate)

##### http示例

```http
PUT /PTZ/1/Calibrate HTTP/1.1
Connection:close
Host: 192.168.0.46
Content-Length:

Param1=1
```

##### 请求URL

 - `/PTZ/ChannelID/Calibrate`
 ChannelID从1开始

##### 请求方式

- put
 
##### 成功返回示例
```
{}

```
