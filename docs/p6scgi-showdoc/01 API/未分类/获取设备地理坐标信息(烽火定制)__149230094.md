**字段说明**

##### 响应

**xml**
```xml
<?xml version="1.0" encoding="utf-8"?>
<LonLatInfo>
	<Lon><!--rw,req,xs:double --></Lon>
	<Lat><!--rw,req,xs:double --></Lat>
</LonLatInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Lon | double | 经度 | 是 | 是 | 否 | 可读可写 | [-180,180] |  |  |  |  |  |
| Lat | double | 纬度 | 否 | 是 | 否 | 可读可写 | [-90,90] |  |  |  |  |  ||
