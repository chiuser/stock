# 获取云存储错误信息
##### 简要描述

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<CloudStorageErrorCodeList>
    <Count><!--ro,req,xs:Interger; 错误码数量--></Count>
    <CloudStorageErrorCodeBaseStatus>
		<ID><!--ro,req,xs:Interger;--></ID>
		<NetworkStatus><!--ro,req,xs:Interger; 正常：0 , 异常：大于0（错误代码）, 1.网络超时--></NetworkStatus>
		<StorageStatus><!--ro,req,xs:Interger;空闲：0, 存储中：1, 存储异常：大于2（错误代码）--></StorageStatus>
		<ErrorCode><!--ro,req,xs:Interger; 该错误码由模块错误码基址+接口错误码基址+错误码组成--></ErrorCode>
		<Time><!--ro,req,xs:Interger;--></Time>
		<Line><!--ro,req,xs:Interger;--></Line>
		<FileName><!--ro,req,xs:string,max length 128;--></FileName>
	</CloudStorageErrorCodeBaseStatus>
</CloudStorageErrorCodeList>
```
