# 获取指定通道图片能力配置
##### 简要描述
用于获取抓拍图片的分辨率
##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<?xml version = "1.0" encoding = "utf-8"?>
<SnapshotCapabilityList><!--ro,req-->
    <SnapshotCapability><!--ro,opt-->
        <ID><!--ro,req,xs:integer--></ID>
        <ResolutionWidth><!--ro,req,xs:integer--></ResolutionWidth>
        <ResolutionHeight><!--ro,req,xs:integer--></ResolutionHeight>
    </SnapshotCapability>
</SnapshotCapabilityList>
```

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
|  |  |  |  |  |  |  |  |  |  |  | <span class="colour" style="color: rgb(0, 0, 0);">设备能力专用URL：/System/DeviceCap；能力定义：DeviceCap-Snapshot</span><span class="colour" style="color: rgb(206, 145, 120);">；</span> |  |
| SnapshotCapability |  |  | 否 | 是 |  |  |  |  |  | <span class="colour" style="color:rgb(206, 145, 120)">配置-系统设置-抓图配置</span> |  |  |
| ID | integer | 抓图能力支持的分辨率的索引 | 是 | 是 | 否 | 只读 | 取值需与设备确认 |  |  |  |  |  |

 - `/Snapshot/ChannelID/Capability`
 ChannelID从1开始

##### 请求方式

- get
