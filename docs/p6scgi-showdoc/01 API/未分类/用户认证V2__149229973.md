# 用户认证V2
##### 简要描述
  | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
 | ---------------- | ---------------- | ---------- | --------- |
 |  | <span class="colour" style="color: rgb(206, 145, 120);">登录界面</span> |  |||
 
##### 请求示例

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<Security>
    <Username><!--rw,req,xs:string, the max  length : 64--></Username>
    <Password><!--rw,req,xs:string, the max  length : 64--></Password>
    <Nonce><!--rw,req,xs:string, the max  length : 64--></Nonce>
    <Created><!--rw,req,xs:string, the max  length : 64--></Created>
</Security>
```

##### 字段说明

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Username | string | 用户名 | 是 | 是 | 否 | 只写 | 最大长度64 |  |  | <span class="colour" style="color: rgb(206, 145, 120);">登录界面</span> |  |  |
| Password | string | 经加密后的密码 | 是 | 是 | 否 | 只写 | 最大长度64 | 计算方式为：密文密码 = Base64(SHA1(Nonce + Created + Password)) |  | <span class="colour" style="color: rgb(206, 145, 120);">登录界面</span> |  |  |
| Nonce | string | 随机数，用于计算密文密码 | 是 | 是 | 否 | 只写 | 最大长度64 |  |  |  |  |  |
| Created | string | 时间，用于计算密文密码，格式：YYYY-MM-DDThh:mm:ssZ | 是 | 是 | 否 | 只写 | 最大长度64 |  |  |  |  |  ||

##### 请求URL

 - `/Security/UserAuthV2` 

##### 请求方式

- put
