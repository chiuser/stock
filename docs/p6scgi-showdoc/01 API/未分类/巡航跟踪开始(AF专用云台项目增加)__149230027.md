# 巡航跟踪开始(AF专用云台项目增加)
##### 简要描述

| 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| ---------------- | ---------------- | ---------- | --------- |
|  | <span class="colour" style="color: rgb(206, 145, 120);">web没有调用</span> |  |  ||

##### 说明

URI中的`<ChannelID>`显示通道编号。 `<ChannelID>`从1开始。
  有一个参数，“Param1”是巡航号。值的范围是0-15。

##### 示例

URL：[http://192.168.1.46/PTZ/1/Cruise/CruiseTrackStart](http://192.168.1.46/PTZ/1/Cruise/StartCruise)

##### http示例

```http
PUT /PTZ/1/Cruise/CruiseTrackStart HTTP/1.1
Connection:close
Host: 192.168.0.46
Content-Length:

Param1=1
```

##### 请求URL

 - `/PTZ/ChannelID/Cruise/CruiseTrackStart`

##### 请求方式

- put
 
##### 成功返回示例  
```
{}

```
