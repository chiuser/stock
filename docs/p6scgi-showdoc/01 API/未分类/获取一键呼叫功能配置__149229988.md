# 获取一键呼叫功能配置
##### 简要描述

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<DeviceOneButtonCallFuncCfg>
    <Enable><!--rw,req,xs:boolean --></Enable>
</DeviceOneButtonCallFuncCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | boolean | 使能一键呼叫功能;false-去使能,true-使能 | 是 | 是 | 否 | 可读可写 | false,true |  |  |  |  |  | |

##### 请求URL

 - `/System/DevOneBtnCallFuncCfg` 

##### 请求方式

- get
