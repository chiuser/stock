# 获取指定通道一键报警配置
##### 简要描述

##### 请求

**xml**
无

**字段说明**
无


##### 响应

**xml**
```xml
<?xml version="1.0" encoding="utf-8"?>
<OneClickAlarmConfig>
	<IsVoiceOpen><!--rw,req,xs:boolean --></IsVoiceOpen>
	<IsLightOpen><!--rw,req,xs:boolean --></IsLightOpen>
	<IsAlarmOutOpen><!--rw,req,xs:boolean --></IsAlarmOutOpen>
	<AlarmTime><!--rw,req,xs:integer --></AlarmTime>
</OneClickAlarmConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| IsVoiceOpen | boolean | 是否开启声音报警；false-否，true-是 | 是 | 是 | 否 | 可读可写 | false，true |  |  |  |  |  |
| IsLightOpen | boolean | 是否开启灯光报警；false-否，true-是 | 是 | 是 | 否 | 可读可写 | false，true |  |  |  |  |  |
| IsAlarmOutOpen | boolean | 是否开启报警输出；false-否，true-是 | 是 | 是 | 否 | 可读可写 | false，true |  |  |  |  |  |
| AlarmTime | integer | 报警持续时长，单位：秒 | 是 | 是 | 否 | 可读可写 | [0-60] |  |  |  |  |  ||


##### 请求URL

 - `/Alarm/ChannelID/OneClickAlarmCfg`
 ChannelID从1开始

##### 请求方式

- get
