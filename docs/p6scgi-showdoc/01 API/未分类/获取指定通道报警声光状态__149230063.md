# 获取指定通道报警声光状态
##### 简要描述

##### 请求

**xml**
无

**字段说明**
无


##### 响应

**xml**
```xml
<?xml version="1.0" encoding="utf-8"?>
<AlarmVoiceLightState>
	<State><!--rw,req,xs:boolean --></State>
	<RemainTime><!--rw,req,xs:integer --></RemainTime>
</AlarmVoiceLightState>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| State | boolean | 是否在报警状态中；false-否，true-是 | 是 | 是 | 否 | 可读可写 | false，true |  |  |  |  |  |
| RemainTime | integer | 报警剩余时长，单位：秒 | 是 | 是 | 否 | 可读可写 |  |  |  |  |  |  ||


##### 请求URL

 - `/Alarm/ChannelID/VoiceLightState`
 ChannelID从1开始

##### 请求方式

- get
