# 远程控制命令
##### 简要描述

##### 请求

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<RemoteControlCmd>
	<MainType><!--rw,req,xs:integer --></MainType>
	<SubType><!--rw,req,xs:integer --></SubType>
	<Info>
		<SubType><!--rw,req,xs:integer --></SubType>
	</Info>
</RemoteControlCmd>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| MainType | integer | 主类型；<br>1044-手动回充，1048-逗宠配置 | 是 | 是 | 否 | 可读可写 | false，true |  |  |  |  |  |
| SubType | integer | 次类型；<br>MainType=1044时,SubType=1表示手动回充；<br>MainType=1048时,SubType=1表示逗宠动作,SubType=2表示逗宠声音 | 是 | 是 | 否 | 可读可写 | false，true |  |  |  |  |  |
| Info |  | 拓展信息 |  |  |  |  |  |  |  |  |  |  |
| TeasePetAction | integer | 逗宠动作,MainType=1048,SubType=1时有效;<br>1-大圆环,2-直线式,3-随机漫步,4-鸭子漫步,5-原地摇摆,6-步步前提,7-8字形,8-徘徊式,9-小蛇游走,10-Z字行进,11-边走边玩,12-四面出击,1000-大口吃粮,1001-鸭子玩具,1002-开罐头啦,1003-呼唤喵宝,1004-小猫叫声,1005-呼噜呼噜,1006-来开饭啦,1007-萌猫萌鸣 | 否 | 是 | 否 | 只写 | 1-12,1000-1007 |  |  |  |  |  | |

##### 响应
**xml**
```
<?xml version = "1.0" encoding = "utf-8"?>
<ResponseStatus>
    <requestURL><!-- ro,req:string, the max length : 128 --></requestURL>
    <statusCode><!-- ro,req:integer --></statusCode>
    <message><!-- ro,req:string, the max length : 128 --></message>
</ResponseStatus>
```
