# 设置设备宠物检测配置
##### 简要描述

##### 请求

**xml**
```xml
<?xml version="1.0" encoding="utf-8"?>
<PetDetectCfg>
	<Enable><!--rw,req,xs:boolean --></Enable>
	<SDCardRecord><!--rw,req,xs:boolean --></SDCardRecord>
	<RecordingDuration><!--rw,req,xs:integer --></RecordingDuration>
	<Tracking><!--rw,req,xs:boolean --></Tracking>
	<Snapshot><!--rw,req,xs:boolean --></Snapshot>
	<IsRecordSupportDurationCtl><!--rw,req,xs:boolean --></IsRecordSupportDurationCtl>
</PetDetectCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | boolean | 是否开启宠物检测;false:关闭,true:启用 | 是 | 是 | 否 | 可读可写 | false,true |  |  |  |  |  |
| SDCardRecord | boolean | 是否开启SD卡录像;false:关闭,true:启用 | 是 | 是 | 否 | 可读可写 | false,true |  |  |  |  |  |
| RecordingDuration | integer | 录像时长,单位：秒 | 是 | 是 | 否 | 可读可写 |  |  |  |  |  |  |
| Tracking | boolean | 是否开启联动跟踪;false:关闭,true:启用 | 是 | 是 | 否 | 可读可写 | false,true |  |  |  |  |  |
| Snapshot | boolean | 是否开启联动抓拍;false:关闭,true:启用 | 是 | 是 | 否 | 可读可写 | false,true |  |  |  |  |  |
| IsRecordSupportDurationCtl | boolean | 事件录像是否支持时长控制;false:否,true:是 | 是 | 是 | 否 | 可读可写 | false,true |  |  |  |  |  ||
