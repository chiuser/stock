# 设置氛围灯配置
##### 简要描述

##### 请求

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<AtmosphereLightCfg>
    <Enable><!--rw,req,xs:boolean --></Enable>
	<ModeType><!--rw,req,xs:integer --></ModeType>
</AtmosphereLightCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | boolean | 使能服务器配置;false-去使能,true-使能 | 是 | 是 | 否 | 可读可写 | false,true |  |  |  |  |  |
| ModeType | integer | 氛围灯配置模式；0-红灯，1-蓝灯，2-绿灯，3-循环 | 是 | 是 | 否 | 可读可写 | 0/1/2/3 |  |  |  |  |  | |

```
    <statusCode><!-- ro,req:integer --></statusCode>
    <message><!-- ro,req:string, the max length : 128 --></message>
</ResponseStatus>
```
