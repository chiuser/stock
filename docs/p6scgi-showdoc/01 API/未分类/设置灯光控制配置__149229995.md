# 设置灯光控制配置
##### 简要描述

##### 请求

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<LightControlCfg>
    <Enable><!--rw,req,xs:boolean --></Enable>
	<HasPersonLightBright><!--rw,req,xs:integer --></HasPersonLightBright>
	<NoPersonLightBright><!--rw,req,xs:integer --></NoPersonLightBright>
	<RadarSensorEnable><!--rw,req,xs:integer --></RadarSensorEnable>
	<IntellectOnLightEnable><!--rw,req,xs:integer --></IntellectOnLightEnable>
	<TimeOnLightEnable><!--rw,req,xs:integer --></TimeOnLightEnable>
	<DayTimeSlot>
		<Enable><!--rw,req,xs:boolean --></Enable>
		<StartTime><!--rw,req,xs:string,"hh:mm", max lenggth 32 --></StartTime>
		<EndTime><!--rw,req,xs:string,"hh:mm", max lenggth 32 --></EndTime>
	</DayTimeSlot>
	<NightTimeSlot>
		<Enable><!--rw,req,xs:boolean --></Enable>
		<StartTime><!--rw,req,xs:string,"hh:mm", max lenggth 32 --></StartTime>
		<EndTime><!--rw,req,xs:string,"hh:mm", max lenggth 32 --></EndTime>
	</NightTimeSlot>
	<AllowLightTimeSlotList Version="1.0">
        <SchedTimeSlot>
            <ID><!--rw,req,xs:interger, 1,2,3...--></ID>
            <Enable><!--rw,,req,xs:boolean,"true","false"--></Enable>
            <StartTime><!--rw,req,xs:string,"hh:mm",max length 32--></StartTime>
            <EndTime><!--rw,req,xs:string,"hh:mm",max length 32--></EndTime>
            <Weekday><!--rw,req,xs:string,"11111111",max length 8; 每周7天, 字符串内容从左至右分别表示周日,周一...,以此类推;取值1表示选定对应星期,取值0表示没有选择对应星期,第8位保留--></Weekday>
        </SchedTimeSlot>
        ...
    </AllowLightTimeSlotList>
</LightControlCfg>
```
