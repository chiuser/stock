# 获取报警拓展服务器信息
##### 简要描述

##### 请求

**xml**
无

**字段说明**
无


##### 响应

**xml**
```xml
<?xml version="1.0" encoding="utf-8"?>
<AMS>
	<Enable><!--rw,req,xs:boolean --></Enable>
	<ServerName><!--rw,req,xs:string, max length 64 --></ServerName>
	<UserName><!--rw,req,xs:string, max length 64 --></UserName>
	<Password><!--rw,req,xs:string, max length 64 --></Password>
	<Message><!--rw,req,xs:string, max length 128 --></Message>
</AMS>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | boolean | 是否启用报警服务器;false:关闭,true:启用 | 是 | 是 | 否 | 可读可写 | false,true |  |  |  |  |  |
| ServerName | string | 服务器名称 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |  |  |  |  |
| UserName | string | 用户名 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |  |  |  |  |
| Password | string | 用户密码 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |  |  |  |  |
| Message | string | 服务器url经base64编码后的内容 | 是 | 是 | 否 | 可读可写 | 最大长度128 |  |  |  |  |  ||


##### 请求URL

 - `/Alarm/AMS`
