# 获取指定通道雷达检测配置
##### 简要描述

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<RadarDetect>
    <Enable><!--rw,req,xs:boolean --></Enable>
	<Senstive><!--rw,req,xs:integer --></Senstive>
	<DistanceDisplayEnable><!--rw,req,xs:boolean --></DistanceDisplayEnable>
</RadarDetect>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | boolean | 是否使能雷达检测配置;false-否,true-是 | 是 | 是 | 否 | 可读可写 | false,true |  |  |  |  |  |
| Senstive | integer | 雷达检测侦测灵敏度;0-30为低,30-60为中,60-100为高 | 是 | 是 | 否 | 可读可写 | [0-100]] |  |  |  |  |  |
| DistanceDisplayEnable | boolean | 是否使能测距显示;false-否,true-是 | 是 | 是 | 否 | 可读可写 | false,true |  |  |  |  |  ||

##### 请求URL

 - `/Pictures/ChannelID/RadarDetect`
 ChannelID从1开始

##### 请求方式

- get
