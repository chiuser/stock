# 获取设备3D定位配置
##### 简要描述

##### 请求

**xml**
无

**字段说明**
无


##### 响应

**xml**
```xml
<?xml version="1.0" encoding="utf-8"?>
<Device3DPositioningCfg>
	<Operator><!--rw,req,xs:integer --></Operator>
	<_3DPositionCoord>
		<PointLeftTop>
			<PosX><!--rw,req,xs:integer --></PosX>
			<PosY><!--rw,req,xs:integer --></PosY>
		</PointLeftTop>
		<PointRightTop>
			<PosX><!--rw,req,xs:integer --></PosX>
			<PosY><!--rw,req,xs:integer --></PosY>
		</PointRightTop>
		<PointRightBottom>
			<PosX><!--rw,req,xs:integer --></PosX>
			<PosY><!--rw,req,xs:integer --></PosY>
		</PointRightBottom>
		<PointLeftBottom>
			<PosX><!--rw,req,xs:integer --></PosX>
			<PosY><!--rw,req,xs:integer --></PosY>
		</PointLeftBottom>
		<PointCenter>
			<PosX><!--rw,req,xs:integer --></PosX>
			<PosY><!--rw,req,xs:integer --></PosY>
		</PointCenter>
	</_3DPositionCoord>
</Device3DPositioningCfg>
```
