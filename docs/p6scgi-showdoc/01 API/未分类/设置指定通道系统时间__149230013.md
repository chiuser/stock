# 设置指定通道系统时间
##### 简要描述

##### 说明

SystemTime：接受并返回ISO 8601日期/时间字符串。

##### 请求

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<Time>
    <DateTimeFormat><!--rw,req,string, "YYYYMMDDWhhmmss,YYYYMMDDhhmmss,MMDDYYYYWhhmmss,MMDDYYYYhhmmss,DDMMYYYYWhhmmss,DDMMYYYYhhmmss"--></DateTimeFormat>
    <TimeFormat><!--rw,req,xs:string, "12hour,24hour"--></TimeFormat>
    <SystemTime><!--rw,req,xs:datetime,” 20040503T173008+08”--></SystemTime>
    <SyncNTPFlag><!--rw,opt,xs:string,"Sync,NoSync"--></SyncNTPFlag>
    <UpdateFlag><!--wo,req,xs:integer,0,1,2--></UpdateFlag>
</Time>
```
