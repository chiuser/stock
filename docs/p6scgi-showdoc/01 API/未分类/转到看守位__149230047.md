# 转到看守位
##### 简要描述

| 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| ---------------- | ---------------- | ---------- | --------- |
|  | <span class="colour" style="color: rgb(206, 145, 120);">web没有调用</span> |  |  ||

##### 说明
URI中的`<ChannelID>`显示通道编号。 `<ChannelID>`从1开始。
  有一个参数，“Param1”是看守位序号。值的范围是0-15。以前设备没有分开预置位和看守位，如果预置点的坐标修改，看守位的坐标也修改了，为避免这种问题将与预置位和看守位分开

##### 示例

URL：[http://192.168.1.46/PTZ/1/WatchCareGoto](http://192.168.1.46/PTZ/1/WatchCareGoto)

##### http示例

```http
PUT /PTZ/1/WatchCareGoto HTTP/1.1
Connection:close
Host: 192.168.0.46
Content-Length:

Param1=1
```

##### 请求URL

 - `/PTZ/ChannelID/WatchCareGoto`
 ChannelID从1开始

##### 请求方式

- put
 
##### 成功返回示例
```
{}

```
