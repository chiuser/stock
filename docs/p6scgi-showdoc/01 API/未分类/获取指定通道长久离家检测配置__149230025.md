# 获取指定通道长久离家检测配置
##### 简要描述

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<LongAwayHomeDetectCfg>
    <Enable><!--rw,req,xs:boolean --></Enable>
	<AwayHomeAlarmDuration><!--rw,req,xs:integer --></AwayHomeAlarmDuration>
</LongAwayHomeDetectCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | boolean | 是否使能长久离家检测;false-否,true-是 | 是 | 是 | 否 | 可读可写 | false,true |  |  |  |  |  |
| Senstive | integer | 长久离家时间,单位:小时;4-4小时,6-6小时,8-8小时,10-10小时,12-12小时 | 是 | 是 | 否 | 可读可写 | 4/6/8/10/12 |  |  |  |  |  ||

##### 请求URL

 - `/Pictures/ChannelID/LongAwayHomeDetect`
 ChannelID从1开始
