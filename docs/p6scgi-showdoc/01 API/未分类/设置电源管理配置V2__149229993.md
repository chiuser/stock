# 设置电源管理配置V2
##### 简要描述

##### 请求

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<DevicePowerManageCfgV2>
    <WorkMode><!--rw,req,xs:integer --></WorkMode>
	<EnergyConserThre><!--rw,req,xs:integer --></EnergyConserThre>
	<AovSleepCycle><!--rw,req,xs:integer --></AovSleepCycle>
</DevicePowerManageCfgV2>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| WorkMode | integer | 工作模式; 0–省电模式，1–低功耗模式，2–AOV模式, 3–智能模式| 是 | 是 | 否 | 可读可写 | 0/1/2/3 |  |  | |||
| EnergyConserThre | integer | 电量阈值，用于控制设备端依赖电量的功能（云台、喇叭等外设），根据阈值判断是否工作，取值范围[0-100],电量阈值是否使用只与设备有关，与工作模式无关。 | 是 | 是 | 否 | 可读可写 | [0-100] | 电量阈值是否使用只与设备有关，与工作模式无关 |  |  |  |  |
| AovSleepCycle | integer | AOV下休眠周期（单位：秒，WorkMode为AOV模式下生效） | 是 | 是 | 否 | 可读可写 |  | WorkMode为AOV模式下生效 |  |  |  |  | |
