##### 请求

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<ElectronicDenceCfgEx>
    <Version><!--rw,opt,xs:string;"V1,V2"--></Version>

    <VoiceAlarmSchedule Version="1.0">
        <AllDay><!--rw,req,xs:boolean--></AllDay>
		<DayMode><!--rw,req,xs:string,"evening,day,disable,unknown"--></DayMode>
        <TimeBlockList Version="1.0">
            <TimeBlock_0><!--rw,req,xs:string,eg:111111111111111111111111111111111111111111111111--></TimeBlock_0>
            <TimeBlock_1><!--rw,req,xs:string,eg:111111111111111111111111111111111111111111111111--></TimeBlock_1>
            <TimeBlock_2><!--rw,req,xs:string,eg:111111111111111111111111111111111111111111111111--></TimeBlock_2>
            <TimeBlock_3><!--rw,req,xs:string,eg:111111111111111111111111111111111111111111111111--></TimeBlock_3>
            <TimeBlock_4><!--rw,req,xs:string,eg:111111111111111111111111111111111111111111111111--></TimeBlock_4>
            <TimeBlock_5><!--rw,req,xs:string,eg:111111111111111111111111111111111111111111111111--></TimeBlock_5>
            <TimeBlock_6><!--rw,req,xs:string,eg:111111111111111111111111111111111111111111111111--></TimeBlock_6>
        </TimeBlockList>
    </VoiceAlarmSchedule>
    <EventVoiceAlarmTimeSlotList Version="1.0">
            <SchedTimeSlot>
                <ID><!--rw,req,xs:interger, 1,2,3...--></ID>
                <Enable><!--rw,req,xs:boolean,"true","false"--></Enable>
                <IsSet><!--rw,req,xs:boolean,"true","false"--></IsSet>
                <StartTime><!--rw,req,xs:string,"hh:mm",max length 32--></StartTime>
                <EndTime><!--rw,req,xs:string,"hh:mm",max length 32--></EndTime>
                <Weekday><!--rw,req,xs:string,"11111111",max length 8; 每周7天, 字符串内容从左至右分别表示周日,周一...,以此类推;取值1表示选定对应星期,取值0表示没有选择对应星期,第8位保留--></Weekday>
            </SchedTimeSlot>
            ...
    </EventVoiceAlarmTimeSlotList>
<ElectronicDenceCfgEx>
```
