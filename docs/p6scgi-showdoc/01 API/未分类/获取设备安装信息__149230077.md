# 获取设备安装信息
##### 简要描述

##### 请求

**xml**
无

**字段说明**
无


##### 响应

**xml**
```xml
<?xml version="1.0" encoding="utf-8"?>
<DeviceInstallInfo>
	<IsDeviceNameShow><!--rw,req,xs:string --></IsDeviceNameShow>
	<DeviceName><!--rw,req,xs:string,max length 128 --></DeviceName>
	<IsInstallAddressShow><!--rw,req,xs:string --></IsInstallAddressShow>
	<InstallAddress><!--rw,req,xs:string,max length 256 --></InstallAddress>
</DeviceInstallInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| IsDeviceNameShow | string | 是否显示设备名称；no:不显示;show:显示 | 是 | 是 | 否 | 可读可写 | no/show |  |  |  |  |  |
| DeviceName | string | 设备名称 | 是 | 是 | 否 | 可读可写 | 最大长度128 |  |  |  |  |  |
| IsInstallAddressShow | string | 是否显示安装地址；no:不显示;show:显示 | 是 | 是 | 否 | 可读可写 | no/show |  |  |  |  |  |
| InstallAddress | string | 安装地址 | 是 | 是 | 否 | 可读可写 | 最大长度256 |  |  |  |  |  ||


##### 请求URL

 - `/System/DeviceInstallInfo`

##### 请求方式

- get
