# 获取屏幕管理配置
##### 简要描述

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<ScreenManagementCfg>
    <Enable><!--rw,req,xs:boolean --></Enable>
	<ScreenCloseTime><!--rw,req,xs:integer --></ScreenCloseTime>
	<ScreenLight><!--rw,req,xs:integer --></ScreenLight>
	<CurrentScreenThemeType><!--rw,req,xs:integer --></CurrentScreenThemeType>
</ScreenManagementCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | boolean | 是否使能屏幕管理;false-否,true-是 | 是 | 是 | 否 | 可读可写 | false,true |  |  | | | |
| ScreenCloseTime | integer | 息屏时间,单位:秒; 0表示永不息屏 | 是 | 是 | 否 | 可读可写 |  |  |  |  |  |  |
| ScreenLight | integer | 屏幕亮度,[0-100] | 是 | 是 | 否 | 可读可写 | [0-100] |  |  |  |  |  |
| CurrentScreenThemeType | integer | 屏幕主题类型,[0-9] | 是 | 是 | 否 | 可读可写 | [0-9] |  |  |  |  |  | |

##### 请求URL

 - `/System/ScreenManagementCfg` 

##### 请求方式

- get

[]
