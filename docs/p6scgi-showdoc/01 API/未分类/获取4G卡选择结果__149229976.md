# 获取4G卡选择结果
##### 简要描述

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<_4GCardSelectResult>
    <ICCID><!--ro,req,xs:string; max length 64 --></ICCID>
	<CardID><!--ro,req,xs:Interger --></CardID>
	<SelectErrCode><!--ro,req,xs:Interger --></SelectErrCode>
</_4GCardSelectResult>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ICCID | string | ICCID | 是 | 是 | 否 | 只读 | 最大长度64 |  |
| CardID | integer | 卡序号，CardID=0表示卡0，CardID=1表示卡1, CardID=2表示卡2，依此类推；同时为兼容/Network/4GCardCfgList接口CardType字段，约定 卡0表示内置卡，卡1表示外置卡 | 是 | 是 | 否 | 只读 | 0/1/2 |  |
| SelectErrCode | integer | 4G卡切换结果；0-成功，非0值表示切换失败 | 是 | 是 | 否 | 只读 | 0-成功，非0值表示切换失败 |  ||

##### 请求URL

 - `/Network/4GCardSelectResult` 

##### 请求方式

- get
