# 远程抓图
##### 简要描述

URI中的<ChannelID>显示通道编号，<ChannelID>从1开始。
“ImageFormat”是图像类型，如bmp，jpg等，如果“ImageFormat”为1，你捕获的图片是bmp的格式，如果“ImageFormat”是2，它是jpg的格式，默认是 jpg的格式，所以，你应该将“ImageFormat”设置为2，如果你将“ImageFormat”设置为其他值，也许你会得到一个你不想看到的结果。
"HorizontalPixel"对应分辨率中的水平像素，"VerticalPixel"对应分辨率中的垂直像素，如分辨率1920x1080对应HorizontalPixel=1920，VerticalPixel=1080
比如:
    [http://192.168.1.46/Snapshot/1/RemoteImageCapture?ImageFormat=2&HorizontalPixel=1920&VerticalPixel=1080](http://192.168.1.46/Snapshot/1/RemoteImageCapture?ImageFormat=2&HorizontalPixel=1920&VerticalPixel=1080)

##### 请求URL

 - `/Snapshot/ChannelID/RemoteImageCapture` 

##### 请求方式

- get
