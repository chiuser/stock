# 获取指定通道指定码流的MJPEG流
##### 简要描述

- URI中的<ChannelID>是通道编号。<ChannelID>从1开始。
默认打开的是子码流。
<StreamID>表示流类型，通常“1”表示主流，“2”表示“第一个子流”，依此类推。

##### 请求URL

 - `/Streams/ChannelID/StreamID/ReceiveData` 

##### 请求方式

- get
