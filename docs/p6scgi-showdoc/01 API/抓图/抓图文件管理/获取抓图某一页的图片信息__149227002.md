# 获取抓图某一页的图片信息
##### 简要描述
获取抓拍图片集合中某一页的抓拍图片信息
 ##### 说明

Example:**<span class="size"></span>**
[http://192\.168\.0\.180/SnapshotFileList/Pages/1?Pathtype=0\|1](http://192.168.0.180/RecordFileList/Pages/1?Pathtype=0%7C1)**(0，<PathName>相对于http根目录.1，<PathName>是绝对路径。)**

##### **请求**

**xml**
无
**字段说明**
无

##### **响应**

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<SnapshotFileList>
   <SnapshotFile>
      <PathName><!--ro,req,xs:string; the max length 64--></PathName>
      <FileName><!--ro,req,xs:string; the max length 32--></FileName>
      <SnapshotTime><!--ro,req,xs:string; the max length 32--></SnapshotTime>
      <FileSize><!--ro,req,xs:interger,the unit is byte--></FileSize>
   </SnapshotFile>
</SnapshotFileList>
```
