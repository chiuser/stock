# 设置抓图文件列表属性
##### 简要描述

- ##### 说明

当http协议的方法为“PUT”时，<begin_time>，<end_time>，<timezone_min_between_utc>有效。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<SnapshotFileListAttribute>
     <SnapshotFileSumCount><!--rw,req,xs:integer--></SnapshotFileSumCount>
     <SnapshotFileCountPerPage><!--rw,req,xs:integer--></SnapshotFileCountPerPage>
     <begin_time><!--wo,opt,xs:string,”20180507 020445”--></begin_time>
     <end_time><!--wo,opt,xs:string” 20180507 020445”--></end_time>
     <timezone_min_between_utc><!--wo,opt,xs:integer,the unit is minute --></timezone_min_between_utc>
</SnapshotFileListAttribute>
```
