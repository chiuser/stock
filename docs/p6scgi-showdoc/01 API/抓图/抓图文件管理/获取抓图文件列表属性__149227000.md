# 获取抓图文件列表属性
##### 简要描述
获取抓图文件的文件列表属性信息
 ##### 请求

**xml**
无
**字段说明**
无

##### **响应**

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<SnapshotFileListAttribute>
     <SnapshotFileSumCount><!--rw,req,xs:integer--></SnapshotFileSumCount>
     <SnapshotFileCountPerPage><!--rw,req,xs:integer--></SnapshotFileCountPerPage>
</SnapshotFileListAttribute>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| SnapshotFileListAttribute |  |  |  |  |  |  |  |  |  |  | <span class="colour" style="color: rgb(0, 0, 0);">设备能力专用URL：/System/DeviceCap；能力定义：Device-FunctionList-SD</span> |  |
| SnapshotFileSumCount | integer | <span class="colour" style="color:rgb(106, 153, 85)">抓图文件总数</span> | 是 | 是 | 否 | 可读可写 | 取值范围需与设备确认 |  |  | <span class="colour" style="color:rgb(206, 145, 120)">配置-存储-存储设备-查询图片-查询-查询结果展示的总条数</span> |  | <span class="colour" style="color: rgb(85, 85, 85);">无</span> |
