# 设置定时抓拍配置
##### 简要描述
设置定时抓拍功能的配置参数
##### 请求

**xml**

```
<TimedCaptureConfig Version="1.0">
    <Enable><!--rw,req,xs:boolean--></Enable>
    <TimedCaptureFTP Version="1.0">
        <Enable><!--rw,req,xs:boolean--></Enable>
        <CapturePictureCount><!--rw,opt,xs:integer，抓拍张数--></CapturePictureCount>
        <TimeInterval><!--rw,req,xs:integer，抓拍间隔--></TimeInterval>
    </TimedCaptureFTP>
    <TimedCaptureSD Version="1.0">
        <Enable><!--rw,req,xs:boolean--></Enable>
        <CapturePictureCount><!--rw,opt,xs:integer，抓拍张数--></CapturePictureCount>
        <TimeInterval><!--rw,req,xs:integer，抓拍间隔--></TimeInterval>
    </TimedCaptureSD>
    <TimedCaptureMQTT Version="1.0">
        <Enable><!--rw,req,xs:boolean--></Enable>
        <CapturePictureCount><!--rw,req,xs:integer，抓拍张数--></CapturePictureCount>
        <TimeInterval><!--rw,opt,xs:integer，抓拍间隔--></TimeInterval>
    </TimedCaptureMQTT>
</TimedCaptureConfig>
```
