# 指定通道人形检测相关配置版本说明
#### 版本说明
指定通道人形检测相关配置有V0、V1两个版本，区别在支持的功能

#### V1版本
V1版本支持获取和设置人形检测功能的界面配置参数、检测区域、表格方式的布防计划和联动方式

#### V2版本
V2版本在V1版本的基础上支持时间段方式的布防计划
