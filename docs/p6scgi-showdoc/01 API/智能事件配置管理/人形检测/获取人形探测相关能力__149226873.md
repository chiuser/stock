##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<PeopleAbility>
    <isSupportPeople><!--ro,req,xs:boolean; "false","true"--></isSupportPeople>
    <TrackBox>
        <IsSupportMainStream><!--ro,req,xs:boolean; "false","true"--></IsSupportMainStream>
        <IsSupportSubStream><!--ro,req,xs:boolean; "false","true"--></IsSupportSubStream>
        <IsSupportSecSubStream><!--ro,req,xs:boolean; "false","true"--></IsSupportSecSubStream>
    </TrackBox>
</PeopleAbility>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| isSupportPeople | boolean | 是否支持人形探测；false 否，true 是 | 是 | 是 | 否 | 只读 | false/true |  |
| TrackBox |  |  | 是 | 是 |  |  |  |  |
| IsSupportMainStream | boolean | 是否支持主码流；false 否，true 是 | 是 | 是 | 否 | 只读 | false/true |  |
| IsSupportSubStream | boolean | 是否支持子码流；false 否，true 是 | 是 | 是 | 否 | 只读 | false/true |  |
| IsSupportSecSubStream | boolean | 是否支持第二子码流；false 否，true 是 | 是 | 是 | 否 | 只读 | false/true |  ||
