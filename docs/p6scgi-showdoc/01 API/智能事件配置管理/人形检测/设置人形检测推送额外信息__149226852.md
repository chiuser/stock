# 设置人形检测推送额外信息
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**

```
<PeopleDetectExtraInfoSwitch>
    <ChannelID><!--rw,opt,xs:Interger--></ChannelID>
    <Enable><!--rw,opt,xs:boolean; "false","true"--></Enable>
</PeopleDetectExtraInfoSwitch>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ChannelID | integer | 通道ID，从1递增 | 否 | 是 | 否 | 可读可写 | [1-32] |  |
| Enable | boolean | 是否启用人形推送额外信息 | 否 | 是 | 否 | 可读可写 | false/true |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/Pictures/ChannelID/PeopleDetectExtraInfoSwitch` 

##### 请求方式

- put
