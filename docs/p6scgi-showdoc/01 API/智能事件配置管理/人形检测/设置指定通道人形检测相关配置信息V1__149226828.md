# 设置指定通道人形检测相关配置信息V1
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

MainStreamOverlay：主码流人形叠加框
SubStreamOverlay：子码流人形叠加框
