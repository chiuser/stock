# 获取人形检测停留时间
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<PeopleDetectStayTime>
    <StayTime><!--rw,opt,xs:integer--></StayTime>
</PeopleDetectStayTime>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| StayTime<span lang="EN-US"></span> | integer | 人形跟踪停留时间，单位：秒<span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 取值需与设备确认 |  ||

##### 请求URL

 - `/Pictures/ChannelID/PeopleDetectStayTime` 

##### 请求方式

- get

```
[]
```
