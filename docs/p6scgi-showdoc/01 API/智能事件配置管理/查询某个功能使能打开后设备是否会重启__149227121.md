# 查询某个功能使能打开后设备是否会重启
##### 简要描述

- ##### 请求

**xml**

```
<DeviceCapInfo>
    <DeviceCapability><!--rw,opt,xs:integer--></DeviceCapability>
</DeviceCapInfo>
```

**字段说明**

| 字段 | 类型 | 说明 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| DeviceCapability | integer | 设备能力;1-电子围栏,2-越界侦测,3-离岗侦测,4-客流统计,5-目标跟踪,6-人脸抓拍,7-人脸识别,8-车牌抓拍 | 否 | 是 | 否 | 可读可写 | 1/2/3/4/5/6/7/8 |  |  | <span class="colour" style="color: rgb(206, 145, 120);">启用事件配置时会调用  <br><br>  智能事件是互斥的，启用部分事件时会切换算法，设备需要修改内存配置并重启(例如由电子围栏、越界侦测、离岗侦测、客流统计切换到目标跟踪、人脸抓拍、人脸识别、车牌抓拍，电子围栏、越界侦测、离岗侦测、客流统计之间切换不需要重启)，为避免切换事件时设备直接重启给客户造成设备异常的错觉，新增该接口提示客户是否切换事件并重启设备</span> | <span class="colour" style="color: rgb(206, 145, 120);">设备能力专用URL：/System/DeviceCap <br><br> 能力定义：Device-ConfigReboot-ElectronicFence、TraversePlane、OffDuty、PassengerFlow、ObjectTrack、FaceSnapshot、FaceReco、LPR、CarPark、TrafficFlow、FireDetect、LPSurveillance</span> | 无 |

##### 响应

**xml**

```
<DeviceCapInfo>
    <DeviceCapability><!--rw,opt,xs:integer--></DeviceCapability>
    <IsNeedReboot><!--ro,opt,xs:boolean--></IsNeedReboot>
</DeviceCapInfo>
```

**字段说明**

| 字段 | 类型 | 说明 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| DeviceCapability | integer | 设备能力;1-电子围栏,2-越界侦测,3-离岗侦测,4-客流统计,5-目标跟踪,6-人脸抓拍,7-人脸识别,8-车牌抓拍 | 否 | 是 | 否 | 可读可写 | 1/2/3/4/5/6/7/8 |  |  | <span class="colour" style="color: rgb(206, 145, 120);">启用事件配置时会调用 <br> <br> 智能事件是互斥的，启用部分事件时会切换算法，设备需要修改内存配置并重启(例如由电子围栏、越界侦测、离岗侦测、客流统计切换到目标跟踪、人脸抓拍、人脸识别、车牌抓拍，电子围栏、越界侦测、离岗侦测、客流统计之间切换不需要重启)，为避免切换事件时设备直接重启给客户造成设备异常的错觉，新增该接口提示客户是否切换事件并重启设备</span> | <span class="colour" style="color: rgb(206, 145, 120);">设备能力专用URL：/System/DeviceCap <br><br> 能力定义：Device-ConfigReboot-ElectronicFence、TraversePlane、OffDuty、PassengerFlow、ObjectTrack、FaceSnapshot、FaceReco、LPR、CarPark、TrafficFlow、FireDetect、LPSurveillance</span>  | 无 |
| IsNeedReboot | boolean | 是否需要重启;true-使能,false-不使能 | 否 | 是 | 否 | 只读 | false/true |  |  | 网页弹窗提示是否需要重启 |  | 无 |

##### 请求URL

 - `/AI/DeviceNeedReboot` 

##### 请求方式

- post
