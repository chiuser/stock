# 电子围栏版本说明
### 电子围栏版本说明
电子围栏有V1、V2两个版本，区别在检测目标、检测方向的不同

### 电子围栏V1
检测目标：只支持人、机动车，且只能检测单个目标
检测方向：支持进入、离开检测区域，且只能检测单个方向

### 电子围栏V2
检测目标：支持人、机动车、非机动车，且能支持多个检测目标，同时支持后续新增检测目标
检测方向：支持进入、离开、滞留检测区域，且能检测多个方向
