# 查询脸库中符合条件的人员信息个数
##### 简要描述

- #### 以T5AI设备为例说明

**说明**
    <span class="colour" style="color:rgb(255, 0, 0)">设备端支持通过人名、建模状态、组织ID进行条件查询；建模状态必传且不可为空，不支持通过人名模糊查询，组织ID不可传脸库ID</span>

##### **请求**

**_xml_**

```
<PersonInfoFilter>
    <GroupID><!-- wo,req,xs:interger,-1 is all --></GroupID>
    <Name><!-- wo,req,xs:string --></Name>
    <Sex><!-- wo,req,xs:string, "none,male,female" --></Sex>
    <CertificateType><!-- wo,req,xs:string,"none,passport,IC,custom,other"--></CertificateType>
    <CertificateID><!-- wo,req,xs:string(max size:32)--></CertificateID>
    <Country><!-- wo,req,xs:string(max size:64) --></Country>
    <Address><!-- wo,req,xs:string(max size:256)--></Address>
    <StartBirthday><!-- wo,req,xs:datetime,”20190610T020202”--></StartBirthday>
    <StopBirthday><!-- wo,req,xs:datetime”20190610T020202”--></StopBirthday>

</PersonInfoFilter>
```
