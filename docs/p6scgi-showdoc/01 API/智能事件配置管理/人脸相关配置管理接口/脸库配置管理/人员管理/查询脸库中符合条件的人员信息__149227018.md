##### 简要描述

- #### 以T5AI设备为例说明

**说明**
    <span class="colour" style="color:rgb(255, 0, 0)">设备端支持通过人名、建模状态、组织ID进行条件查询；不支持通过人名模糊查询，组织ID不可传脸库ID</span>
