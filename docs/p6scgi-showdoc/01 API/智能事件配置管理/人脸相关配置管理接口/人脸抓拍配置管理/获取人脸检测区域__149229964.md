# 获取人脸检测区域
##### 简要描述

- #### 以T5AI设备为例说明

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<FaceDetectRegion>
    <Region>
        <ID><!--rw,req,xs:interger--></ID>
        <TopLeftX><!--rw,req,xs:interger,”0~10000”--></TopLeftX>
        <TopLeftY><!--rw,req,xs:interger,”0~10000”--></TopLeftY>
        <BottomRightX><!--rw,req,xs:interger,”0~10000”--></BottomRightX>
        <BottomRightY><!--rw,req,xs:interger,”0~10000”--></BottomRightY>
    </Region>
</FaceDetectRegion>
```

**响应xml**

| 字段 | 类型 | 描述 | 是否必须 | 字段是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ------ | ----- | ---------------------- | ------- | --- |
| Region |  | <span class="colour" style="color:rgb(106, 153, 85)">人脸检测区域</span> | 是 | 是 |  |  |  |  |
