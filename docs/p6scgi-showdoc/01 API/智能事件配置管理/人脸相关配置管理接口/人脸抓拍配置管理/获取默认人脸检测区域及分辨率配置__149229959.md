# 获取默认人脸检测区域及分辨率配置
##### 简要描述

 ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<DefaultFaceRegionInfo>
    <DetectRegion>
        <TopLeftX><!--ro,req,xs:Interger--></TopLeftX>
        <TopLeftY><!--ro,req,xs:Interger--></TopLeftY>
        <BottomRightX><!--ro,req,xs:Interger--></BottomRightX>
        <BottomRightY><!--ro,req,xs:Interger--></BottomRightY>
    </DetectRegion>
    <MaxFaceSize>
        <Width><!--ro,req,xs:Interger--></Width>
        <Height><!--ro,req,xs:Interger--></Height>
    </MaxFaceSize>
    <MinFaceSize>
        <Width><!--ro,req,xs:Interger--></Width>
        <Height><!--ro,req,xs:Interger--></Height>
    </MinFaceSize>
</DefaultFaceRegionInfo>
```
