# 设置人脸检测区域
##### 简要描述

- #### 以T5AI设备为例说明

**xml**

``` xml
<?xml version="1.0" encoding="UTF-8" ?>
<FaceDetectRegion>
    <Region>
        <ID><!--rw,req,xs:interger--></ID>
        <TopLeftX><!--rw,req,xs:interger,”0~10000”--></TopLeftX>
        <TopLeftY><!--rw,req,xs:interger,”0~10000”--></TopLeftY>
        <BottomRightX><!--rw,req,xs:interger,”0~10000”--></BottomRightX>
        <BottomRightY><!--rw,req,xs:interger,”0~10000”--></BottomRightY>
    </Region>
</FaceDetectRegion>
```

**请求xml**

| 字段 | 类型 | 描述 | 是否必须 | 字段是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ------ | ----- | ---------------------- | ------- | --- |
| Region |  | <span class="colour" style="color:rgb(106, 153, 85)">人脸检测区域</span> | 否 | 是 |  |  |  |  |
| ID | interger | <span class="colour" style="color:rgb(106, 153, 85)">人脸检测区域ID，从0递增</span> | 否 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(106, 153, 85)">从0递增</span> |  |
| TopLeftX | interger | <span class="colour" style="color:rgb(106, 153, 85)">人脸检测区域的左上点x相对坐标</span> | 否 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(106, 153, 85)"><span class="colour" style="color:rgb(106, 153, 85)">（0-703）</span></span> |  |
| TopLeftY | interger | <span class="colour" style="color:rgb(106, 153, 85)">人脸检测区域的左上点y相对坐标</span> | 否 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(106, 153, 85)"><span class="colour" style="color:rgb(106, 153, 85)">（0-575）</span></span> |  |
| BottomRightX | interger | <span class="colour" style="color:rgb(106, 153, 85)">人脸检测区域的右下点x相对坐标</span> | 否 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(106, 153, 85)"><span class="colour" style="color:rgb(106, 153, 85)">（0-703）</span></span> |  |
| BottomRightY | interger | <span class="colour" style="color:rgb(106, 153, 85)">人脸检测区域的右下点y相对坐标</span> | 否 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(106, 153, 85)"><span class="colour" style="color:rgb(106, 153, 85)">（0-575）</span></span> |  ||
