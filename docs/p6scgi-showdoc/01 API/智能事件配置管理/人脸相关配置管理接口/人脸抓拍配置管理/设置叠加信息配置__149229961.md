# 设置叠加信息配置
##### 简要描述

- ##### 说明

EnableFaceTrackFrame：人脸跟踪框
EnableBackEndSuperposition：后端叠加使能

##### 请求

**xml**

```
<FaceOverlayInfo>
    <FaceTrackFrame>
        <EnableFaceTrackFrame><!--rw,req,xs:boolean--></EnableFaceTrackFrame>
        <EnableBackEndSuperposition><!--rw,req,xs:boolean--></EnableBackEndSuperposition>
    </FaceTrackFrame>
    <EnableFaceStatistcs><!--rw,req,xs:boolean--></EnableFaceStatistcs>
    <FaceTrackFrame_SubStream>
        <EnableFaceTrackFrame><!--rw,req,xs:boolean--></EnableFaceTrackFrame>
        <EnableBackEndSuperposition><!--rw,req,xs:boolean--></EnableBackEndSuperposition>
    </FaceTrackFrame_SubStream>
    <FaceTrackFrame_SecondSubStream>
        <EnableFaceTrackFrame><!--rw,req,xs:boolean--></EnableFaceTrackFrame>
        <EnableBackEndSuperposition><!--rw,req,xs:boolean--></EnableBackEndSuperposition>
    </FaceTrackFrame_SecondSubStream>
</FaceOverlayInfo>
```
