# 获取人脸过滤区域分辨率
##### 简要描述

- #### 以T5AI设备为例说明

**xml**

``` xml
<?xml version="1.0" encoding="UTF-8" ?>
<FaceFilterRegionSize>
    <MaxFaceRegionSize>
        <Width><!--rw,req,xs:interger,”0~10000”--></Width>
        <Height><!--rw,req,xs:interger,”0~10000”--></Height>
    </MaxFaceRegionSize>
    <MinFaceRegionSize>
        <Width><!--rw,req,xs:interger,”0~10000”--></Width>
        <Height><!--rw,req,xs:interger,”0~10000”--></Height>
    </MinFaceRegionSize>
</FaceFilterRegionSize>
```

**响应xml**

| 字段 | 类型 | 描述 | 是否必须 | 字段是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ------ | ----- | ---------------------- | ------- | --- |
| MaxFaceRegionSize |  | 最大人脸过滤区域 | 是 | 是 |  |  |  |  |
| Width | interger | 最大人脸过滤区域分辨率的高度， | 是 | 是 | 否 | 可读可写 | 取值范围[0-10000] |  |
| Height | interger | 最大人脸过滤区域分辨率的宽度 | 是 | 是 | 否 | 可读可写 | 取值范围[0-10000] |  |
| MinFaceRegionSize |  | 最小人脸过滤区域 | 是 | 是 |  |  |  |  |
| Width | interger | 最小人脸过滤区域分辨率的高度 | 是 | 是 | 否 | 可读可写 | 取值范围[0-10000] |  |
| Height | interger | 最小人脸过滤区域分辨率的宽度 | 是 | 是 | 否 | 可读可写 | 取值范围[0-10000] |  ||
