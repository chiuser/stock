# 获取人脸算法版本
##### 简要描述

- ##### **请求**

**xml**
无
**字段说明**
无

##### **响应**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<FaceAlgorithmVersion Version="1.0">
    <FeatureVersion><!--rw,opt,xs:string,max size 32--></FeatureVersion>
    <Manufacturer><!--rw,opt,xs:string,max size 16--></Manufacturer>
    <Platform><!--rw,opt,xs:string,max size 16--></Platform>
</FaceAlgorithmVersion>
```

**字段说明**

| 字段 | 值 | 解释 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
|  |  |  |  |  |  |  |  |  |  | web没有调用接口 |  |  |
| FeatureVersion | string | 特征值版本，最大长度32 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |  |  |  |  |
| Manufacturer | string | 厂商名，最大长度16 | 否 | 是 | 否 | 可读可写 | 最大长度16 |  |  |  |  |  |
| Platform | string | 平台名，最大长度16 | 否 | 是 | 否 | 可读可写 | 最大长度16 |  |  |  |  |  ||
