# 获取人脸智能曝光配置
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<FaceSmartExposure>
    <ChannelID><!--ro,opt,xs:integer--></ChannelID>
    <Enable><!--rw,opt,xs:boolean; "false","true"--></Enable>
    <WorkThreshold><!--rw,opt,xs:integer--></WorkThreshold>
    <FaceBrightness><!--rw,opt,xs:integer--></FaceBrightness>
</FaceSmartExposure>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ChannelID | <span class="colour" style="color:black">integer</span><span lang="EN-US"></span> | 通道编号，从1开始。<span lang="EN-US"></span> | <span class="colour" style="color:black">否</span><span lang="EN-US"></span> | <span class="colour" style="color:black">是</span> | 否 | 只读 | [1-32] |  |
| Enable | boolean | 是否启用人脸智能曝光<span lang="EN-US"></span> | <span class="colour" style="color:black">否</span><span lang="EN-US"></span> | <span class="colour" style="color:black">是</span> | 否 | 可读可写 | false/true |  |
| WorkThreshold | <span class="colour" style="color:black">integer</span> | 智能曝光阈值；值越小，智能曝光功能就越灵敏<span lang="EN-US"></span> | <span class="colour" style="color:black">否</span><span lang="EN-US"></span> | <span class="colour" style="color:black">是</span> | 否 | 可读可写 | 0-100 |  |
| FaceBrightness | <span class="colour" style="color:black">integer</span> | 人脸亮度；值越大，曝光后人脸越亮<span lang="EN-US"></span> | <span class="colour" style="color:black">否</span><span lang="EN-US"></span> | <span class="colour" style="color:black">是</span> | 否 | 可读可写 | 0-100 |  ||

##### 请求URL

 - `/Pictures/ChannelID/FaceSmartExposure` 

##### 请求方式

- get
