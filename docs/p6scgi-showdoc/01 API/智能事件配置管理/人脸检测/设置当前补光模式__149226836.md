# 设置当前补光模式
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Pictures>
    <LightFillingMode><!--rw,req,xs:string:”PowerSaving”,”Warning”,”AlwayLight”--></LightFillingMode>
    <DayStartTime><!--rw,req,xs:string;format "hh:mm:ss",max length 32 --></DayStartTime>
    <DayEndTime><!--rw,req,xs:string;format "hh:mm:ss",max length 32 --></DayEndTime>
</Pictures>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| LightFillingMode | string | <span class="colour" style="color:rgb(106, 153, 85)">补光模式；</span><span class="colour" style="color:rgb(206, 145, 120)">PowerSaving </span><span class="colour" style="color:rgb(106, 153, 85)">省电模式，</span><span class="colour" style="color:rgb(206, 145, 120)">Warning </span><span class="colour" style="color:rgb(106, 153, 85)">告警模式，</span><span class="colour" style="color:rgb(206, 145, 120)">AlwayLight </span><span class="colour" style="color:rgb(106, 153, 85)">常亮模式</span> | 是 | 是 | 否 | 可读可写 | 动态数组 |  |
| DayStartTime | string | <span class="colour" style="color:rgb(106, 153, 85)">补光起始时间，</span><span class="colour" style="color:rgb(206, 145, 120)">AlwayLight </span><span class="colour" style="color:rgb(106, 153, 85)">常亮模式下有效；24小时制，格式：hh:mm:ss</span> | 是 | 是 | 否 | 可读可写 | 最大长度32 |  |
| DayEndTime | string | <span class="colour" style="color:rgb(106, 153, 85)">补光结束时间，</span><span class="colour" style="color:rgb(206, 145, 120)">AlwayLight </span><span class="colour" style="color:rgb(106, 153, 85)">常亮模式下有效；24小时制，格式：hh:mm:ss</span> | 是 | 是 | 否 | 可读可写 | 最大长度32 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/Pictures/ChannelID/LightFillingMode` 

##### 请求方式

- put
