# 查询定时提醒自定义语音信息
##### 简要描述

 ##### 说明

##### 请求
**xml**
无
**字段说明**
无


##### 响应

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<TimeRemindAudioInfoList>
	<TimeRemindAudioInfo>
    	<ID><!--rw,req,xs:integer--></ID>
		<Name><!--rw,req,xs:string; max length 128 --></Name>
	</TimeRemindAudioInfo>
</TimeRemindAudioInfoList>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| ID | integer | 自定义语音ID,与定时提醒计划中的语音类型对应; 0:自定义语音1, 6:自定义语音2, 7:自定义语音3 | 是 | 是 | 否 | 可读可写 |  |  |  | 无 | 无 |  |
| Name | string | 自定义语音名称; unicode编码 | 是 | 是 | 否 | 可读可写 | 最大长度128 |  |  | 无 | 无 |  | |


##### 请求URL

 - `/System//TimeRemindAudioInfoQuery` 

##### 请求方式

- get
