# 添加定时提醒计划
##### 简要描述

##### 说明
定时提醒的自定义语音数据通过  [/System/DeviceCustomFunction](http://zwp2p.p6sai.com:4999/web/#/663863654/149226554 "/System/DeviceCustomFunction") 添加

##### 请求

**xml**

```xml
<TimeRemindPlanList>
	<TimeRemindPlan>
		<Enable><!-- rw,req,xs:boolean;false,true --></Enable>
		<VoiceType><!--rw,req,xs:integer;[0-7]--></VoiceType>
		<VoiceTypeName><!--rw,req,xs:string,max length 64, --></VoiceTypeName>
		<BroadcastCount><!--rw,req,xs:integer;--></BroadcastCount>
		<BroadcastVolume><!--rw,req,xs:integer;[0-100],default 90--></BroadcastVolume>
		<Period><!--rw,req,xs:string,max length 8, eg:11111111 --></Period>
		<RemindTime><!--rw,req,xs:string,max length 32, format:YYYY-MM-DDThh:mm:ss--></RemindTime>
		<RemindName><!--rw,req,xs:string,max length 128, --></RemindName>
	</TimeRemindPlan>
</TimeRemindPlanList>

```
