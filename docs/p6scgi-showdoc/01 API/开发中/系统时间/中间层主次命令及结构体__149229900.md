# 中间层主次命令及结构体
##### 简要描述
 新增 dwSyncAllTimeFlag，表示是否同步所有时间标识; 0表示不同步，1表示同步

**xml**

//主类型
/** @brief 获取设备配置参数                                                      */

/** @brief 设置设备配置参数                                                      */
#define HY_DVR_SET_DEVICECFG                126
