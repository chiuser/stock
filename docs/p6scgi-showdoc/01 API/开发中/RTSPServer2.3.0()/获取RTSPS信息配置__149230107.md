# 获取RTSPS信息配置
##### 简要描述

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```xml
<?xml version="1.0" encoding="utf-8"?>
<RTSPSCfg>
    <Enable><!--rw,req,xs:boolean,”true,false”--></Enable>
    <Port><!--rw,req,xs:integer,--></Port>
</RTSPSCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | boolean | 是否启用RTSPS；true启用，false不启用 | 是 | 是 | 否 | 可读可写 | true，false |  |  |  |  |  |
| Port | integer | RTSPS端口 | 是 | 是 | 否 | 可读可写 | |  |  |  |  |  ||

##### 请求URL

 - `/System/RTSPSCfg`

##### 请求方式

- get
