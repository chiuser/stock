# 设置HTTPS信息配置
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<HTTPSCfg>
    <Enable><!—-rw,req,xs:boolean,”true,false”--></Enable> <!-- 是否启用https；true启用，false不启用  -->
    <HTTPSPort><!—-rw,req,xs:integer,--></HTTPSPort> <!-- https端口  -->
    <TLSVersion><!—-rw,req,xs:string,--></TLSVersion>  <!-- TLS版本；TLSV1.1，TLSV1.2  -->
</HTTPSCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | boolean | 是否启用https；true启用，false不启用 | 是 | 是 | 否 | 可读可写 | true，false |  |  |  |  |  |
| HTTPSPort | integer | https端口 | 是 | 是 | 否 | 可读可写 | |  |  |  |  |  |
| TLSVersion | string | TLS版本；TLSV1.1，TLSV1.2 | 是 | 是 | 否 | 可读可写 | TLSV1.1，TLSV1.2 |  |  |  |  |  ||
