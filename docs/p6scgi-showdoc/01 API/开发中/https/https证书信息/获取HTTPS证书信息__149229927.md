# 获取HTTPS证书信息
##### 简要描述

- ##### 请求

**请求示例**

```
<?xml version="1.0" encoding="utf-8"?>
<HTTPSCertificationInfo>
    <CertificationStatus><!—-ro,req,xs:string,--></CertificationStatus>  <!-- 证书状态；1.NoCertifacation - 无证书，2.Uninstall - 未安装，3.Installed - 已安装，4.CertificationExpireSoon - 证书即将过期, 5.CertificationExpired - 证书已过期, 6.CertificationInvalid - 证书无效  -->
    <CertificateHolderInfo><!—-ro,req,xs:string, max length 2048--></CertificateHolderInfo> <!-- 证书持有者信息  -->
    <CertificateDetailContent><!—-ro,req,xs:string, max length 4096--></CertificateDetailContent> <!-- 证书详细内容 -->
</HTTPSCertificationInfo>
```


**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| CertificationStatus | string | 证书状态；1.NoCertifacation - 无证书，2.Uninstall - 未安装，3.Installed - 已安装，4.CertificationExpireSoon - 证书即将过期, 5.CertificationExpired - 证书已过期, 6.CertificationInvalid - 证书无效 | 是 | 是 | 否 | 只读 |  |  |  |  |  |  |
| CertificateHolderInfo | string | 证书持有者信息 | 是 | 是 | 否 | 只读 | 最大长度2048 |  |  |  |  |  |
| CertificateDetailContent | string | 证书详细内容 | 是 | 是 | 否 | 只读 | 最大长度4096 |  |  |  |  |  ||
