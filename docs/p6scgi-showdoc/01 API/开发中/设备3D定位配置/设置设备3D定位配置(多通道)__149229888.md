# 设置设备3D定位配置(多通道)
##### 简要描述

- ##### 请求

**请求示例**

```
<?xml version="1.0" encoding="utf-8"?>
<Device3DPositioningCfg>
    <Operator><!-- rw,req,xs:interger --></Operator>
    <_3DPositionCoord>
        <PointLeftTop>
            <PosX><!-- rw,req,xs:interger --></PosX>
            <PosY><!-- rw,req,xs:interger --></PosY>
        </PointLeftTop>
        <PointRightTop>
            <PosX><!-- rw,req,xs:interger --></PosX>
            <PosY><!-- rw,req,xs:interger --></PosY>
        </PointRightTop>
        <PointRightBottom>
            <PosX><!-- rw,req,xs:interger --></PosX>
            <PosY><!-- rw,req,xs:interger --></PosY>
        </PointRightBottom>
        <PointLeftBottom>
            <PosX><!-- rw,req,xs:interger --></PosX>
            <PosY><!-- rw,req,xs:interger --></PosY>
        </PointLeftBottom>
        <PointCenter>
            <PosX><!-- rw,req,xs:interger --></PosX>
            <PosY><!-- rw,req,xs:interger --></PosY>
        </PointCenter>
    </_3DPositionCoord>
</Device3DPositioningCfg>
```


**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |

| _3DPositionCoord |  | 3D定位坐标信息 |  |  |  |  |  |  |  |  |  |  |
| PointLeftTop |  | 3D定位区域(矩形)左上点 |  |  |  |  |  |  |  |  |  |  |
| PosX | interger | 3D定位区域(矩形)左上点x坐标 | 是 | 是 | 否 | 可读可写 | [0,10000] |  |  |  |  |  |
| PosY | interger | 3D定位区域(矩形)左上点y坐标 | 是 | 是 | 否 | 可读可写 | [0,10000] |  |  |  |  |  |
| PointRightTop |  | 3D定位区域(矩形)右上点 |  |  |  |  |  |  |  |  |  |  |
| PosX | interger | 3D定位区域(矩形)右上点x坐标 | 是 | 是 | 否 | 可读可写 | [0,10000] |  |  |  |  |  |
| PosY | interger | 3D定位区域(矩形)右上点y坐标 | 是 | 是 | 否 | 可读可写 | [0,10000] |  |  |  |  |  |
| PointRightBottom |  | 3D定位区域(矩形)右下点 |  |  |  |  |  |  |  |  |  |  |

| PosY | interger | 3D定位区域(矩形)左下点y坐标 | 是 | 是 | 否 | 可读可写 | [0,10000] |  |  |  |  |  |
