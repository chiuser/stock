# 获取P6SCMS平台配置信息
##### 简要描述

 ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="UTF-8"?>
<P6SCMSConfig Version="1.0">
    <ServerDomain><!-- rw,req,string, max length 256 --></ServerDomain>
    <ServerPort><!-- rw,req,integer, [0,65535] --></ServerPort>
    <Path><!-- rw,req,string, max length 128 --></Path>
    <UserName><!-- rw,req,string, max length 64 --></UserName>
    <SupportedFeatures><!-- rw,req,string --></SupportedFeatures>
    <Enable><!-- rw,req,integer, [0,1] --></Enable>
    <ProtocolType><!-- rw,req,string, max length 32 --></ProtocolType>
    <ConnectionStatus><!-- ro,req,integer --></ConnectionStatus>
    <ErrorCode><!-- ro,req,integer --></ErrorCode>
    <LastReqTimestamp><!-- ro,req,string, max length 32 --></LastReqTimestamp>
</P6SCMSConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| ServerDomain | string | CMS平台地址(可以为IP或域名),最大长度256 | 是 | 是 | 否 | 可读可写 | 最大长度256 |  |  | 配置-网络-云端配置-设备云端配置管理-服务器域名 |  |  |
| ServerPort | integer | CMS平台端⼝,默认443 | 是 | 是 | 否 | 可读可写 | 默认443 |  |  | 配置-网络-云端配置-设备云端配置管理-服务器端口 |  |  |
| Path | string | CMS平台url,最大长度128 | 是 | 是 | 否 | 可读可写 | 最大长度128 |  |  | 配置-网络-云端配置-设备云端配置管理-路径 |  |  |
| UserName | string | 用户名,最大长度64 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |  | 配置-网络-云端配置-设备云端配置管理-用户名 |  |  |
| SupportedFeatures | string | ⽀持功能列表,目前支持gb28181,mqtt,rtmp | 是 | 是 | 否 | 可读可写 | gb28181,mqtt,rtmp |  |  | 配置-网络-云端配置-云端配置-支持功能 |  |  |
| Enable | integer | 使能开关,1-开，0-关 | 是 | 是 | 否 | 可读可写 | 0,1 |  |  | 配置-网络-云端配置-云端配置-云端自动配置 |  |  |
| ProtocolType | string | 协议类型，http,https | 是 | 是 | 否 | 可读可写 | http,https |  |  | 配置-网络-云端配置-云端配置-协议 |  |  |
| ConnectionStatus | integer | 连通状态；0:未知,1:成功, 2:失败,  默认值0 该参数由设备赋值，对客户端来说是只读参数 | 是 | 是 | 否 | 只读 | 0:未知,1:成功, 2:失败,  默认值0 |  |  | 配置-网络-云端配置-云端配置-当前连接状态 |  |  |
| ErrorCode | integer | 错误码 | 是 | 是 | 否 | 只读 |  |  |  |  |  |  |
| LastReqTimestamp | string | 上次请求时间戳，最大长度64，格式：YYYY-MM_DD hh:mm:ss | 是 | 是 | 否 | 只读 | 最大长度64 |  |  | 配置-网络-云端配置-云端配置-上次通信时间 |  |  | |
