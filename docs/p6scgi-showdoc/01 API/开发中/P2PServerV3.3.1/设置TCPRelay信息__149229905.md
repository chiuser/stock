# 设置TCPRelay信息

 ##### 说明


##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<TCPRelayInfo>
    <Enable><!--rw,req,xs:boolean;"false","true"--></Enable>
</TCPRelayInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| TCPRelayInfo |  |  |  |  |  |  |  |  |  |  |  |  |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否使能TCPRelay；false-否，true-是</span> | 是 | 是 | 否 | 可读可写 | false/true |  |  | 无 | 无 |  | |
