# 设置P6SGA1400平台配置信息
##### 简要描述

##### 请求


**xml**

```xml
<?xml version="1.0" encoding="UTF-8"?>
<P6SGA1400Config Version="1.0">
	<Enable><!-- rw,req,boolean --></Enable>
    <ServerAddress><!-- rw,req,string, max length 256 --></ServerAddress>
    <ServerPort><!-- rw,req,integer, [0,65535] --></ServerPort>
    <UserName><!-- rw,req,string, max length 64 --></UserName>
	<Password><!-- rw,req,string, max length 64 --></Password>
	<DeviceID><!-- rw,req,string, max length 128 --></DeviceID>
    <ProtocolType><!-- rw,req,string, max length 32 --></ProtocolType>
	<RegisterInterval><!-- rw,req,integer --></RegisterInterval>
	<KeepAliveInterval><!-- rw,req,integer --></KeepAliveInterval>
</P6SGA1400Config>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | integer | 使能开关,true-开，false-关 | 是 | 是 | 否 | 可读可写 | false，true |  |  |  |  |  |
| ServerAddress | string | 平台地址(可以为IP或域名),最大长度256 | 是 | 是 | 否 | 可读可写 | 最大长度256 |  |  |  |  |  |
| ServerPort | integer | 平台端⼝ | 是 | 是 | 否 | 可读可写 | (0,65535] |  |  |  |  |  |
| UserName | string | 用户名,最大长度64 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |  |  |  |  |
| Password | string | 密码,最大长度64 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |  |  |  |  |
| DeviceID | string | 设备ID | 是 | 是 | 否 | 可读可写 | 最大长度128 |  |  |  |  |  |
| ProtocolType | string | 协议类型，http,https | 是 | 是 | 否 | 可读可写 | http,https |  |  |  |  |  |
| RegisterInterval | integer | 注册间隔 | 是 | 是 | 否 | 可读可写 |  |  |  |  |  |  |
| KeepAliveInterval | integer | 保活间隔 | 是 | 是 | 否 | 可读可写 |  |  |  |  |  |  ||
