##### 响应

**xml**

```xml
<?xml version="1.0" encoding="UTF-8"?>
<P6SGA1400ConnectStatus Version="1.0">

    <LastReqTimestamp><!-- ro,req,string, max length 32 --></LastReqTimestamp>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| ConnectionStatus | integer | 连通状态；0:未知,1:成功, 2:失败,  默认值0 该参数由设备赋值，对客户端来说是只读参数 | 是 | 是 | 否 | 只读 | 0:未知,1:成功, 2:失败,  默认值0 |  |  |  |  |  |
| LastReqTimestamp | string | 上次请求时间戳，最大长度64，格式：YYYY-MM_DD hh:mm:ss | 是 | 是 | 否 | 只读 | 最大长度64 |  |  |  |  |  | |
