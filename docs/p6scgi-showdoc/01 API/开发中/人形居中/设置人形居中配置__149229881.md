# 设置人形居中配置
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<PersonCenterCfg>
    <Enable><!—-rw,req,xs:boolean,”true,false”--></Enable> <!-- 是否启用人形居中；true启用，false不启用  -->
</PersonCenterCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Enable | boolean | 是否启用人形居中；true启用，false不启用 | 是 | 是 | 否 | 可读可写 | true，false |  | APP暂不支持,由APP规划的版本支持和发布 | 配置-系统设置-人形居中-启用人形居中 | 根据以下能力，进行显示<SmartDetect><ObjectCentering><Support><!--xs:boolean--></Support></ObjectCentering></SmartDetect> |无  ||

##### 响应
**xml**
无
**字段说明**
无
