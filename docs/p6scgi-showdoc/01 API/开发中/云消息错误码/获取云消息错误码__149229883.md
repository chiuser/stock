# 获取云消息错误码
##### 简要描述
设计文档：http://192.168.250.99:8090/pages/viewpage.action?pageId=149463419

- ##### 请求

**请求示例**

```
<?xml version="1.0" encoding="utf-8"?>
<CloudMessageErrorCodeList>
    <Count><!-- ro,req,xs:interger --></Count>       <!-- 错误码列表个数，最大256 -->
    <CloudMessageErrorCodeInfo>                      <!-- 错误码信息 -->
        <ID><!-- ro,req,xs:interger --></ID>                                 <!-- 错误码ID,从1开始递增 -->
        <ThreadID><!-- ro,req,xs:interger --></ThreadID>                     <!-- 线程ID -->
        <ThreadName><!-- ro,req,xs:string，max length 16 --></ThreadName>    <!-- 线程名 -->
        <ErrorCode><!-- ro,req,xs:interger --></ErrorCode>                   <!-- 云消息错误码 -->
    </CloudMessageErrorCodeInfo>
    <!-- 可多个 CloudMessageErrorCodeInfo-->
</CloudMessageErrorCodeList>
```


**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| Count | interger | 错误码列表个数，最大256 | 是 | 是 | 否 | 只读 |  |  |  |  |  |  |
| CloudMessageErrorCodeInfo |  | 错误码信息 |  |  |  |  |  |  |  |  |  |  |
| ID | interger | 错误码ID,从1开始递增 | 是 | 是 | 否 | 只读 | 最大256 |  |  |  |  |  |
| ThreadID | interger | 线程ID | 是 | 是 | 否 | 只读 |  |  |  |  |  |  |
| ThreadName | string | 线程名 | 是 | 是 | 否 | 只读 | 最大长度16 |  |  |  |  |  |
| ErrorCode | interger | 云消息错误码 | 是 | 是 | 否 | 只读 |  |  |  |  |  |  |
| Time | interger | 时间戳(秒) | 是 | 是 | 否 | 只读 |  |  |  |  |  |  |
| Line | interger | 错误对应行号 | 是 | 是 | 否 | 只读 |  |  |  |  |  |  |
| FileName | string | 错误对应源文件名,最大长度128 | 是 | 是 | 否 | 只读 |  |  |  |  |  |  ||
