# 设置RTMP流配置信息
##### 简要描述

##### 说明

URI中的<ChannelID>显示通道编号，<ChannelID>从1开始。
<StreamID>表示流类型，通常“1”表示主流，“2”表示“第一子流”，“3”表示“第二子流”，依此类推。
当BasicConfig的<Mode>等于“manual”时，<Enable>字段和<PushURL>有效。 “true”使设备将流推送到RTMP服务器，“false”禁用RTMP服务。
<PushURL>字段是用于按RTMP协议推送流的RTMP URL。 当设备在手动模式下工作时，该字段必须由用户填写。
当设备在动态模式下工作时，<PlayURL>字段有效。 用户云通过Web浏览器打开此URL以观看流（ChannelID / StreamID）。

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Config>
    <Enable><!--rw,req,xs:boolean;"false","true"--></Enable>
    <PushURL><!--rw,req,xs:string, the max length : 512--></PushURL>
    <PushURL_Base64><!--rw,req,xs:string, the max length : 512--></PushURL_Base64>
    <Status><!--ro,req,xs:string, the max length : 32--></Status>
    <PlayURL><!--ro,req,xs:string, the max length : 256--></PlayURL>
    <PlayURL_Base64><!--ro,req,xs:string, the max length : 256--></PlayURL_Base64>
    <AudioEnable><!--rw,req,xs:boolean;"false","true"--></AudioEnable>
	<AudioFormat><!--rw,opt,xs:string, the max length : 32--></AudioFormat>
	<SampleRate><!--rw,opt,xs:integer--></SampleRate>
</Config>
```
