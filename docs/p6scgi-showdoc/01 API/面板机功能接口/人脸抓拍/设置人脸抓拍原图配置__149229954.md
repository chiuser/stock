# 设置人脸抓拍原图配置
##### 简要描述

- ##### 请求

**xml**

```
<OriginImageConfig>
    <OriginImageEnable><!--rw,opt,xs:boolean”true”,”false”--></OriginImageEnable>
</OriginImageConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| OriginImageEnable | boolean | 是否使能人脸抓拍原图配置；false-否，true-是 | 否 | 是 | 否 | 可读可写 | false/true |  ||

##### 响应

**xml**
无
**字段说明**
无
