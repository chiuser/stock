# 设置固定识别区域的配置
##### 简要描述

- ##### 说明

RegionModeEnable：是否启用区域探测模式
RegionMode：区域探测模式
global：全区域
local：部分区域
Region：当RegionMode为“local“的时候，以下值决定区域范围
TopLeftX：区域左上角X坐标
TopLeftY：区域左上角Y坐标
BottomRightX：区域右下角X坐标
BottomRightY：区域右下角Y坐标

##### 请求

**xml**

```
<FixedRegionDetectConfig>
    <RegionModeEnable><!--rw,req,xs:boolean”true”,”false”--></RegionModeEnable>
    <RegionMode><!--rw,req,xs:string”global”,”local”--></RegionMode>
    <Region>
        <TopLeftX><!--rw,req,xs:Interger, 0-703--></TopLeftX>
        <TopLeftY><!--rw,req,xs:Interger, 0-575--></TopLeftY>
        <BottomRightX><!--rw,req,xs:Interger, 0-703--></BottomRightX>
        <BottomRightY><!--rw,req,xs:Interger, 0-575--></BottomRightY>
    </Region>
</FixedRegionDetectConfig>
```
