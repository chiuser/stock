# 设置设备人脸抓拍模式
##### 简要描述

- ##### 说明

设置当前设备的人脸抓拍模式，当设置为RecoMode的时候，设备处于人脸识别模式（并非所有设备都支持），当设置为抓拍模式的时候，设备不进行人脸识别，用户通过9.20.10 /Face/ChannelID/FaceSnapshotImage轮询获取抓拍到的人脸图片，获取到后，可以使用该图片进行人脸入库。

##### 请求

**xml**

```
<FaceSnapshotMode>
    <Mode><!--rw,opt,xs:string”RecoMode”,”SnapshotMode”--></Mode>
</FaceSnapshotMode>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Mode | string | 人脸识别模组工作模式；RecoMode:人脸识别模式, SnapshotMode:人脸抓拍模式 | 否 | 是 | 否 | 可读可写 | 动态数组 |  ||

##### 响应

**xml**
无
**字段说明**
无
