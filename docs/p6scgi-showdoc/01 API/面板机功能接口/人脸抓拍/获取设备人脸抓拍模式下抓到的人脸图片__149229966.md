# 获取设备人脸抓拍模式下抓到的人脸图片
##### 简要描述

- /Face/ChannelID/FaceSnapshotMode设置为SnapshotMode的时候轮询调用此接口，当Content-Length不为0的时候，响应体为图片的二进制数据
GET HTTP请求示例

|  |
| --- |
| <span class="colour" style="color: red;">GET /Face/1/FaceSnapshotImage HTTP/1\.1\r\n Authorization: Basic YWRtaW46\r\n User\-Agent: PostmanRuntime/7\.26\.10\r\n Accept: \_\_/\_\_Cache\-Control: no\-cache Postman\-Token: c8b820b7\-3031\-4c05\-8bab\-109e265992e5 Host: 192\.168\.1\.100 Accept\-Encoding: gzip\, deflate\, br Connection: keep\-alive</span> |

GET HTTP回应示例一，设备抓拍到人脸图片，大小为Content-Length表示的32768字节

|  |
| --- |
| <span class="colour" style="color: blue;">HTTP/1.0 200 OK Server: CGI/1.9.3 Content-Length: 32768 Content-Type: application/xml Connection: close  …………(人脸图片的二进制数据) </span> |

GET HTTP回应示例二，设备未抓拍到人脸图片， Content-Length的值为0

|  |
| --- |
| <span class="colour" style="color: blue;">HTTP/1.0 200 OK Server: CGI/1.9.3 Content-Length: 0 Content-Type: application/xml Connection: close </span> |
