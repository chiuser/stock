# 设置事件记录上传定制内容
##### 简要描述

- ##### **请求**

**xml**

```
<EventRecordUploadCustomCfg>
    <StrangerUpload><!--rw,opt,xs:boolean,"true,false"--></StrangerUpload>
    <IdentifyRecordPicture><!--rw,opt,xs:boolean,"true,false"--></IdentifyRecordPicture>
    <IDCardUpload><!--rw,opt,xs:boolean,"true,false"--></IDCardUpload>
    <CardNumberUpload><!--rw,opt,xs:boolean,"true,false"--></CardNumberUpload>
</EventRecordUploadCustomCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| StrangerUpload | boolean | 是否陌生人上传,true-是,false-否 | 否 | 是 | 否 | 可读可写 | false/true |  |
| IdentifyRecordPicture | boolean | 是否识别记录带图片,true-是,false-否 | 否 | 是 | 否 | 可读可写 | false/true |  |
| IDCardUpload | boolean | 是否身份证上传,true-是,false-否 | 否 | 是 | 否 | 可读可写 | false/true |  |
| CardNumberUpload | boolean | 是否卡号上传,true-是,false-否 | 否 | 是 | 否 | 可读可写 | false/true |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/EventRecordUploadCustomCfg` 

##### 请求方式

- put
