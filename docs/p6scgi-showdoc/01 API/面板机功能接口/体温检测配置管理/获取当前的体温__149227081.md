# 获取当前的体温
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<FaceTemperatureStatus>
    <ChannelID><!--ro,req,xs:integer--></ChannelID>
    <Temperature><!--ro,req,xs:float--></Temperature>
</FaceTemperatureStatus>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ChannelID | integer | <span class="colour" style="color:rgb(106, 153, 85)">通道ID，对IPC来说是1</span> | 是 | 是 | 否 | 只读 | [1-32] |  |
| Temperature | float | 体温 | 是 | 是 | 否 | 只读 | 取值范围需与设备确认 |  | |

##### 请求URL

 - `/FaceTemperatureDetect/ChannelID/FaceTemperatureStatus` 

##### 请求方式

- get
