# 设置体温探测修正的状态
##### 简要描述

- ##### 请求

**xml**

```
<FaceTemperatureDetectRevise>
    <ReviseResult><!--wo,opt,xs:string”success”,”failed”,”revising”--></ResultResult>
</FaceTemperatureDetectRevise>
```

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |

| ReviseResult | string | 体温探测修正的状态；<span class="colour" style="color:rgb(206, 145, 120)">success</span><span class="colour" style="color:rgb(106, 153, 85)">:成功</span><span class="colour" style="color:rgb(206, 145, 120)">failed</span><span class="colour" style="color:rgb(106, 153, 85)">:失败  </span><span class="colour" style="color:rgb(206, 145, 120)">revising</span><span class="colour" style="color:rgb(106, 153, 85)">:校正中</span> | 否 | 是 | 否 | 只写 | 动态数组 |  | |
