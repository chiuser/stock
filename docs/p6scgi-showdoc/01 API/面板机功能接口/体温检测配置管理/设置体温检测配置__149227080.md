# 设置体温检测配置
##### 简要描述

- ##### 请求

**xml**

```
<FaceTemperatureDetectConfig>
    <Enable><!--rw,opt,xs:boolean”true”,”false”--></Enable>
    <TemperatureType><!--rw,opt,xs:string”Fahrenheit”,”Centigrade”--></Temperature>
    <NormalTemperatureDownLimit><!--rw,opt,xs:float--></NormalTemperatureDownLimit>
    <NormalTemperatureUpLimit><!--rw,opt,xs:float--></NormalTemperatureUpLimit>
    <TemperatureReviseEnable><!--rw,opt,xs:string,”disable”,”Manualcompen”,”OutdoorAuto”--></TemperatureReviseEnable>
    <TemperatureReviseValue><!--rw,opt,xs:float--></TemperatureReviseValue>
    <HighTemperatureNoPassEnable><!--rw,opt,xs:boolean”true”,”false”--></HighTemperatureNoPassEnable>
    <WorkMode><!--rw,opt,xs:string”InDoor”,”OutDoor”--></WorkMode>
<FaceTemperatureDetectConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否开启体温检测；false 否，true 是</span> | 否 | 是 | 否 | 可读可写 | false/true |  |
| TemperatureType | string | <span class="colour" style="color:rgb(106, 153, 85)">体温类型；</span><span class="colour" style="color:rgb(206, 145, 120)">Fahrenheit </span><span class="colour" style="color:rgb(106, 153, 85)">华氏度，</span><span class="colour" style="color:rgb(206, 145, 120)">Centigrade </span><span class="colour" style="color:rgb(106, 153, 85)">摄氏度，</span><span class="colour" style="color:rgb(206, 145, 120)">Unknown </span><span class="colour" style="color:rgb(106, 153, 85)">未知</span> | 否 | 是 | 否 | 可读可写 | 动态数组 |  |
| NormalTemperatureDownLimit | float | <span class="colour" style="color:rgb(106, 153, 85)">正常体温下限</span>(eg:37.2) | 否 | 是 | 否 | 可读可写 | 取值范围需与设备确认 |  |
| NormalTemperatureUpLimit | float | <span class="colour" style="color:rgb(106, 153, 85)">正常体温上限</span>(eg:37.6) | 否 | 是 | 否 | 可读可写 | 取值范围需与设备确认 |  |
| TemperatureReviseEnable | string | <span class="colour" style="color:rgb(106, 153, 85)">温度修正开启关闭；</span><span class="colour" style="color:rgb(206, 145, 120)">disable</span><span class="colour" style="color:rgb(106, 153, 85)">：关闭  </span><span class="colour" style="color:rgb(206, 145, 120)">Manualcompen</span><span class="colour" style="color:rgb(106, 153, 85)">：启用手动补偿,</span><span class="colour" style="color:rgb(206, 145, 120)">OutdoorAuto</span><span class="colour" style="color:rgb(106, 153, 85)">:启用户外自动补偿</span> | 否 | 是 | 否 | 可读可写 | 动态数组 |  |
| TemperatureReviseValue | float | <span class="colour" style="color:rgb(106, 153, 85)">温度值修正（-2.0-2.0）</span> | 否 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(106, 153, 85)">-2.0-2.0</span> |  |
| HighTemperatureNoPassEnable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否使能高体温禁止通行；false 否，true 是</span> | 否 | 是 | 否 | 可读可写 | false/true |  |
| WorkMode | string | <span class="colour" style="color:rgb(106, 153, 85)">工作模式；</span><span class="colour" style="color:rgb(206, 145, 120)">InDoor</span><span class="colour" style="color:rgb(106, 153, 85)">：室内</span><span class="colour" style="color:rgb(206, 145, 120)">OutDoor</span><span class="colour" style="color:rgb(106, 153, 85)">：室外</span> | 否 | 是 | 否 | 可读可写 | 动态数组 |  | |
