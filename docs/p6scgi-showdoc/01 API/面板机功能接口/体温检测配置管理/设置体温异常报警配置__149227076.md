# 设置体温异常报警配置
##### 简要描述

- ##### 请求

**xml**

```
<FaceTemperatureAbnormalAlarmConfig>
    <VoiceAlert><!--rw,opt,xs:string”Enable”,”Disable”--></VoiceAlert>
    <DisableWhiteListLinkage><!--rw,opt,xs:string”Enable”,”Disable”--></DisableWhiteListLinkage>
    <PushToPhone><!--rw,opt,xs:string”Enable”,”Disable”--></PushToPhone>
    <AlarmOut1><!--rw,opt,xs:string”Enable”,”Disable”--></AlarmOut1>
    <AlarmOut2><!--rw,opt,xs:string”Enable”,”Disable”--></AlarmOut2>
    <Email><!--rw,opt,xs:string”Enable”,”Disable”--></Email>
</FaceTemperatureAbnormalAlarmConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| VoiceAlert | string | 是否使能语音报警；Disable 去使能，Enable 使能 | 否 | 是 | 否 | 可读可写 | 动态数组 |  |
| DisableWhiteListLinkage | string | 是否使能禁止白名单联动项；Disable 去使能，Enable 使能 | 否 | 是 | 否 | 可读可写 | 动态数组 |  |
| PushToPhone | string | 是否使能手机推送；Disable 去使能，Enable 使能 | 否 | 是 | 否 | 可读可写 | 动态数组 |  |
| AlarmOut1 | string | 是否使能报警输出1；Disable 去使能，Enable 使能 | 否 | 是 | 否 | 可读可写 | 动态数组 |  |
| AlarmOut2 | string | 是否使能报警输出2；Disable 去使能，Enable 使能 | 否 | 是 | 否 | 可读可写 | 动态数组 |  |
| Email | string | 是否使能邮件推送；Disable 去使能，Enable 使能 | 否 | 是 | 否 | 可读可写 | 动态数组 |  | |

##### 响应

**xml**
无

无
