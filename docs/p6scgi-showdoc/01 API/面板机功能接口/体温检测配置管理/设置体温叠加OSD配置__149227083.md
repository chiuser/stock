# 设置体温叠加OSD配置
##### 简要描述

- ##### 请求

**xml**

```
<OverlayTemperatureOnOSDConfig>
    <Enable><!--rw,req,xs:boolean”true”,”false”--></Enable>
</OverlayTemperatureOnOSDConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否叠加温度信息在OSD上；false 否，true 是</span> | <span class="colour" style="color:rgb(106, 153, 85)">是</span> | 是 | 否 | 可读可写 | false/true |  | |

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/FaceTemperatureDetect/ChannelID/OverlayFaceTemperatureOnOSD` 

##### 请求方式
