# 远程开门
##### 简要描述

- ##### 说明

本接口用于远程开门，开门成功后，会通过HTTP事件发送开门事件，ControlID的值会包含在事件的controlId字段中，以与本次开门对应

##### 请求

**xml**

```
<OpenDoorInfo>
    <ControlID><!--wo,req,xs:string; the max length 32--></ControlID>
</OpenDoorInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ControlID | string | 开门成功后，会通过HTTP消息推送开门事件（假设已经在设备上配置HTTP服务器），ControlID的值会包含在事件的controlId字段中，以与本次开门对应，当ControlID为空时，HTTP消息中controlId字段值也为空<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 只写 | 最大长度32 |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/AccessGate/ChannelID/RemoteOpenDoor` 

##### 请求方式

- put
 
##### 成功返回示例  
```
{}

```
