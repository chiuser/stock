# 根据ID查询密码
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<AccessPasswordInfo>
    <ID><!--ro,req,xs:string; the max length 32--></ID>
    <Password><!--ro,req,xs:string; the max length 32--></Password>
</AccessPasswordInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ID | string | 索引ID | 是 | 是 | 否 | 只读 | 最大长度32 |  |
| Password | string | 密码 | 是 | 是 | 否 | 只读 | 最大长度32 |  ||

##### 请求URL

 - `/AccessGate/QueryPasswordByID?ID=xxx` 

##### 请求方式

- get
