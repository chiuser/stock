# 更改门禁卡
##### 简要描述

- ##### **请求**

**xml**

```
<AccessCardInfoList>
    <AccessCardInfo>
        <ID><!--rw,req,xs:string, the max length 32--></ID>
        <CardNumber><!--rw,req,xs:string, the max length 32--></CardNumber>
    </AccessCardInfo>
    …
</AccessCardInfoList>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| AccessCardInfo |  |  |  |  |  |  |  |  |
| ID | string | 门禁卡ID | 是 | 是 | 否 | 可读可写 | 最大长度32 |  |
| CardNumber | string | 门禁卡卡号 | 是 | 是 | 否 | 可读可写 | 最大长度32 |  ||

##### 响应

**xml**
无
**字段说明**
无
