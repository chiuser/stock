# 获取读卡模式
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<CardReadMode>
    <Mode><!--rw,opt,xs:string,”Auto”,”Manual”--></Mode>
</CardReadMode>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Mode | string | 读卡模式；<span class="colour" style="color:rgb(206, 145, 120)">Auto</span>自动，<span class="colour" style="color:rgb(206, 145, 120)">Manual</span>手动，<span class="colour" style="color:rgb(206, 145, 120)">Unknown</span>未知 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  ||

##### 请求URL

 - `/AccessGate/CardReadMode` 

##### 请求方式

- get

[]
