# 获取息屏时间
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<ScreenCloseTimeConfig>
    <Enable><!--rw,req,xs:boolean--></Enable>
    <ChannelID><!--wo,req,xs:interger--></ChannelID>		//此字段PUT不用传
    <ScreenCloseTime><!--rw,req,xs:interger,unit:second--></ScreenCloseTime>
    <ImageSwitchTime><!--rw,req,xs:interger,unit:second(3-30)--></ImageSwitchTime>
    <R><!--rw,req,xs:interger--></R>
    <G><!--rw,req,xs:interger--></G>
    <B><!--rw,req,xs:interger--></B>
    <SNorMACEnable><!--rw,req,xs:string,"Invalid,SN,MAC"--></SNorMACEnable>
    <TrafficPageStayTime><!--rw,req,xs:interger,"2,5,10,15,20,25,30,0"--></TrafficPageStayTime>
    <TrafficCustomStayTime><!--rw,req,xs:interger,"5-300"--></TrafficPageStayTime>
</ScreenCloseTimeConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | 息屏是否启用<span class="colour" style="color:rgb(106, 153, 85)">，false-否，true-是</span><span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 可读可写 | false/true |  |
| ChannelID | integer | 通道，由1递增<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 只读 | [1-32] |  |
| ScreenCloseTime | integer | 息屏时间：秒<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| ImageSwitchTime | integer | 屏保图片切换时间(3-30s) | 是<span lang="EN-US"></span> | 是 | 否 | 可读可写 | [3-30] |  |
| R | integer | 息屏R值<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| G | integer | 息屏G值<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| B | integer | 息屏B值<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| SNorMACEnable | string | 显示序列号或MAC地址.<span class="colour" style="color:rgb(206, 145, 120)">Invalid</span>-无效,<span class="colour" style="color:rgb(206, 145, 120)">SN</span>-SN，<span class="colour" style="color:rgb(206, 145, 120)">MAC</span>-MAC | 是<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 动态数组 |  |
| TrafficPageStayTime | integer | 通行结果页面停留时间.2秒/5秒/10秒/15秒/20秒/25秒/30秒/0-自定义,注:此设置会引起屏保功能失效<span lang="EN-US"></span> | 是<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 0/2/5/10/15/20/25/30 |  |
