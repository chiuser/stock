# 设置低温拟合配置信息
##### 简要描述

- ##### 请求

**xml**

```
<LowTemFitSwitch>
    <Enable><!--rw,opt,xs:boolean,”true”,”false”--></Enable>
</LowTemFitSwitch>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | 是否使能低温拟合配置<span class="colour" style="color:rgb(106, 153, 85)">，false-否，true-是</span> | 否 | 是 | 否 | 可读可写 | false/true |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/ChannelID/LowTemFitSwitch` 

##### 请求方式

- put
