# 获取梯控基本配置
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<ElevatorConfig>
    <ChannelID><!--ro,opt,xs:integer--></ChannelID>
    <Enable><!--rw,opt,xs:boolean--></Enable>
    <Mode><!--rw,opt,xs:string, "elevator, firefighting, unknown"--></Mode>
    <FloorDownLimit><!--rw,opt,xs:integer--></FloorDownLimit>
    <FloorUpLimit><!--rw,opt,xs:integer--></FloorUpLimit>
</ElevatorConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ChannelID | integer | IPC通道，从1递增<span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 只读 | [1-32] |  |
| Enable | boolean | 禁用/启用梯控基本配置;false-禁用，true-启用<span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | false/true |  |
| Mode | string | 梯控模式<span lang="EN-US"></span>火警模式；<span class="colour" style="color:rgb(206, 145, 120)">elevator</span><span class="colour" style="color:rgb(106, 153, 85)">：梯控模式    </span><span class="colour" style="color:rgb(206, 145, 120)">firefighting</span><span class="colour" style="color:rgb(106, 153, 85)">：消防模式</span><span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 动态数组 |  |
| FloorDownLimit | integer | 当前设备所在建筑的最低楼层；<span lang="EN-US"></span>示例值-3，代表当前设备所在建筑的最低楼层是地下3层<span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| FloorUpLimit | integer | 当前设备所在建筑的最高楼层；示例值40，代表当前设备所在建筑的最低楼层是40层<span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 取值需与设备确认 |  ||

##### 请求URL

 - `/System/ChannelID/ElevatorBasicConfig` 

##### 请求方式

- get
