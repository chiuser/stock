# 设置第三方平台连接状态信息
##### 简要描述

- ##### **请求**

**xml**

```
<LLPlatConnectStateInfo>
    <Enable><!--rw,opt,xs:boolean,"true","false"--></Enable>
    <Status><!--rw,opt,xs:string,"online","offline"--></Status>
</LLPlatConnectStateInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | 是否使能第三方平台连接状态功能<span class="colour" style="color:rgb(106, 153, 85)">；false-否，true-是</span> | 否 | 是 | 否 | 可读可写 | false/true |  |
| Status | string | 第三方平台连接状态；<span class="colour" style="color:rgb(206, 145, 120)">offline </span><span class="colour" style="color:rgb(106, 153, 85)">不在线，</span><span class="colour" style="color:rgb(206, 145, 120)">online </span><span class="colour" style="color:rgb(106, 153, 85)">在线</span> | 否 | 是 | 否 | 可读可写 | 动态数组 |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/LLPlatConnectStateInfo` 

##### 请求方式

- put

{}
