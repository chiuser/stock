# 查询人脸识别记录条数
##### 简要描述

- ##### 说明

时间格式要求：yyyyMMddThhmmss

##### 请求

**xml**

```
<FaceRecognitionFilter>
    <GroupID><!--wo,req,xs:integer--></GroupID>  //该参数为-1表示，对所有的人脸库进行查询
    <StartTime><!-- wo,req,xs:datetime,”20040503T173008" --></StartTime>
    <StopTime><!-- wo,req,xs:datetime,”20040503T173008" --></StopTime>
    <RecognitionResultType><!--wo,req,xs:string,"all,Comparison pass,Comparison fail,Failure of biopsy"--></RecognitionResultType>
    <RuleID><!--wo,req,xs:integer --></RuleID>
    <PeopleName><!-- wo,req,xs:string, the max length 32 --></PeopleName>
</FaceRecognitionFilter>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 | 在APP的哪一个页面的哪一个字段 | 在web的哪一个页面的哪一个字段 | 字段受哪一个能力限制 | 字段受哪个字段限制 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| FaceRecognitionFilter |  |  |  |  |  |  |  |  |  | web没有调用该接口 |  |  |
| GroupID | integer | <span class="colour" style="color:rgb(106, 153, 85)">脸库ID，从0开始自增</span> | 是 | 是 | 否 | 只写 | <span class="colour" style="color:rgb(106, 153, 85)">从0开始自增</span> |  |  |  |  |  |
| StartTime | string | <span class="colour" style="color:rgb(106, 153, 85)">查询的开始时间，最大长度32，格式“YYYYMMDDThhmmss”，不可为空</span> | 是 | 是 | 否 | 只写 | <span class="colour" style="color:rgb(106, 153, 85)">最大长度32</span> |  |  |  |  |  |
| StopTime | string | <span class="colour" style="color:rgb(106, 153, 85)">查询的结束时间，最大长度32，格式“YYYYMMDDThhmmss”，不可为空</span> | 是 | 是 | 否 | 只写 | <span class="colour" style="color:rgb(106, 153, 85)">最大长度32</span> |  |  |  |  |  |

##### 响应

**xml**

```
<FaceRecognition>
    <RecognitionRecordCount><!--ro,xs:integer--></RecognitionRecordCount>
</FaceRecognition>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| RecognitionRecordCount | integer | <span class="colour" style="color:rgb(106, 153, 85)">人脸识别记录个数</span> | 是 | 是 | 否 | 只读 | 取值需要设备确认 | 设备实际人脸识别记录个数 |

 - `/FaceRecognition/QueryRecordCount`
