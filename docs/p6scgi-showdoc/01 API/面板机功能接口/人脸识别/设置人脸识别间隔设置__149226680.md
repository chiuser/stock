# 设置人脸识别间隔设置
##### 简要描述

- ##### 请求

**xml**

```
<FaceRecognitionIntervalCfg>
    <FaceRecognitionInterval><!--rw,opt,xs:integer,"2-15"--></FaceRecognitionInterval>
</FaceRecognitionIntervalCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| FaceRecognitionInterval | integer | 人脸识别间隔，2s-15s | 否 | 是 | 否 | 可读可写 | [2,15] |  ||

##### 响应

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/FaceRecognitionIntervalCfg` 

##### 请求方式

- put

```
{}
```
