# 查询人脸识别记录
##### 简要描述

- ##### 请求

**xml**

```
<FaceRecognitionFilter>
    <GroupID><!--rw,req,xs:integer--></GroupID>  //该参数为-1表示，对所有的人脸库进行查询
    <StartTime><!-- wo,req,xs:datetime,20040503T173008+08 --></StartTime>
    <StopTime><!-- wo,req,xs:datetime,20040503T173008+08--></StopTime>
    <Pagesize><!--wo,req,xs:integer, 表示每一页的最大记录数 --><Pagesize>
    <Pagenum><!--wo,req,xs:integer, 表示第几页, 从1开始 --><Pagenum>
    <IsHasPath><!--wo,req,xs:integer, 0表示没有路径, 1表示有路径 --></IsHasPath>
    <RecognitionResultType><!--wo,req,xs:string,"all,Comparison pass,Comparison fail,Failure of biopsy"--></RecognitionResultType>
    <PeopleName><!--rw,req,xs:string(max size:32) --></PeopleName>
    <RuleID><!--rw,req,xs:integer --></RuleID>//该参数为-1表示，对所有的规则进行查询
</FaceRecognitionFilter>
```

| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| FaceRecognitionFilter |  |  |  |  |  |  |  |  |  | web没有调用接口 |  |  |
| GroupID | integer | <span class="colour" style="color:rgb(106, 153, 85)">脸库ID，从0开始自增</span> | 是 | 是 | 否 | 可读可写 | <span class="colour" style="color:rgb(106, 153, 85)">从0开始自增</span> |  |  |  |  |  |
| StartTime | string | <span class="colour" style="color:rgb(106, 153, 85)">查询的开始时间，最大长度32，格式“YYYYMMDDThhmmss”，不可为空</span> | 是 | 是 | 否 | 只写 | <span class="colour" style="color:rgb(106, 153, 85)">最大长度32</span> |  |  |  |  |  |
| StopTime | string | <span class="colour" style="color:rgb(106, 153, 85)">查询的结束时间，最大长度32，格式“YYYYMMDDThhmmss”，不可为空</span> | 是 | 是 | 否 | 只写 | <span class="colour" style="color:rgb(106, 153, 85)">最大长度32</span> |  |  |  |  |  |
| Pagesize | integer | <span class="colour" style="color:rgb(106, 153, 85)">每一页的最大记录数，作为输出，表示每一页实际记录数</span> | 是 | 是 | 否 | 只写 | <span class="colour" style="color:rgb(106, 153, 85)">每一页实际记录数</span> |  |  |  |  |  |
| Pagenum | integer | <span class="colour" style="color:rgb(106, 153, 85)">第几页，从1开始</span> | 是 | 是 | 否 | 只写 | <span class="colour" style="color:rgb(106, 153, 85)">从1开始</span> |  |  |  |  |  |
| IsHasPath | integer | <span class="colour" style="color:rgb(106, 153, 85)">0，表示没有路径，1，表示有路径</span> | 是 | 是 | 否 | 只写 | 0/1 |  |  |  |  |  |
| RecognitionResultType | string | <span class="colour" style="color:rgb(106, 153, 85)">人脸识别结果类型；Comparison pass表示对比通过，Comparison fail表示对比失败，Failure of biopsy表示活体检测失败，all全部</span> | 是 | 是 | 否 | 只写 | 动态数组 |  |  |  |  |  |
| RuleID | integer | <span class="colour" style="color:rgb(106, 153, 85)">识别规则ID,1-白名单，2-黑名单，3-未注册，100-刷卡有效，101-刷卡无效，102-密码，为-1表示对所有的规则进行查询</span> | 是 | 是 | 否 | 可读可写 | -1/1/2/3/100/101/102 |  |  |  |  |  |

##### 响应

**xml**

```
<RecognitionRecordList>
    <RecognitionRecord>
        <LogID><!--ro,req,xs:integer --></LogID>
        <GroupID><!-- rw,req,xs:interger --></GroupID>
        <PersonID><!-- ro,opt,xs:interger --></PersonID>
        <GroupName><!--ro,req,xs:string(max size:32)--></GroupName>
        <Time><!-- ro,req,xs:datetime,”20040503T173008+08" --></Time>
        <Pass><!--ro,req,xs:interger, 0 pass, 1 no pass--><Pass>
        <SnapshotPath><!-- ro,req,xs:string, the max length 80 --></SnapshotPath>
        <Similar><!-- ro,req,xs:interger(0-100)--></Similar>
        <RuleID><!-- rw,req,xs:interger , 从1开始--></RuleID>
        <PeopleName><!-- rw,req,xs:string --></PeopleName>
        <FaceTemperature>//支持人脸温度检测则有此标签，否则无此标签 	
            <Temperature><!--ro,req,xs:float--></Temperature> 	
            <TemperatureUnit><!-- ro,req,xs:string,"celsius,fahrenheit"--></TemperatureUnit> 	
            <Fever><!-- ro,req,xs:string,"unknown,normal,fever"--><Fever>
        </FaceTemperature>
        <FaceMask><!-- ro,req,xs:string,"unknown,has,no"--><FaceMask>
        //人脸识别结果是否有效，根据不同规则，部分记录人脸识别结果无效
        <RecoValid><!--ro,req,xs:boolean--><RecoValid>
        <UniqueID><!--ro,opt,xs:string(max size:32) --></UniqueID>
        <HealthCode><!--ro,opt,xs:string”Green”,”Yellow”,”Red”--></HealthCode>
        <CardID_Desen><!-- ro,opt,xs:string, the max length 32 --></CardID_Desen>
        <Name_Desen><!-- ro,opt,xs:string, the max length 32  --></NameDesen>
        <TravelData><!-- ro,opt,xs:string, the max length 192  --></TravelData>
        <NucleicData><!-- ro,opt,xs:string, the max length 128 --></NucleicData>
        <TrafficResults><!-- ro,opt,xs:string,"Passed","NoPass",default "NoPass" --></TrafficResults>
    </RecognitionRecord>
</RecognitionRecordList>
```
