# 查询口罩探测通行模式
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<MaskPassConfig>
    <ChannelID><!--ro,opt,xs:integer--></ChannelID>
    <PassConfig><!--rw,opt,xs:string,”disable”,”wearmasknopass”,”nowearmasknopass”--></PassConfig>
</MaskPassConfig>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| ChannelID | integer | 通道ID，从1递增 | 否 | 是 | 否 | 只读 | [1-32] |  |
| PassConfig | string | 通行配置；<span class="colour" style="color:rgb(206, 145, 120)">disable</span>去使能，<span class="colour" style="color:rgb(206, 145, 120)">wearmasknopass</span>戴口罩不可通行，<span class="colour" style="color:rgb(206, 145, 120)">nowearmasknopass</span>未带口罩不可通行，<span class="colour" style="color:rgb(206, 145, 120)">unknown</span>未知 | 否 | 是 | 否 | 可读可写 | 动态数组 |  | |

##### 请求URL

 - `/FaceMaskDetect/ChannelID/PassConfig` 

##### 请求方式

- get
