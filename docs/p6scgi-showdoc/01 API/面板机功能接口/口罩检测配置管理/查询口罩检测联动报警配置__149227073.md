# 查询口罩检测联动报警配置
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<FaceMaskAlarmLinkage>
    <VoiceAlert><!--rw,opt,xs:boolean,”true”,”false”--></VoiceAlert>
    <AlarmOut1><!--rw,opt,xs:boolean,”true”,”false”--></AlarmOut1>
    <EmailAlert><!--rw,opt,xs:boolean,”true”,”false”--></EmailAlert>
</FaceMaskAlarmLinkage>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| VoiceAlert | boolean | 是否语音报警；false 否，true 是 | 否 | 是 | 否 | 可读可写 | false/true |  |
| AlarmOut1 | boolean | 是否联动报警1；false 否，true 是 | 否 | 是 | 否 | 可读可写 | false/true |  |
| EmailAlert | boolean | 是否Email联动报警；false 否，true 是 | 否 | 是 | 否 | 可读可写 | false/true |  ||

##### 请求URL

 - `/FaceMaskDetect/AlarmLinkage` 

##### 请求方式

- get
