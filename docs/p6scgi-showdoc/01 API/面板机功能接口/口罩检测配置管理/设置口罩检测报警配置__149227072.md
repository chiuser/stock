# 设置口罩检测报警配置
##### 简要描述

- ##### 请求

**xml**

```
<FaceDetectMaskAlarm>
    <AlarmConfig><!--rw,req,xs:string”NoAlarm”,”HasMaskAlarm”,”NoMaskAlarm”--></AlarmConfig>
</FaceDetectMaskAlarm>
```

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| AlarmConfig | string | <span class="colour" style="color:rgb(106, 153, 85)">报警配置；</span><span class="colour" style="color:rgb(206, 145, 120)">NoAlarm</span><span class="colour" style="color:rgb(106, 153, 85)">:不报警  </span><span class="colour" style="color:rgb(206, 145, 120)">HasMaskAlarm</span><span class="colour" style="color:rgb(106, 153, 85)">:有口罩报警  </span><span class="colour" style="color:rgb(206, 145, 120)">NoMaskAlarm</span><span class="colour" style="color:rgb(106, 153, 85)">:无口罩报警</span> | 是 | 是 | 否 | 可读可写 | 动态数组 |  ||
