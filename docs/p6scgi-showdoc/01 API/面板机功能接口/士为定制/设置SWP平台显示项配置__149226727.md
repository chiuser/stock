# 设置SWP平台显示项配置
##### 简要描述

- ##### **请求**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<SWPPlatformDisplayItemCfg>
    <SnapshotDynamicDisplay><!--rw,opt,xs:string,"no,snapshot,face" --></Company>
</SWPPlatformDisplayItemCfg>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| SnapshotDynamicDisplay | string | 抓拍内容动态显示设定项,<span class="colour" style="color:rgb(206, 145, 120)">snapshot</span>:显示抓拍图片,<span class="colour" style="color:rgb(206, 145, 120)">face</span>:显示脸库图片,<span class="colour" style="color:rgb(206, 145, 120)">no</span>:不显示任何内容 | 否 | 是 | 否 | 可读可写 | 动态数组 |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/SWPPlatformDisplayItemCfg` 

##### 请求方式

- put
 
##### 成功返回示例  
```
{}
```
