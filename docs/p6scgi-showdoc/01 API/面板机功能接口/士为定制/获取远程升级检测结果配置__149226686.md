# 获取远程升级检测结果配置
##### 简要描述
面板机士为定制接口

- ##### **请求**

**xml**
无
**字段说明**
无

##### **响应**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<RemoteUpdateResultInfo>
    <RemoteUpdateResult><!-- rw,opt,xs:string,"success","LatestVersion","InvalidPackage"--></RemoteUpdateResult>
</RemoteUpdateResultInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| RemoteUpdateResult | string | 远程升级检测结果,success <span class="colour" style="color:rgb(106, 153, 85)">成功</span>,LatestVersion <span class="colour" style="color:rgb(106, 153, 85)">当前已是最新版本</span>,InvalidPackage <span class="colour" style="color:rgb(106, 153, 85)">无可用升级包</span> | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 动态数组 |  ||

##### 请求URL

 - `/System/RemoteUpdateResultInfo` 

##### 请求方式
