# 设置SWP平台公司名和设备场所配置信息
##### 简要描述

- ##### **请求**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<SWPPlatformCompanyDeviceInfo>
    <Company><!--rw,opt,xs:string,max size 128 --></Company>
    <DeviceAddress><!--rw,opt,xs:string,max size 256 --></DeviceAddress>
</SWPPlatformCompanyDeviceInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Company | string | 公司名 | 否 | 是 | 否 | 可读可写 | 最大长度128 |  |
| DeviceAddress | string | 设备场所 | 否 | 是 | 否 | 可读可写 | 最大长度256 |  ||

##### **响应**

**xml**
无
**字段说明**
无

##### 请求URL

 - `/System/SWPPlatformCompanyDeviceInfo` 

##### 请求方式

- put

{}
