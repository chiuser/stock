# 获取移动激活信息
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<CMDOTAuthInfo>
    <AuthStatus><!--ro,opt,xs:Integer--></AuthStatus>
    <SerialNumber><!--rw,opt,xs:string, the max length : 32--></SerialNumber>
    <CMDotSn><!--rw,opt,xs:string, the max length : 17--><CMDotSn>
    <BindCode><!--rw,opt,xs:string, the max length : 9--></BindCode>
    <Password><!--rw,opt,xs:string, the max length : 9--></Password>
    <CMDotCMEI_IMEI><!--rw,opt,xs:string, the max length : 64--></CMDotCMEI_IMEI>
    <MAC><!--rw,opt,xs:string--></MAC>
</CMDOTAuthInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| AuthStatus | integer | <span class="colour" style="color:rgb(106, 153, 85)">授权状态；0 否，1 是</span> | 否 | 是 | 否 | 只读 | 0,1 |  |
| SerialNumber | string | <span class="colour" style="color:rgb(106, 153, 85)">序列号</span> | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| CMDotSn | string | <span class="colour" style="color:rgb(106, 153, 85)">移动设备序列号,16个字节,ex:7943690000000001</span> | 否 | 是 | 否 | 可读可写 | 最大长度17 |  |
| BindCode | string | <span class="colour" style="color:rgb(106, 153, 85)">平台接入码，保证唯一性,8字节 ex:1C94piOs</span> | 否 | 是 | 否 | 可读可写 | 最大长度9 |  |
| Password | string | <span class="colour" style="color:rgb(106, 153, 85)">密码,8字节 ex:1C94piOs</span> | 否 | 是 | 否 | 可读可写 | 最大长度9 |  |
| CMDotCMEI_IMEI | string | <span class="colour" style="color:rgb(106, 153, 85)">CMEI/IMEI,和IMEI2选一个填,参考规范文档;设备没有的话向移动申请； ex:111041730000001</span> | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| MAC | string | <span class="colour" style="color:rgb(106, 153, 85)">设备MAC地址</span> | 否 | 是 | 否 | 可读可写 | 最大长度32 |  ||
