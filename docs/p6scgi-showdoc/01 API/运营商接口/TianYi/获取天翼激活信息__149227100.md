**xml**

```
<TianYiAuthInfo>
    <AuthStatus><!--ro,opt,xs:boolean--></AuthStatus>
    <SerialNumber><!--rw,opt,xs:string, the max length : 32--></SerialNumber>
    <CTEI><!--rw,opt,xs:string, the max length : 16--></CTEI>
    <DeviceCode><!--rw,opt,xs:string, the max length : 16--></DeviceCode>
    <DevicePassword><!--rw,opt,xs:string, the max length : 16--></DevicePassword>
```
