# 设置联通激活信息
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<UnicomAuthInfo Version="1.0">
    <SerialNumber><!--rw,opt,xs:string, the max length : 32--></SerialNumber>
    <UnicomEI><!--rw,opt,xs:string, the max length : 16--></UnicomEI>
    <DeviceCode><!--rw,opt,xs:string, the max length : 16--></DeviceCode>
    <DevicePassword><!--rw,opt,xs:string, the max length : 16--></DevicePassword>
    <BindVerifyCode><!--rw,opt,xs:string, the max length : 16--></BindVerifyCode>
    <BindCode><!--rw,opt,xs:string, the max length : 64--></BindCode>
    <MAC><!--rw,opt,xs:string--></MAC>
</UnicomAuthInfo>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| SerialNumber | string | 序列号 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| UnicomEI | string | 15byte十进制数，前8byte是TUI码，不同型号产品不同（如天翼3MP室外枪机TUI为 18483912），后7位从0000001开始递增，每台设备唯一（示例：184839120000011） | 否 | 是 | 否 | 可读可写 | 最大长度16 |  |
| DeviceCode | string | 设备码 | 否 | 是 | 否 | 可读可写 | 最大长度16 |  |
| DevicePassword | string | 设备密码 | 否 | 是 | 否 | 可读可写 | 最大长度16 |  |
| BindVerifyCode | string | 绑定验证码 | 否 | 是 | 否 | 可读可写 | 最大长度16 |  |
| BindCode | string | 设备绑定标识二维码 | 否 | 是 | 否 | 可读可写 | 最大长度64 |  |
| MAC | string | Mac地址 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  ||

##### 响应

无

无
