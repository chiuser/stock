# 获取设备对讲模式
##### 简要描述

- ##### **请求**

**xml**
无
**字段说明**
无

##### **响应**

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<DeviceIntercomMode Version="1.0">
    <IntercomMode><!--rw,opt,xs:string,"FullDuplex,HalfDuplex"--></IntercomMode>
</DeviceIntercomMode>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| IntercomMode | string | 对讲模式;FullDuplex-全双工对讲,HalfDuplex-半双工对讲<span lang="EN-US"></span> | 否<span lang="EN-US"></span> | 是 | 否 | 可读可写 | 动态数组 |  ||

##### 请求URL

 - `/System/DeviceIntercomMode` 

##### 请求方式

- get
 
##### 成功返回示例  
```
[]

```
