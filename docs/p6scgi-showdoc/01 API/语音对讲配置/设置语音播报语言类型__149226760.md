# 设置语音播报语言类型
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="UTF-8" ?>
<VoiceBroadcastLanguage>
    <Language><!--rw,req,xs:string”Chinese,English,Korean,Japanese,Italian,Russian,Spanish,Portuguese,Persian,Arabic,Bulgarian,Chinese_Traditional,Custom,Croation,Czech,Danish,Dutch,German,Estonian,Finnish,French,Greek,Hebrew,Hungarian,Latvian,Lithuanian,Norwegian,Polish,Romanian,Slovak,Slovenian,Swedish,Thai,Turkish,Vietnamese,Indonesian,KoreanLanguage”--></Language>
</VoiceBroadcastLanguage>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Language | string | 语言类型；Chinese 简体中文，English 英语，Korean 韩国，Japanese 日语，Italian 意大利语，Russian 俄罗斯语，Spanish 西班牙语，Portuguese 葡萄牙语，Persian 波斯语， Arabic 阿拉伯文，Bulgarian 保加利亚语，Chinese_Traditional 繁体中文，Custom 定制语言，Croation 克罗地亚语，Czech 捷克语，Danish 丹麦语，Dutch 荷兰（德语），German 德语，Estonian 爱沙尼亚语，Finnish 芬兰语，French 法语，Greek 希腊语，Hebrew 希伯来语，Hungarian 匈牙利语，Latvian 拉脱维亚语，Lithuanian 立陶宛语，Norwegian 挪威语，Polish 波兰语，Romanian 罗马尼亚语，Slovak 斯洛伐克语，Slovenian 斯洛维尼亚语，Swedish 瑞典语，Thai 泰语，Turkish 土耳其语，Vietnamese 越南语，  Indonesian 印尼语，KoreanLanguage 朝鲜语 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  ||

##### 响应

**xml**
无
**字段说明**
无

 - `/System/VoiceBroadcastLanguage`
