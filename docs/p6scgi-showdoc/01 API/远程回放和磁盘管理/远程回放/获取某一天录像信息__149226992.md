# 获取某一天录像信息
##### 简要描述

- ##### 说明

<Channel>从0开始，如果值为0xff，则存在搜索所有通道。
<RecordType>无效，默认搜索所有记录信息。
比如：
[http://192.168.0.180/Playback/GetRecordInfoByDay?Year=2017&Month=2&Day=10&Channel=0&RecordType=0](http://192.168.0.180/Playback/GetRecordInfoByDay?Year=2017&Month=2&Day=10&Channel=0&RecordType=0)

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<RecordInfoByDay>
   <RecordInfoList>
      <RecordInfo>
          <Channel><!--ro,req,xs:interger--></Channel>
          <RecordType><!--ro,req,xs:string,”general,manual,alarm,ai,motion”--></RecordType>
          <RecordSubType><!--ro,req,xs:string, the max length 32 --></RecordSubType>
          <StartTime><!--ro,req,xs:datetime,” 20040503173008”--></StartTime>
          <EndTime><!--ro,req,xs:datetime,” 20040503173008”--></EndTime>
      </RecordInfo>
   </RecordInfoList>
</RecordInfoByDay>
```
