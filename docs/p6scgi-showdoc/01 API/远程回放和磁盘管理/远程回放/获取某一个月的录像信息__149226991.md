# 获取某一个月的录像信息
##### 简要描述

- ##### 说明

从左到右，如果<RecordInfo>的位为“0”，则没有记录，否则，表示有记录。
比如:
  [http://192.168.0.180/Playback/GetRecordInfoByMonth?Year=2017&Month=2](http://192.168.0.180/Playback/GetRecordInfoByMonth?Year=2017&Month=2)
参数Month的数值应该为2位补齐, 例如7月份应传Month=07

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<RecordInfoByMonth>
   <RecordInfo><!—ro,req,xs:string,”00000000000000001111111111111111”--></RecordInfo>
</RecordInfoByMonth>
```

| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- | ---------------- | ---------------- | ---------- | --------- |
| RecordInfoByMonth |  |  |  |  |  |  |  |  |  | <span class="colour" style="color: rgb(206, 145, 120);">回放-选择月份-查找</span> | <span class="colour" style="color: rgb(0, 0, 0);">设备能力专用URL：/System/DeviceCap；能力定义：Device-FunctionList-SD</span> |  |
| RecordInfo | string | 录像记录存在性；从左到右，如果\<RecordInfo>的位为“0”，则没有记录，否则，表示有记录。 | 是 | 是 | 否 | 只读 | 最大长度32 |  |  |  |  | 无 |
