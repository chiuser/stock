# 获取磁盘信息
##### 简要描述

- ##### 说明

<PictureCapacityPercent>和<RecordCapacityPercent>是实际存储大小，而不是百分比。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<DiskList>
   <Disk>
     <DiskID><!--rw,req,xs:integer,”0,1,2….”, max value 15--></DiskID>
     <DiskTypeName><!--rw,req,xs:string,max size 32--></DiskTypeName>
     <TotalCapacity><!--rw,req,xs:integer,the unit is MB--></TotalCapacity>
     <AvailableCapacity><!--rw,req,xs:integer,the unit is MB--></AvailableCapacity>
     <DiskStorageType><!--rw,req,xs:string,”sd,samba”--></DiskStorageType>
     <DiskStorageAttribute><!--rw,req,xs:string,”idle,writting,reading,diskexception,diskerror,readonly,readwrite,nodisk,exceptionneedformat,exceptionneedChangeDisk,formatfailedneedreboot” --></DiskStorageAttribute>
     <PictureCapacityPercent><!--rw,req,xs:integer--></PictureCapacityPercent>
     <RecordCapacityPercent><!--rw,req,xs:integer--></RecordCapacityPercent>
     <DiskFormatStatus><!--rw,req,xs:string,”unformatted,formatting,formatted,format failure,umount failure,device is busy”--></DiskFormatStatus>
   </Disk>
</DiskList>
```
