# 获取录像计划
##### 简要描述

- ##### 说明

URI中的<ChannelID>显示通道编号。 <ChannelID>从1开始。
    如果<AllDay>的值为true，则表示每天的所有时间对于运动有效，但<TimeBlockList>的值无效，如果为false，则<TimeBlockList>的值有效。
    一天分为48块，这意味着每半小时到一块时间，当一块时间的记录类型是定时记录时，则块设置为1，当块的记录类型为no时记录，然后将块设置为0，当块的记录类型为运动记录时，则将块设置为2，当块的记录类型为报警记录时，则将块设置为3。
例如：
如果一天中的所有时间都没有记录，
那么<TimeBlock_0>的值是
“000000000000000000000000000000000000000000000000”
如果一天中的所有时间都是时间记录，
那么<Block_0>的值是
“111111111111111111111111111111111111111111111111”
如果一天的所有时间都是运动记录，
那么<Block_0>的值是
“222222222222222222222222222222222222222222222222”。
如果一天中的所有时间都被报警，
那么<Block_0>的值是
“333333333333333333333333333333333333333333333333”。

##### 请求

**xml**
无
**字段说明**
无

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<RecordSchedule>
    <StreamType><!--rw,req,xs:string,”main,sub,hdsub” --></StreamType>

        <AllDay><!--rw,req,xs:boolean; "false","true"--></AllDay>
        <TimeBlockList>
            <TimeBlock_0><!-- rw,req,xs:string,max length 48,eg:111111111111111111111111111111111111111111111111 --></TimeBlock_0>
            <TimeBlock_1><!-- rw,req,xs:string,max length 48,eg:111111111111111111111111111111111111111111111111 --></TimeBlock_1>
            <TimeBlock_2><!-- rw,req,xs:string,max length 48,eg:111111111111111111111111111111111111111111111111 --></TimeBlock_2>
            <TimeBlock_3><!-- rw,req,xs:string,max length 48,eg:111111111111111111111111111111111111111111111111 --></TimeBlock_3>
            <TimeBlock_4><!-- rw,req,xs:string,max length 48,eg:111111111111111111111111111111111111111111111111 --></TimeBlock_4>
            <TimeBlock_5><!-- rw,req,xs:string,max length 48,eg:111111111111111111111111111111111111111111111111 --></TimeBlock_5>
            <TimeBlock_6><!-- rw,req,xs:string,max length 48,eg:111111111111111111111111111111111111111111111111 --></TimeBlock_6>
        <TimeBlockList>
    </Schedule>
</RecordSchedule>
```
