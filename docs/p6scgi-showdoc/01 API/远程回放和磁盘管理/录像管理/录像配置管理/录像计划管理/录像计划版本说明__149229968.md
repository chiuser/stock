# 录像计划版本说明
#### 说明
录像计划有V1、V2两个版本，区别在录像计划的展示样式和适用的客户端

#### 录像计划V1
录像计划V1只支持表格样式展示，主要适用于web

#### 录像计划V2
录像计划V2支持表格样式展示和时间段样式展示，表格样式适用于web，时间段样式适用于app
