# 设置录像上传服务器配置
##### 简要描述

- ##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<URL>
  <Description><!--rw,opt,xs: string, the max length : 32 --></Description>
  <Protocol><!--rw,req,xs:string,"http"--></Protocol>
  <Host><!--rw,req,xs: string, the max length : 256--></Host>
  <Port><!--rw,req,xs:interger--></Port>
  <Path><!--rw,req,xs:string, the max length : 32--></Path>
  <Username><!--rw,opt,xs:string, the max length : 32--></Username>
  <Password><!--rw,opt,xs:string, the max length : 32 --></Password>
</URL>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Description | string | 录像服务器备注描述信息 | 否 | 是 | 是 | 可读可写 | 最大长度32 |  |
| Protocol | string | 协议；目前仅支持<span class="colour" style="color:rgb(206, 145, 120)">HTTP</span> | 是 | 是 | 否 | 可读可写 | 最大长度32 |  |
| Host | string | 录像服务器域名 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |
| Port | integer | 录像服务器端口 | 是 | 是 | 否 | 可读可写 | 取值需与设备确认 |  |
| Path | string | 录像路径 | 是 | 是 | 否 | 可读可写 | 最大长度64 |  |
| Username | string | 用户名 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  |
| Password | string | 用户密码 | 否 | 是 | 否 | 可读可写 | 最大长度32 |  ||
