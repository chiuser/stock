# 获取录像配置
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<Record>
    <RecordWriteCircleType><!--rw,req,xs:string,”fullnotwrite,writecircle”--></RecordWriteCircleType>
    <RecordDeleteType><!--rw,req,xs:string,”24,48,none”--></RecordDeleteType>
    <RecordStreamType><!--rw,req,xs:string,”main,sub,hdsub”--></RecordStreamType>
    <PreRecord><!--rw,req,xs:integer,1-120,the unit is second--></PreRecord>
    <DelayRecord><!--rw,req,xs:integer,10-300,the unit is second--></DelayRecord>
    <RecordMode><!--rw,req,xs:string,”stop,manual,auto”--></RecordMode>
</Record>
```

**字段说明**

| RecordDeleteType | string | <span class="colour" style="color:rgb(106, 153, 85)">录像覆写删除类型；</span><span class="colour" style="color:rgb(206, 145, 120)">none</span><span class="colour" style="color:rgb(106, 153, 85)">,不删除，</span><span class="colour" style="color:rgb(206, 145, 120)">24</span><span class="colour" style="color:rgb(106, 153, 85)">,24小时，表示循环写入的时候，只覆盖超过24小时的录像，其他来的录像丢弃。</span><span class="colour" style="color:rgb(206, 145, 120)">48</span><span class="colour" style="color:rgb(106, 153, 85)">,48小时，表示循环写入的时候，只覆盖超过48小时的录像，其他来的录像丢弃.</span> | 是 | 是 | 否 | 可读可写 | 最大长度32 |  |
