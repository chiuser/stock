# 获取录像文件列表某一个页的录像信息
##### 简要描述

- ##### 说明

[http://192\.168\.0\.180/RecordFileList/Pages/1?Pathtype=0\|1](http://192.168.0.180/RecordFileList/Pages/1?Pathtype=0%7C1)(0，<PathName>相对于http根目录.1，<PathName>是绝对路径。)

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<RecordFileList>
   <RecordFile>
      <PathName><!--ro,req,xs:string, the max length : 64--></PathName>
      <FileName><!--ro,req,xs:string, the max length : 128--></FileName>
      <StartTime><!--ro,req,xs:datetime” 20040503 173008”--></StartTime>
      <StopTime><!--ro,req,xs:datetime” 20040503 173008”--></StopTime>
```
