# 查看人脸识别记录详细内容
##### 简要描述

- 请求xml

| 字段 | 类型 | 描述 | 是否必须 |
| --- | --- | --- | ---- |
| LogID | integer | <span class="colour" style="color:rgb(106, 153, 85)">标记日志记录的ID，从0递增</span> | 是 |
| IsPicture | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否带图片，false表示不带，true表示带</span> | 是 |

响应xml

| 字段 | 类型 | 描述 | 是否必须 |
| --- | --- | --- | ---- |
| Name | string | <span class="colour" style="color:rgb(106, 153, 85)">姓名，最大长度32，不可为空，中文字符使用utf-8格式</span> | 是 |
| Sex | string | <span class="colour" style="color:rgb(106, 153, 85)">性别,male,female</span> | 是 |
| CertificateType | string | <span class="colour" style="color:rgb(106, 153, 85)">证件类型 ；</span><span class="colour" style="color:rgb(206, 145, 120)">none，IC，passport，other；</span><span class="colour" style="color:rgb(106, 153, 85)">最大长度32</span> | 是 |
| CertificateID | string | <span class="colour" style="color:rgb(106, 153, 85)">证件ID，可为空，最大长度32</span> | 是 |
| PersonID | interger | <span class="colour" style="color:rgb(106, 153, 85)">人员ID，从0开始递增，可为0，最新版本接口暂未使用可不传</span> | 否 |
| Country | string | <span class="colour" style="color:rgb(106, 153, 85)">国家，可为空,最大长度32</span> | 否 |
| Address | string | <span class="colour" style="color:rgb(106, 153, 85)">地址，可为空,最大长度64</span> | 否 |
| Birthday | string | <span class="colour" style="color:rgb(106, 153, 85)">生日,最大长度64，不可为空，格式：YYYYMMDDThhmmss</span> | 是 |
| RecoResult | boolean | <span class="colour" style="color:rgb(106, 153, 85)">识别结果；Comparison pass表示对比通过，Comparison fail表示对比失败，Failure of biopsy表示活体检测失败，all全部</span> | 是 |
| FaceTemperature |  | <span class="colour" style="color:rgb(106, 153, 85)">人脸温度信息(支持人脸温度检测的设备有该节点)</span> | 否 |
| Temperature | float | <span class="colour" style="color:rgb(106, 153, 85)">人脸温度(支持人脸温度检测的设备有该节点)</span> | 是 |
| TemperatureUnit | string | <span class="colour" style="color:rgb(106, 153, 85)">人脸温度单位(支持人脸温度检测的设备有该节点)（</span><span class="colour" style="color:rgb(206, 145, 120)"><span class="colour" style="color:rgb(206, 145, 120)">notsupport</span></span><span class="colour" style="color:rgb(106, 153, 85)">-不支持，</span><span class="colour" style="color:rgb(206, 145, 120)">celsius</span><span class="colour" style="color:rgb(106, 153, 85)">-摄氏度，</span><span class="colour" style="color:rgb(206, 145, 120)">fahrenheit</span><span class="colour" style="color:rgb(106, 153, 85)">-华氏度）</span> | 是 |
| Fever | string | <span class="colour" style="color:rgb(106, 153, 85)">发热(支持人脸温度检测的设备有该节点)（</span><span class="colour" style="color:rgb(206, 145, 120)"><span class="colour" style="color:rgb(206, 145, 120)">notsupport</span></span><span class="colour" style="color:rgb(106, 153, 85)">-不支持，</span><span class="colour" style="color:rgb(206, 145, 120)">normal</span><span class="colour" style="color:rgb(106, 153, 85)">-正常，</span><span class="colour" style="color:rgb(206, 145, 120)">fever</span><span class="colour" style="color:rgb(106, 153, 85)">-发热，</span><span class="colour" style="color:rgb(206, 145, 120)">unknown</span><span class="colour" style="color:rgb(106, 153, 85)">-未知）</span> | 是 |
| FaceMask | string | <span class="colour" style="color:rgb(106, 153, 85)">口罩（</span><span class="colour" style="color:rgb(206, 145, 120)"><span class="colour" style="color:rgb(206, 145, 120)">notsupport</span></span><span class="colour" style="color:rgb(106, 153, 85)">-不支持，</span><span class="colour" style="color:rgb(206, 145, 120)">has</span><span class="colour" style="color:rgb(106, 153, 85)">-有口罩，</span><span class="colour" style="color:rgb(206, 145, 120)">no</span><span class="colour" style="color:rgb(106, 153, 85)">-无口罩，</span><span class="colour" style="color:rgb(206, 145, 120)">unknown</span><span class="colour" style="color:rgb(106, 153, 85)">-未知）</span> | 否 |
| RecoValid | boolean | <span class="colour" style="color:rgb(106, 153, 85)">识别结果是否有效，</span><span class="colour" style="color:rgb(206, 145, 120)">true</span><span class="colour" style="color:rgb(106, 153, 85)">-有效，</span><span class="colour" style="color:rgb(206, 145, 120)">false</span><span class="colour" style="color:rgb(106, 153, 85)">-无效</span> | 是 |
| UniqueID | string | <span class="colour" style="color:rgb(106, 153, 85)">人员唯一标识ID，最大长度32，可为空，最新版本接口暂未使用可不传</span> | 否 |

字段Address中的省份(州)和市（区）之间使用#来隔开。

UniqueID：并非所有设备都支持，若返回的XML中包含UniqueID，则必定与PersonID出于同一条记录，即PersonID与UniqueID相对应

 - `/FaceRecognition/DetailByRecognitionRecord`
