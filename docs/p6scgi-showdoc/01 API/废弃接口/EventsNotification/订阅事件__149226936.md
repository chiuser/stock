# 订阅事件
##### 简要描述

- ##### 说明

您只使用“PUT”方法订阅事件类型，并且只设置<EventType>的值

##### 请求

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<SubscribedEventTypeList>
    <SubscribedEventType>
       <ID><!--rw,req,xs:integer--></ID>
       <EventType><!—-rw,req,xs:string，“VMD,videolost,AlarmIn”--></EventType>
       <EventTypeDescription><!—-rw,req,xs:string, "Video Motion Detect", "video lost", "alarm in"--></EventTypeDescription>
    </SubscribedEventType>
</SubscribedEventTypeList>
```
