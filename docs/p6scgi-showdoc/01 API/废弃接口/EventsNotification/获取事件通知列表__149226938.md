# 获取事件通知列表
##### 简要描述

- ##### 说明

首先，您必须通过/EventsNotification/SubscribedEventTypeList的URL订阅您想要的事件（VMD，VideoLost，AlarmIn），然后，您可以通过url /EventsNotification/EventList获取当前事件列表。

##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<EventList>
    <Event>
       <ID><!--ro,req,xs:integer --></ID>
       <IPAddress><!—-ro,req,xs:string, the max length : 32--></IPAddress>
       <Port><!—-ro,req,xs:integer--></Port>
       <Protocol><!—-ro,req,xs:string, "http"--></Protocol>
       <ChannelID><!—-ro,req,xs:string, the max length : 32--></ChannelID>
       <DateTime><!—-ro,req,xs:datetime,"yyyymmddThhmmss"--></DateTime>
       <EventType><!—-ro,req,xs:string，“VMD,videolost,AlarmIn”--></EventType>
       <EventTypeDescription><!—-ro,req,xs:string, "Video Motion Detect", "video lost", "alarm in"--></EventTypeDescription>
    </Event>
</EventList>
```
