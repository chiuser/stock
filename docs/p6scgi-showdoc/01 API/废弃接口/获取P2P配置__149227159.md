# 获取P2P配置
##### 简要描述

- ##### 请求

**xml**
无
**字段说明**
无

##### 响应

**xml**

```
<?xml version="1.0" encoding="utf-8"?>
<P2P>
    <Enable><!--rw,req,xs:boolean--></Enable>
    <UUID><!--rw,req,xs:string, the max  length: 32--></UUID>
    <Status><!--ro,req,xs:string,”offline,internet-ready,intranet-ready,Network-Unreachable,Invalid-UUID,NotFoundServer” --></Status>
</P2P>
```

**字段说明**

| 字段 | 类型 | 描述 | 是否必须 | 是否有效 | 是否可为空 | 可读可写(rw)/只读(ro)/只写(wo) | 取值范围/长度 | 备注 |
| --- | --- | --- | ---- | ---- | ----- | ---------------------- | ------- | --- |
| Enable | boolean | <span class="colour" style="color:rgb(106, 153, 85)">是否启用TUTK服务</span> | 是 | 是 | 否 | 可读可写 | false/true |  |
| UUID | string | <span class="colour" style="color:rgb(106, 153, 85)">当前设备的TUTK UID</span> | 是 | 是 | 否 | 可读可写 | 最大长度32 |  |
| Status | string | <span class="colour" style="color:rgb(106, 153, 85)">TUTK状态，offline未联机，internet-ready内网就绪，intranet-ready外网就绪，Network-Unreac网络不可达，Invalid-UUID无效UUID，NotFoundServer未找到服务</span> | 是 | 是 | 否 | 只读 | 动态数组 |  |

##### 请求URL

 - `/Network/P2P` 

##### 请求方式

- get
