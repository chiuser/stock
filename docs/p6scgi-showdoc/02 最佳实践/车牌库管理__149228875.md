# 车牌库管理
限制（在磁盘空间或者内存空间足够的情况下）
---------------------

*   **车牌库**：目前设备仅支持1个车牌库，每个车牌库最大支持5000个车牌，
*   **图片大小限制**：车牌库中只保存车牌号，不保存图片

功能简介
----

车牌库相关功能包含：车牌抓拍，车牌布控，车牌库管理(增删改查)，车牌管理(增删改查)，车牌布控事件

**车牌抓拍**

1.  车牌抓拍功能，用户可以指定检测区域，当检测目标进入检测区域时，可以对车牌进行抓拍，并在客户端进行展示；
2.  抓拍到车牌时，可把车牌信息显示在预览界面中；
3.  当前若开启了人脸抓拍/人脸识别，需要切换为车牌抓拍/车牌识别功能时，需要重启生效；

**_车牌联动处理_**

联动需要满足驶入方向和报警规则条件才能触发联动：

*   若现在配置驶入方向为下行为驶入，报警规则配置为驶入，这时候如果事件触发时，判断车是在下行（即车靠近摄像头），这时候就会触发事件
*   若现在配置驶入方向为下行为驶入，报警规则配置为驶出，这时候如果事件触发时，判断车是在上行（即车远离摄像头），这时候就会触发事件
*   若现在配置驶入方向为上行为驶入，报警规则配置为驶入，这时候如果事件触发时，判断车是在上行（即车远离摄像头），这时候就会触发事件
*   若现在配置驶入方向为上行为驶入，报警规则配置为驶出，这时候如果事件触发时，判断车是在下行（即车靠近摄像头），这时候就会触发事件
*   若报警规则配置为驶入和驶出，事件触发不管任何方向均可触发

**_车牌识别_**

1.  功能开启时会进行车牌号码的识别，兼容4.0之前的版本，默认是进行识别车牌号码的
2.  功能关闭时，只进行抓拍图片，速度上优于识别车牌号码的时候
3.  功能关闭时，车牌号填NA（功能开启时如果是无车牌则车牌号填NULL），与车牌有关的属性没有；
4.  抠图类型字段控制发送的车牌图是用车牌图还是车形图；

**_网页展示_**

1.  当设备抓拍到车牌时，会把事件发送到客户端，事件包括图片，车牌号，车辆类型，车牌颜色
2.  客户端图片展示在今日抓拍中；

**车牌布控**

   车牌抓拍和车牌布控功能可同时开启（类似人脸抓拍和人脸识别同时开启），开启车牌布控后优先发送车牌布控事件，使用车牌抓拍的检测区域，当检测目标进入检测区域时，可以对车牌进行抓拍识别后，然后进行数据库对比，并在客户端进行展示对比结果   

   开启车牌布控会同时开启车牌抓拍，车牌抓拍关闭时，车牌布控也被关闭；

   开启车牌布控后，只发送布控规则布控成功的事件，并基于车牌布控中的联动方式触发动作，比如声音报警、触发推送、灯光报警

   车牌布控的规则/类型总共有4个，可多选，最多选4个:

1.  关注车牌：抓拍到的车牌在车牌数据库里面存在，则进行报警
2.  陌生车牌：抓拍到的车牌在车牌数据库里面不存在，则进行报警
3.  非绿色车牌：抓拍到的车牌颜色为非绿色车牌，则进行报警
4.  黄色车牌：抓拍到的车牌颜色为黄色车牌，则进行报警

    每种模式下有独立的联动及布防时间，默认车牌布控告警模式为：陌生车牌，非绿色车牌和黄色车牌功能有重合，是产品需求中要求区分的

    车牌布控类型选了之后可以配置这个规则中的联动方式，布防时间，最大同时支持4组联动

**车牌库**

   对车牌库进行增删改查操作，目前仅支持1个车牌库，每个车牌库最大支持5000个车牌，且车牌库中只保存车牌号，不保存图片

**_车牌库同步_**

1.  客户端调用接口后进行绑定；
2.  安全码校验；
3.  把客户端车牌库和车牌进行同步，这里会将设备的车牌库和车牌删除，重新创建车牌库并添加车牌；

**_车牌库操作_**

1.  车牌库仅支持1个库，无组织架构，车牌库有“车牌数量”和“车牌库名字”显示，黑名单暂时不显示
2.  增删改车牌库操作需要进行安全码校验；
3.  查询车牌库操作不用进行安全码校验；

**车牌管理**

   对车牌进行增删改查操作
   
1.  车牌信息目前只存放车牌号，其他信息不保存，但先定义车牌颜色、车辆颜色、车主姓名等，最大支持5000个车牌
2.  增删改车牌操作需要进行安全码校验；
3.  查询车牌操作不用进行安全码校验；
4.  查询车牌可用模糊查询；

**_进入统计_**

   以上图为例，若A边在警戒线的上面，则B边应该在警戒线的下面，反之B边在警戒线上面，A边在警戒线下面

1.  检测方向为A->B，人形从A边越过到B边，判断为进入
2.  检测方向为B→A，人形从B边越过到A边，判断为进入

**_离开统计_**

   以上图为例，若A边在警戒线的上面，则B边应该在警戒线的下面，反之B边在警戒线上面，A边在警戒线下面

1.  检测方向为A->B，人形从B边越过A边，判断为离开
2.  检测方向为B→A，人形从A边越过B边，判断为离开

**_进入离开语音处理_**

1.  进入和离开同时触发时，使用先触发的那个语音，后面触发的语音不响应；
2.  多人触发播放语音，5s内只播报一次，不要重复进语音播放队列，一直播放；

字段解释
----

*   **拥有者**:接口[/System/LicensePlateOwnnerInfo](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74013)的Ownner字段，表示设备车牌库的拥有者,由想操作设备车牌库的客户端（NVR，EasyVMS或对接的平台）生成唯一标志并通过[/System/LicensePlateOwnnerInfo](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74013)接口设置到设备，设置成功了之后，该客户端（EasyVMS，NVR，平台）就是该设备车牌库的拥有者，可以任意操作该车牌库
*   **安全码**:安全码用来操作车牌库（车牌库的增、删、改，车牌信息的增、删、改）必须传输的字段，比如增加车牌库[/LicensePlateGroup/Create](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74021)的SecurityCode字段，通常和字段SystemTime一起传输给设备，由拥有者和时间进行相关计算（具体java计算源码参考“**安全码生成（java示例）**”章节）生成，生成安全码的时间同时要通过SystemTime一起传给设备，这两个字段作为能够操作设备车牌库的基础。不然无法操作车牌库
*   **车牌库ID**:[/LicensePlateGroup/Create](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74021)的LicensePlateGroupID字段，是标志车牌库的唯一标志，有客户端（VR，EasyVMS或对接的平台）生成，对设备来说唯一即可
*   **车牌库名**:[/LicensePlateGroup/Create](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74021)的LicensePlateGroupName字段，是设备车牌库的名字，跟车牌库ID一样对于设备来说具有唯一性，但是具有可读性，由客户端生成
*   **报警联动**:主要是指车牌识别的报警联动，当抓拍的车牌跟设备车牌库中的车牌匹配度满足该脸库阈值的时候，就会触发报警联动，比如说触发设备的声音报警，灯光报警，触发推送，SD卡抓图，SD卡录像等等，比如说创建的脸库G1，脸库阈值是70，脸库下G1有一个三个人员G1P1，G1P2，G1P3当有人经过设备（人脸抓拍和人脸识别功能已启用）时，设备会触发人脸抓拍，抓拍的人脸会和脸库G1的人员进行对比，当发现P2和抓拍的人员对比的相似值为71时，此时表示人脸识别成功，也就是说抓拍的人已经在脸库，就会触发一个报警联动，这当然是针对报警联动的对象设置为所有脸库成功的情况下，如果报警联动的对象设置的是G1下的P1，那么久不回触发报警联动
*   **报警联动的车牌布控类型**:主要是报警联动针对的车牌布控类型，对应的是[车牌布控配置](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74005)中的LicensePlateSuveillanceType字段
*   **报警联动的布防时间**:主要是指报警联动在指定的时间才允许触发，支持全天布放和自定义布防（将一天划分为48个份，每一份表示半个小时），每种布控类型有独立的事件联动及布防时间，对应的是[车牌布控配置](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74005)中RuleCfg的Schedule字段
*   **报警联动的联动方式**:目前支持联动设备的声音报警（需要使用/FaceReco/ChannelID/RecoRuleListVoiceAlarm进行额外配置），灯光报警（需要使用/Alarm/ChannelID/LightWarning进行额外配置），联动SD卡抓图和录像（需要有SD卡，才能使能），联动消息推送到APP（使能之后，APP上需要做消息订阅才能收到消息推送），联动FTP消息触发（需要使用/Network/ftp进行FTP配置），联动输出报警输出信号（可以接外设，触发外设，比如说门禁，需要使用/Alarm/Alarmout进行报警输出相关配置），对应的是/FaceReco/ChannelID/RecoRuleList中Trigger字段
*   **报警联动的灯光报警**:可以设置灯光报警的模式（常亮或者闪烁）和持续时间（1-60秒），对应的是[车牌布控配置](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74005)中Trigger，具体可以参考[灯光报警](http://xrs-api.p6sai.com:8091/project/11074/interface/api/61688)
*   **报警联动的声音报警**:可以设置声音报警的声音类型（犬吠，警号，自定义等），报警次数，对应的是[车牌布控配置](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74005)中Trigger，每种布控类型有独立的声音报警配置，对应的是[车牌布控配置](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74005)中RuleCfg的VoiceAlarm，具体可以参考[试听音频](http://xrs-api.p6sai.com:8091/project/11074/interface/api/59218)和[音频报警配置](http://xrs-api.p6sai.com:8091/project/11074/interface/api/59223)

接口说明
----

### 车牌抓拍配置

*   [/AI/CarPlateSnap](http://xrs-api.p6sai.com:8091/project/11074/interface/api/72189)，支持GET和PUT，GET表示获取拥有者，PUT表示设置拥有者

### 车牌布控配置

*   [/System/LicensePlateSurveillanceUIDesignCfg](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74005)，支持GET和PUT

### 车牌库管理权限管理

*   [/System/LicensePlateOwnnerInfo](http://192.168.250.99:8090/System/LicensePlateOwnnerInfo)，支持GET和PUT，GET表示获取拥有者，PUT表示设置拥有者

### 车牌库管理

*   [/LicensePlateGroup/Create](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74021) 创建车牌库
*   [/LicensePlateGroup/Modify](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74029) 修改车牌库，主要是修改车牌库名
*   [/LicensePlateGroup/Delete](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74025) 删除车牌库，会删除车牌库以及车牌库下的所有车牌信息
*   [/LicensePlateGroup/QueryAll](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74033) 查询所有的车牌库信息

### 车牌管理

*   [/LicensePlateGroup/DeleteLicensePlateInfoList](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74045) 删除车牌信息列表
*   [/LicensePlateGroup/UpdateLicensePlateInfoList](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74041) 增加和更新车牌信息
*   [/LicensePlateGroup/QueryLicensePlateInfoList](http://xrs-api.p6sai.com:8091/project/11074/interface/api/74049) 查询符合条件的车牌信息列表

问答
--

### ****1.车牌库，车牌信息的关系****

d.添加车牌信息的时候一定是要关联车牌库,不可能存在车牌信息不属于任何车牌库的情况  
e.删除车牌库的时候，都会将车牌库下的所有的车牌信息同时删除

**2.几个删除URL的区别**

包括/LicensePlateGroup/Delete，/LicensePlateGroup/DeleteLicensePlateInfoList  
/LicensePlateGroup/Delete 表示删除车牌库，下属的车牌信息一起删除  
/LicensePlateGroup/DeleteLicensePlateInfoList仅删除车牌信息，支持删除多个车牌信息，最多一次支持删除50个

**4.拥有者和安全码的关系**

/System/FrontDeviceOwnnerInfo中的Ownner表示的是拥有者  
车牌库操作（车牌库的增，删，改，组织的增，删，改，车牌信息的增，删，改）中SecurityCode表示的是安全码  
安全码是由拥有者+时间算出来的，具体计算参考“**安全码生成（java示例）**”章节

**5.添加和更新车牌信息使用的是同一个URL为/LicensePlateGroup/UpdateLicensePlateInfoList，如何区分？**

当请求字段中的LicensePlateUUID车牌库中不存在的时候，表示新增，LicensePlateUUID不可为空  
当请求字段中的LicensePlateUUID车牌库中存在时，表示更新，LicensePlateUUID不可为空

**6.有哪些ID是设备生成的，哪些ID是客户端生成的**

车牌库ID（LicensePlateGroupID）是客户端生成的  
车牌信息ID（LicensePlateUUID）是设备生成的

**7.查询接口不需要安全码，包含哪些接口**

/LicensePlateGroup/QueryAll车牌库查询，不需要参数，直接可以查询所有的车牌库列表  
/LicensePlateGroup/QueryLicensePlateInfoList符合请求条件的车牌信息查询，支持根据车牌模糊查询
